导论与单变量线性回归

◆ 知识重点

  • 机器学习定义（Mitchell）：任务 T、经验 E、性能 P——用 E 改善 P。
  • 监督学习：有标签；回归＝预测连续值，分类＝预测离散类别。无监督：聚类、降维。
  • 训练集记号：样本 x⁽ⁱ⁾、目标 y⁽ⁱ⁾、样本数 m。
  • 线性回归模型 fw,b(x) = wx + b；训练＝arg min J(w,b)。
  • 平方误差代价 J 是 (w,b) 的凸函数（碗形）→ 梯度下降必达全局最优。
  • 「批量(batch)」梯度下降：每步用全部 m 个样本算梯度。

✱ 考试要点

  • 同步更新：w、b 必须用旧值同时更新；先用新 w 去算 b 的梯度＝错。
  • α 太大 → 震荡/发散；太小 → 慢。接近极小值时步幅自动变小（坡度变缓）。
  • 收敛判据是梯度＝0，不是 J＝0。
  • 回归 vs 分类看输出是否连续（房价→回归，垃圾邮件→分类）。
J(w, b) = 1⁄2m Σi=1..m ( fw,b(x⁽ⁱ⁾) − y⁽ⁱ⁾ )²代价函数
repeat {  w := w − α·∂J⁄∂w ;   b := b − α·∂J⁄∂b  }  ⇒   w := w − α·1⁄m Σ (f(x⁽ⁱ⁾)−y⁽ⁱ⁾)·x⁽ⁱ⁾梯度下降
linear_regression.py代价 + 批量梯度下降（同步更新）NumPy
def compute_cost(x, y, w, b):
    m = len(x)
    return np.sum((w*x + b - y)**2) / (2*m)

def gradient_descent(x, y, w, b, alpha, iters):
    for _ in range(iters):
        err = w*x + b - y                # 残差基于旧参数 → 天然同步更新
        w -= alpha * np.sum(err*x) / len(x)
        b -= alpha * np.sum(err)   / len(x)
    return w, b

多变量线性回归

◆ 知识重点

  • 多特征模型：fw,b(x) = w·x + b = w₁x₁ + … + wnxn + b。
  • 向量化：np.dot(w,x) 快于 Python for 循环（并行 + 缓存友好）。
  • 特征缩放：各特征量纲悬殊时（如 x₁∈[0,2000], x₂∈[1,5]）等高线变椭圆 → 收敛慢；缩放后近圆形 → 快。
  • z-score 标准化：(x−μ)/σ，目标范围约 [−1, 1] 即可。
  • 学习率调试：J 应逐迭代下降；上升/震荡 → α÷10；太慢 → α×3。
  • 特征工程：长×宽→面积；多项式回归：用 x, x², x³ 作特征拟合曲线。

✱ 考试要点

  • z-score 公式必须手算会：给 μ、σ 算标准化值（高频选择题）。
  • 判断「要不要缩放」：看特征取值范围差几个数量级。
  • J 曲线上升 ⇒ α 过大，第一反应是减小 α。
  • 多项式回归中 xⁿ 范围爆炸 ⇒ 更需要特征缩放。
multivariate.py向量化 + z-score + 多元梯度下降NumPy
def zscore(X):                          # 逐列标准化
    return (X - X.mean(axis=0)) / X.std(axis=0)

def gd_multi(X, y, w, b, alpha, iters):
    m = X.shape[0]
    for _ in range(iters):
        err = X @ w + b - y              # f = w·x + b，向量化
        w -= alpha * (X.T @ err) / m
        b -= alpha * err.mean()
    return w, b

逻辑回归、过拟合与正则化

◆ 知识重点

  • Sigmoid：g(z) = 1/(1+e−z)，输出解释为 P(y=1|x)。
  • 决策边界：w·x + b = 0；多项式特征 → 非线性边界。
  • 交叉熵损失（分段）：y=1 时 −log f，y=0 时 −log(1−f)。
  • 过拟合（高方差）：训练好、泛化差；欠拟合（高偏差）：训练都差。
  • 对策：①更多数据 ②减少特征 ③正则化（保留全部特征、缩小参数）。
  • 正则化项 λ/(2m)·Σwj²：只罚 w 不罚 b。

✱ 考试要点

  • 逻辑回归不用平方误差：非凸，梯度下降会陷入局部最优。
  • 损失直觉：f→0 而 y=1 ⇒ L→∞（ confidently wrong 惩罚最重）。
  • 逻辑回归的梯度更新公式与线性回归形状完全相同，只是 f 换成 sigmoid。
  • λ 过大 → 所有 w→0 → 欠拟合（接近常数预测）；λ=0 → 无正则化。
J(w, b) = −1⁄m Σ [ y⁽ⁱ⁾·log f(x⁽ⁱ⁾) + (1−y⁽ⁱ⁾)·log(1−f(x⁽ⁱ⁾)) ]  +  λ⁄2m Σj=1..n wj²正则化逻辑回归
logistic.pysigmoid + 正则化交叉熵 + 梯度下降NumPy
def sigmoid(z):
    return 1 / (1 + np.exp(-z))

def cost_logreg(X, y, w, b, lam=0):
    f = sigmoid(X @ w + b)
    ce = -np.mean(y*np.log(f) + (1-y)*np.log(1-f))
    return ce + lam/(2*len(y)) * np.sum(w**2)   # 不含 b

def gd_logreg(X, y, w, b, alpha, iters, lam=0):
    m = len(y)
    for _ in range(iters):
        err = sigmoid(X @ w + b) - y
        w -= alpha * (X.T @ err + lam*w) / m   # 只多出 lam*w 一项
        b -= alpha * err.mean()
    return w, b

Course 1 · 公式笔记

回归与分类的 10 个核心公式。⭐＝必背。

⭐ 线性回归模型F1.1
fw,b(x) = w·x + b
n 维特征时 w·x 为向量内积。
⭐ 平方误差代价F1.2
J(w,b) = 1⁄2m Σ (f(x⁽ⁱ⁾) − y⁽ⁱ⁾)²
系数 ½ 纯为求导消 2；凸函数。
⭐ 线性回归梯度更新F1.3
wj := wj − α·1⁄m Σ (f−y⁽ⁱ⁾)·xj⁽ⁱ⁾  ;  b := b − α·1⁄m Σ (f−y⁽ⁱ⁾)
对所有参数同步更新。
⭐ SigmoidF1.4
g(z) = 1 / (1 + e−z)
z→∞ ⇒ g→1；z=0 ⇒ g=0.5。
⭐ 逻辑回归分段损失F1.5
L(f,y) = −log(f)  if y=1;  −log(1−f)  if y=0
等价简并式：−y·log f −(1−y)·log(1−f)。
⭐ 逻辑回归代价F1.6
J = −1⁄m Σ[ y·log f + (1−y)·log(1−f) ]
凸；梯度形式与线性回归全同。
z-score 特征缩放F1.7
xj′ = (xj − μj) / σj
μ=均值，σ=标准差；让各特征量纲可比。
⭐ 正则化线性回归F1.8
J = 1⁄2m Σ(f−y)² + λ⁄2m Σ wj²
w 的更新多出 +(λ/m)w 项（权重衰减）。
正则化逻辑回归F1.9
J = 交叉熵 + λ⁄2m Σ wj²
同一个 λ 框架套两种模型。
⭐ λ 的权衡F1.10
λ→0 : 无正则(过拟合)  ;  λ 过大 : w→0 (欠拟合)
正则化从不惩罚 b——考试原题。

神经网络与前向传播

◆ 知识重点

  • 神经元：a = g(w·x + b)；一层＝一组神经元同时计算。
  • 前向传播逐层计算：a[l] = g(W[l]a[l−1] + b[l])。
  • 矩阵维度：W[l] ∈ ℝn^[l]×n^[l−1]，b[l] ∈ ℝn^[l]。
  • 三层典型结构：输入层 → 隐藏层（提取特征）→ 输出层。
  • TensorFlow：Sequential([Dense(25,'sigmoid'), …])；Dense＝一层。
  • 每个神经元都在看上一层的全部输出——层的本质是矩阵乘法＋激活。

✱ 考试要点

  • 给网络结构求 W[2] 的 shape：(本层神经元数, 上层神经元数)。
  • 没有激活函数（g=恒等）⇒ 多层网络塌缩为线性回归——激活引入非线性。
  • 「隐藏层」＝既非输入也非输出的层；层数不算输入层（常见陷阱题）。
  • 前向传播手算题：一层层代 g(Wx+b)，别跳步。
a[2] = g( W[2] · a[1] + b[2] ),   a[1] = g( W[1] · x + b[1] )前向传播

激活函数、Softmax 与训练细节

◆ 知识重点

  • 训练三步曲：compile(loss) → fit(X,y,epochs) → predict。
  • 激活函数：ReLU max(0,z)；sigmoid；linear g(z)=z；softmax。
  • Softmax：aj = ez_j/Σkez_k，输出 K 类概率分布（和为 1）。
  • 多分类损失：稀疏交叉熵 −log ay。
  • Adam：自适应缩放各参数学习率（大梯度小步、小梯度大步），α 好调。
  • 反向传播＝计算图上的链式法则，算出 ∂J/∂w（TensorFlow 自动完成）。

✱ 考试要点

  • 输出层激活选择表（必考）：二分类 sigmoid；回归（±∞）linear；非负回归 ReLU；多分类 softmax。
  • 隐藏层默认 ReLU：计算快 + 不易梯度饱和。
  • softmax 所有输出相加恒为 1；单个 z 增大 → 自身概率↑、其余↓。
  • from_logits=True：输出层写 linear，数值更稳，预测时再 softmax。
  • Adam vs 普通 GD：不同参数各自不同的有效学习率。
a1,…,aK = softmax(z)j = ezj / Σk=1..K ezk    L(f, y) = −log aysoftmax + 交叉熵

COURSE 2 · WEEK 3

模型评估、偏差/方差与改进策略

◆ 知识重点

  • 数据三分：train 60% / cv 20% / test 20%；用 cv 集选模型，test 只碰一次。
  • 高偏差（欠拟合）：train 误差 ≈ cv 误差，且都高于基线。
  • 高方差（过拟合）：train 误差低，cv 误差显著更高。
  • 基线＝人类/竞品水平；差距才有意义。
  • 改进路径：更大网络→治偏差；更多数据→治方差；正则化↑→治方差。
  • 迁移学习：预训练模型＋小数据 → 只重训输出层/最后几层。
  • 倾斜数据看 P / R / F1，不看 accuracy。

✱ 考试要点

  • 诊断题套路：先看 train 误差（高→高偏差），再看 cv−train 差距（大→高方差）。
  • 高偏差时「加数据」没用——经典陷阱选项。
  • F1 = 2PR/(P+R) 手算（P=TP/(TP+FP)，R=TP/(TP+FN)）。
  • 正样本占比 0.1% 时，全预测负类 accuracy=99.9% 但毫无价值。
  • 迁移学习适用：新任务输出层不同、数据少、与预训练域相近。

决策树、随机森林与 XGBoost

◆ 知识重点

  • 决策树：每节点选信息增益最大的特征切分，递归到纯/达停止条件。
  • 熵：H(p) = −p·log₂p −(1−p)·log₂(1−p)；p=0.5 时最大=1。
  • 信息增益 ＝ 父节点熵 − 加权子节点熵（权重=样本占比）。
  • 类别特征 → one-hot；连续特征 → 阈值二分；回归树 → 按方差减少分裂。
  • 随机森林：bagging（有放回抽 m 个样本）＋每节点随机特征子集（√n），多树投票。
  • XGBoost：boosting——新树专注拟合前一棵树的残差。

✱ 考试要点

  • 熵计算必考：H(0.5)=1，H(0)=H(1)=0，H(0.8)≈0.72。
  • 信息增益手算：先算父熵，再算左右子熵加权平均，相减。
  • 随机森林 > 单树：集成降低方差、不易过拟合。
  • bagging vs boosting：并行独立 vs 串行纠错。
  • XGBoost 为什么强：正则化 + 早停 + 并行优化，表格数据首选。

K-means 聚类与异常检测

◆ 知识重点

  • K-means 两步循环：① 分配——每个样本归最近质心 c⁽ⁱ⁾ = argmin‖x−μ‖；② 移动——质心＝簇内均值。
  • 代价：J = (1/m)Σ‖x⁽ⁱ⁾−μc(i)‖²，两步都在降 J。
  • 初始化：随机挑 K 个训练样本；跑 50–1000 次取 J 最小。
  • 选 K：肘部法则（不总有效）/ 下游任务评估。
  • 异常检测：拟合 p(x)，p(x) < ε 判异常。
  • 高斯模型：p(x) = Πj p(xj; μj, σj²)，各维独立。

✱ 考试要点

  • K-means 必收敛（J 单调不增），但不保证全局最优——靠多次初始化。
  • 高斯公式手算 + σ 大 → 曲矮胖，σ 小 → 曲瘦高。
  • 选异常检测 vs 监督学习（高频）：负样本极少且未来异常模式未知 → 异常检测；两类样本都多 → 监督学习。
  • 非高斯特征 → log 变换再看直方图。

COURSE 3 · WEEK 2

协同过滤、内容过滤与 PCA

◆ 知识重点

  • 协同过滤：用户参数 w 与物品特征 x 同时学习（评分矩阵已知，特征未知）。
  • 代价：只对已评分 (r=1) 的 (user,item) 对求和，＋双方正则项。
  • 均值归一化：新用户（无评分）预测＝全站均值，避免全 0。
  • 基于内容过滤：物品特征 x 已知（如电影题材），学用户参数；深度版：两个网络提 vu, vm，点积打分。
  • PCA：找 k 个正交方向，投影方差最大 / 重构误差最小。
  • 流程：中心化 → 协方差 Σ=(1/m)XTX → 特征向量 → z = UreduceTx。

✱ 考试要点

  • 协同过滤 vs 内容过滤：特征已知→内容；特征要学→协同（一句话必考）。
  • 均值归一化的动机：冷启动用户给均值而非零。
  • PCA 选 k：保留 ≥99% 方差（(ΣS[:k])/ΣS ≥ 0.99）。
  • PCA 用途：加速、可视化、降噪；不推荐用于防过拟合（正则化更好）。
  • PCA 必须先中心化（缩放可选但常见）。

COURSE 3 · WEEK 3

强化学习：MDP、Q-Learning 与 DQN

◆ 知识重点

  • 四元组框架：状态 S、动作 A、奖励 R、折扣 γ；策略 π(a|s)。
  • 回报：R₁ + γR₂ + γ²R₃ + …；γ=0.9 → 10 步后权重 < 1/3。
  • 状态值 V(s) = maxa Q(s,a)；最优策略 π(s)=argmax Q。
  • Bellman 方程：Q(s,a) = R(s,a) + γ·maxa′ Q(s′,a′)。
  • 随机环境 → 取期望；连续状态（如月球着陆器）→ DQN。
  • DQN 训练目标：y = R + γ·maxa′ Qtarget(s′,a′)，拟合 Q(s,a)。
  • 技巧：ε-greedy 探索（ε 随时间衰减）、小批经验回放、目标网络定期同步。

✱ 考试要点

  • 折扣回报手算（必考）：γ=0.5、奖励 [1, 2, 3] → 1+0.5·2+0.25·3=2.75。
  • γ 越小越短视；γ=0.99 → 看约百步，γ=0.9 → 看约十步。
  • Bellman 应用题：给 Q 表算 Q(s,a) 或 V(s)。
  • Q(s,a) 含义＝在 s 做 a、之后一直最优的期望回报。
  • ε-greedy：概率 ε 随机（探索），其余贪心 argmax（利用）。
Q(s,a) = R(s,a) + γ·maxa′ Q(s′,a′)    ⇒    π*(s) = argmaxa Q(s,a)Bellman 方程
