1.1什么是机器学习

概念★

Arthur Samuel（1959）对机器学习的经典定义是：

  1. A. 研究如何让计算机更快地执行人类编写的明确指令
  2. B. 在没有明确编程的情况下，赋予计算机学习能力的研究领域
  3. C. 用大量算力精确模拟人脑 860 亿个神经元的学科
  4. D. 只处理大数据的统计分析分支
显示答案与解析
答案：B

Samuel 的原话即「field of study that gives computers the ability to learn without being explicitly programmed」。A 是普通编程；C 是类脑计算（且课程明确说「大脑的启发早已褪色」）；D 把机器学习缩小成了统计的一个分支——它已经无处不在：搜索排序、语音助手、自动驾驶感知、大语言模型。

概念★★

用 Tom Mitchell 的 E-T-P 三元组分析「垃圾邮件过滤器」：任务 T = 把邮件分类为垃圾 / 正常。那么「经验 E」指的是：

  1. A. 邮件被正确分类的比例
  2. B. 被用户标记为垃圾 / 正常的历史邮件数据
  3. C. 把某封新邮件投进垃圾箱这个动作本身
  4. D. 垃圾邮件在全部邮件中的占比
显示答案与解析
答案：B

E（Experience）= 学习的材料 = 被标注过的历史邮件。A 是性能 P（正确分类比例）；C 是任务 T 的一部分；D 只是一个统计量，不构成经验。记忆法：E 是教材、T 是考题、P 是分数。

概念★★

下列哪个场景最符合「程序从经验中自我改进」的机器学习定义？

  1. A. 计算器按固定公式算出 2 + 3 = 5
  2. B. 程序员手写 100 条 if-else 规则来识别垃圾邮件
  3. C. 邮件系统随着用户不断标注垃圾邮件，把新邮件分对的概率越来越高
  4. D. 数据库按 SQL 查询语句返回满足条件的记录
显示答案与解析
答案：C

只有 C 同时具备 E（历史标注）、T（分类）、P（分对比例）且 P 随 E 自我改进。A、D 是确定性计算；B 是「明确编程」——正是 Samuel 定义要排除的东西。

概念★★★

关于机器学习的现状与课程目标，下列说法错误的是：

  1. A. 大语言模型的「预训练 + 指令微调」本质上是一个巨型机器学习管道
  2. B. 课程的核心目标之一是建立判断力：知道何时加数据、何时换模型、何时调超参
  3. C. 一个好的机器学习模型应当在训练集上达到 100% 正确率
  4. D. 机器学习已应用于搜索引擎排序、医学影像筛查、自动驾驶感知等领域
显示答案与解析
答案：C（说法错误，故选 C）

训练集 100% 正确往往意味着过拟合——把训练集的噪声也背了下来，新数据上会翻车（第 3 章主题）。模型真正该追求的是没见过的数据上的表现。A、B、D 均为笔记原文观点。

1.2监督学习与无监督学习

概念★

监督学习与无监督学习的根本区别在于：

  1. A. 监督学习用神经网络，无监督学习用决策树
  2. B. 无监督学习不需要数据，凭规则推理
  3. C. 监督学习一定预测连续值，无监督学习一定预测类别
  4. D. 数据是否带有标准答案（标签 y）
显示答案与解析
答案：D

分界线只有一条：每个 x 是否配一个 y。监督学习里「答案一定给足」，输出可连续（回归）也可离散（分类），所以 C 错；算法族与监督性无关，A 错。

概念★

「预测明天午后的气温是 23.5°C」与「预测明天是晴天 / 多云 / 雨天」分别属于：

  1. A. 回归、回归
  2. B. 分类、回归
  3. C. 回归、分类
  4. D. 分类、分类
显示答案与解析
答案：C

输出是连续数值（23.5°C）→ 回归；输出是离散类别（三种天气之一）→ 分类。这是官方测验的经典问法：别看问题内容，看输出空间的类型。

图像★★

下图简化重绘自笔记图 1-1（监督与无监督三分图）。三个面板从左到右依次演示的是：

  1. A. 回归（拟合直线）、分类（找分界线）、聚类（自动分堆）
  2. B. 分类、聚类、回归
  3. C. 聚类、回归、分类
  4. D. 回归、聚类、分类
显示答案与解析
答案：A

面板一：数据点近似排在一条直线附近，用直线拟合连续目标（面积→价格）→ 回归；面板二：红蓝两类点，绿色虚线是决策边界 → 分类；面板三：数据没有标签，虚线圈是算法自己发现的分组 → 聚类（无监督）。注意笔记图 1-1 右下角的虚线圈正是 Course 3 的 K-means 伏笔。

概念★★

Google News 把同一事件的不同媒体报道自动归为一簇、DNA 序列按相似性分组。这类问题属于：

  1. A. 监督学习 · 回归
  2. B. 监督学习 · 分类
  3. C. 无监督学习 · 聚类
  4. D. 强化学习
显示答案与解析
答案：C

数据只有 x（报道内容 / 序列），没有任何「正确分组」标签，算法要自己找出藏在 x 里的结构 → 聚类，无监督学习的代表。无监督家族还包括异常检测（第 8 章）与降维 PCA（9.6）。

概念★★★

笔记说强化学习是「不在图 1-1 里的第三条路」。它与监督学习的本质区别是：

  1. A. 强化学习不需要训练数据
  2. B. 监督学习没有反馈，强化学习有标签
  3. C. 强化学习只能用于游戏
  4. D. 环境反馈的不是标准答案 y，而是奖励分数
显示答案与解析
答案：D

监督学习像批改作业：每个输入配一个正确答案；强化学习像驯兽：做对了给零食（+100）、做错了扣分（−100），但没人告诉你「此刻每片旋翼该转多少」。标签 vs 奖励，是第 10 章一切内容的起点。A 错——RL 靠试错产生大量经验数据；B 恰好说反。

1.3线性回归模型

概念★

在线性回归的记号体系里，m 代表：

  1. A. 特征个数
  2. B. 参数个数
  3. C. 训练样本总数
  4. D. 梯度下降的迭代次数
显示答案与解析
答案：C

m = 训练样本总数；特征个数是 n（第 2 章登场）。单变量线性回归只有 2 个参数 (w, b)。这三个记号是全课程的「通用货币」：x⁽ⁱ⁾ 第 i 个输入、y⁽ⁱ⁾ 第 i 个目标、(x⁽ⁱ⁾, y⁽ⁱ⁾) 第 i 个训练样本。

概念★

模型 fw,b(x) = w·x + b 中，w 与 b 的角色分别是：

  1. A. 截距、斜率
  2. B. 输入特征、目标值
  3. C. 学习率、正则参数
  4. D. 权重（斜率）、偏置（截距）
显示答案与解析
答案：D

w 是权重（weight，几何上即斜率），b 是偏置（bias，几何上即纵截距）。「训练」= 从训练集中挑选让预测最贴近真实 y 的 (w, b)。C 的 α 和 λ 是第 1.5 / 3.6 节的客人；B 是数据不是参数。

图像★★

下图简化重绘自笔记图 1-2（训练集 → 学习算法 → 预测）。问号方框（中间一步）的输出是：

  1. A. 对新样本 x 的预测值 ŷ
  2. B. 学习率 α
  3. C. 成本函数的最小值 J(w, b)
  4. D. 拟合好的参数 w 和 b
显示答案与解析
答案：D

「学习算法」吃进训练集，吐出的是模型本身——即拟合好的参数（如 f(x) = 60x + 100 里的 w=60, b=100）。有了参数才有第三格：把新 x 代入 f 得到预测 ŷ。C 是训练过程中要最小化的量，不是输出；B 是训练的超参数。

计算★★

训练得到模型 f(x) = 60x + 100（x 单位：千平方英尺，f 单位：千美元）。某房面积 2.5 千平方英尺，模型预测价格是多少？

给定　w = 60, b = 100, x = 2.5
  1. A. 250 千美元
  2. B. 160 千美元
  3. C. 350 千美元
  4. D. 150 千美元
显示答案与解析
答案：A

f(2.5) = 60 × 2.5 + 100 = 150 + 100 = 250 千美元。这正是笔记图 1-2 右格的场景。常见错误：忘了加 b 得 150（选 D），或把 w 与 b 相乘。

1.4成本函数：量化「猜得多差」

概念★

平方误差成本 J(w,b) = (1/2m)·Σ(f(x⁽ⁱ⁾) − y⁽ⁱ⁾)² 中，额外除以的「2」的作用是：

  1. A. 把成本值缩小一半，防止数值过大
  2. B. 为了让 J 恒为正
  3. C. 没有作用，写不写都一样（对 argmin 而言确实无影响，但原因不是这个）
  4. D. 求导时与平方带来的因子 2 相消，让梯度公式更干净
显示答案与解析
答案：D

对 (f−y)² 求导会掉出一个 2，分母里的 2 恰好把它消掉。它不影响 argmin 的位置（C 的后半句对，但作为完整答案不对——出题人要的是「为什么」）。平方本身已保证 J ≥ 0，B 错。

概念★★

「训练一个线性回归模型」在数学上等价于：

  1. A. 找到让每个样本的残差都等于 0 的 (w, b)
  2. B. 找到最大的学习率 α 使收敛最快
  3. C. 让 J(w, b) 严格等于 0
  4. D. 求解 arg minw,b J(w, b)
显示答案与解析
答案：D

训练 = 在参数空间里最小化成本函数。A、C 都不现实：数据通常带噪声，最小 J 往往不为 0（也就没有零残差）；能完美零残差反而是过拟合的警号（第 3 章）。α 是优化的「交通工具」，不是训练目标。

图像★★

下图是 J(w, b) 的等高线俯视图（简化重绘自笔记图 1-3 右格）。下列说法正确的是：

  1. A. 同一条等高线上的不同 (w, b) 组合，成本 J 相同
  2. B. 越靠外的环 J 越小
  3. C. 圆心处的 J 最大
  4. D. 等高线只对非凸函数才存在
显示答案与解析
答案：A

等高线的定义就是「J 值相等的 (w,b) 点集」。这个碗的圆心 (w*, b*) 是全局最小（B、C 恰好说反——越外环 J 越大）。因为平方误差 J 是凸函数，等高线是套在一起的闭合曲线、只有一个底；梯度下降就是从任意起点一步步跨向圆心（见笔记图 1-5 左）。

计算★

训练集只有两个样本 (1, 2) 和 (2, 4)，取 w = 1, b = 0。成本 J = ?

给定　x = (1, 2), y = (2, 4), w = 1, b = 0, m = 2
  1. A. 1.25
  2. B. 2.5
  3. C. 5
  4. D. 0
显示答案与解析
答案：A

预测：f(1) = 1, f(2) = 2；残差平方：(1−2)² = 1，(2−4)² = 4。J = (1 + 4) / (2×2) = 5/4 = 1.25。易错：忘除 2m 得 2.5（B），或只用 m 得 5（C）。记住口诀：平方、求和、除 2m。

计算★★★

用笔记图 1-2 的训练数据 x = (1.0, 2.0, 3.0)、y = (300, 500, 700)（千美元），取 w = 200, b = 100。此时 J = ? 这说明什么？

给定　m = 3; w = 200, b = 100; x⁽ⁱ⁾ = 1, 2, 3; y⁽ⁱ⁾ = 300, 500, 700
  1. A. J = 0，说明该直线完美穿过全部 3 个训练点
  2. B. J = 100，说明拟合良好
  3. C. J = 0，说明模型在新数据上也必然完美
  4. D. J 无法计算，因为数据太少
显示答案与解析
答案：A

预测 f(x) = 200x + 100 → (300, 500, 700)，与 y 逐点相等，每个残差为 0，故 J = 0。J = 0 只保证训练集上完美，对新数据的泛化毫无承诺（C 错，这正是第 3.5 节过拟合话题的引子）。手算三个样本就够，D 是无稽之谈。

1.5梯度下降：让小球自己滚下碗

概念★

学习率 α 取得太小，会发生什么？

  1. A. 梯度下降无法收敛，永远到不了最低点
  2. B. 仍然收敛，但每步太小、速度极慢，迭代次数爆炸
  3. C. 越过最低点来回震荡、发散
  4. D. 梯度方向会变反
显示答案与解析
答案：B

α 太小 = 步子太碎：方向没错（仍在下山），只是「半天爬不到碗底」。经典陷阱：A 的「无法收敛」是错的——它只是慢。C 是 α 太大的症状。α 不改变坡度方向，D 错。

概念★★

关于「同步更新」（simultaneous update），正确的实现是：

  1. A. 先更新 w，再用新的 w 计算 b 的梯度并更新 b
  2. B. 先把 w、b 的两个梯度都算好，再用旧值一起更新两者
  3. C. 交替进行：第一轮只更新 w，第二轮只更新 b
  4. D. 先更新 b，再用新的 b 计算 w 的梯度并更新 w
显示答案与解析
答案：B

同步更新的纪律：梯度用旧值算，算完一起写。A、D 都属于「用新值算另一个参数的梯度」，会让轨迹偏离真正的梯度下降；C 是「坐标下降」的思路，不是标准做法。笔记代码里 `dj_dw, dj_db = compute_gradient(...)` 之后才执行两个赋值，就是这个纪律。

图像★★

下图简化重绘自笔记图 1-4 的中图（合适的 α）。小球逐步接近碗底时，为什么步幅会自动变小？

  1. A. 因为 α 随迭代自动衰减
  2. B. 因为接近极小值时曲线变平、导数（坡度）变小，步长 = α × 导数随之变小
  3. C. 因为梯度下降内置了停止条件
  4. D. 因为 J 的值在变小
显示答案与解析
答案：B

每步的实际位移 = α × |∂J/∂w|。α 固定不变（A 错），但碗底附近坡度趋近 0，位移自然收小——所以固定 α 也不会在碗底来回过冲。C：算法不会自己停，要靠「迭代次数」或「J 变化量」判断收敛。D：J 变小是结果不是原因，且 J 值大小与步幅无直接关系。

概念★★★

当前点处 ∂J/∂w = +2（正数）。执行一步 w := w − α·(∂J/∂w) 后（α > 0），w 与 J 的变化是：

  1. A. w 增大，沿上坡方向走
  2. B. w 不变
  3. C. w 减小，沿下坡方向走
  4. D. 无法判断，取决于 J 的绝对大小
显示答案与解析
答案：C

导数为正 = J 随 w 增大而升高（右边的坡朝上）→ 该减 w。减去 α×正数，w 变小，正是逆着上坡方向走。这就是「梯度下降 = 闭眼 downhill」：偏导指坡向，α 负导数就是下山的一步。与 J 绝对值无关，D 错。

计算★★

当前 w = 10，∂J/∂w = 2，α = 0.1。一步更新后 w = ? 若其他不变而 ∂J/∂w = −2，w 又变为多少？

给定　w = 10, ∂J/∂w = 2, α = 0.1
显示答案与解析
答案：9.8；10.2

第一种：w ← 10 − 0.1×2 = 9.8（导数为正，w 减小）。第二种：w ← 10 − 0.1×(−2) = 10 + 0.2 = 10.2（导数为负，说明坡向左下，w 反而增大）。两种情况都在下山——方向由导数符号决定，α 只管步子大小。

1.6梯度下降 × 线性回归：天作之合

概念★

为什么线性回归的梯度下降「从任意起点出发都能收敛到全局最优」？

  1. A. 因为梯度下降算法本身就保证全局最优
  2. B. 因为平方误差成本 J(w, b) 是凸函数，没有局部极小值
  3. C. 因为学习率 α 总能选到合适值
  4. D. 因为 w 和 b 只有两个参数
显示答案与解析
答案：B

功劳在成本函数的凸性，不在算法（A 反例见下一题：非凸函数上梯度下降会卡局部最优）。凸函数 = 碗形 = 局部最优必是全局最优。α 再合适，在非凸地形上也救不了你（C 错）。

图像★★

下图简化重绘自笔记图 1-5 右图（非凸损失）。两个小球从不同起点出发，最可能的结局是：

  1. A. 都到达全局最小值，只是速度不同
  2. B. 都无法收敛，来回震荡
  3. C. 可能各自停在不同的极小值（局部最优 / 全局最优）
  4. D. 取决于 α 的大小
显示答案与解析
答案：C

非凸地形有多个「坑」，梯度下降只保证滚进最近的坑——起点甲可能停在浅坑（局部极小），起点乙落在深坑（全局极小）。幸运的是线性回归的平方误差 J 是凸的，活在「只有一个坑」的世界里。D：α 影响的是步长与是否发散，不改变「就近入坑」的宿命。

概念★★

「批量」（batch）梯度下降中「批量」的含义是：

  1. A. 每一步用全部 m 个训练样本计算梯度
  2. B. 每次并行训练多个模型
  3. C. 数据要分批喂入，每批一小份
  4. D. 参数 w 和 b 要打包成向量批量更新
显示答案与解析
答案：A

batch = 每步「吃下」整个训练集求平均梯度。样本一大就得换 mini-batch（第 5 章 DQN 也会用）。C 恰好说反：mini-batch / SGD 才是分小批。B、D 是对「批量」一词的望文生义。

计算★★★

训练集 (x, y) = {(1, 1), (2, 2)}，初始 w = 0, b = 0，α = 0.1。执行一步同步更新后，新的 w 和 b 各是多少？

给定　m = 2; 样本 (1,1), (2,2); w = b = 0; α = 0.1
f(x) = w·x + b;　∂J/∂w = (1/m)Σ(f−y)·x;　∂J/∂b = (1/m)Σ(f−y)
  1. A. w = 0.25, b = 0.15
  2. B. w = 0.25, b = 0.1
  3. C. w = 0.15, b = 0.25
  4. D. w = 0.3, b = 0.3
显示答案与解析
答案：A

当前 f = (0, 0)，残差 f−y = (−1, −2)。
∂J/∂w = [(−1)(1) + (−2)(2)] / 2 = −5/2 = −2.5；∂J/∂b = [(−1) + (−2)] / 2 = −1.5。
同步更新：w ← 0 − 0.1×(−2.5) = 0.25；b ← 0 − 0.1×(−1.5) = 0.15。
易错点：若先更新 w 再用新 w 算 b 的梯度，会得到 B 一类的错值——同步更新必须两梯度都用旧值。这条题同时考了残差、加权求和与同步纪律。

2.1多元特征与向量化

概念★

多元线性回归 f(x) = w₁x₁ + w₂x₂ + … + wnxn + b 被称为「线性」回归，「线性」指的是什么？

  1. A. 每个特征 xj 只能是一次原始变量，不能变换
  2. B. 只能画成一条直线
  3. C. 输出 y 必须是线性增长的
  4. D. 模型对参数 w 是线性组合；特征本身可以先被变换（如 x²、√x）
显示答案与解析
答案：D

「线性」约束的是参数：f 是 w₁…wn 的线性组合。特征可以随便造（2.4 节的多项式回归正是把 x²、x³ 当新特征），所以 B 错——x 对 y 的曲线关系照样能拟合。这也是「多项式回归本质仍是线性回归」的原因。

概念★★

课程实验中，np.dot(w, x) 比等价的 Python for 循环快 1~2 个数量级，根本原因是：

  1. A. NumPy 的代码行数更少，解释器负担小
  2. B. NumPy 底层用 SIMD / BLAS 把点积交给并行硬件计算
  3. C. for 循环算的结果精度较低
  4. D. np.dot 会自动调用 GPU
显示答案与解析
答案：B

向量化的双重收益 = 代码少 + 速度快，而速度来自底层并行（CPU 的 SIMD 指令 / BLAS 库；GPU 上差距更大）。A 把次要原因当主因；C 无稽之谈，结果完全一致；D 不是自动的——GPU 要显式用 TensorFlow 之类的框架（第 4 章）。

图像★★

下图简化重绘自笔记图 2-1。两段代码算的是同一个点积，运行时间条却差一个数量级。这个对比主要想说明：

  1. A. 能写成张量运算的，永远不要写 Python 循环
  2. B. for 循环的结果是错的
  3. C. np.dot 采用了近似算法，牺牲精度换速度
  4. D. n 越小，向量化优势越明显
显示答案与解析
答案：A

工程铁律：两种写法结果完全一致（B、C 错），差别只在速度；且维度越高、规模越大，向量化优势越大（D 说反）。第 4 章神经网络全部用矩阵乘法书写，正是这条铁律的延伸——GPU 只会两件事：矩阵乘与逐元素非线性。

计算★

w = (3, 2, 1)，b = 4，某样本特征 x = (2, 1, 3)。模型预测 f(x) = w·x + b = ?

给定　w = (3, 2, 1), b = 4, x = (2, 1, 3)
  1. A. 11
  2. B. 15
  3. C. 12
  4. D. 19
显示答案与解析
答案：B

f = 3×2 + 2×1 + 1×3 + 4 = 6 + 2 + 3 + 4 = 15。点积逐项相乘再求和，最后加偏置 b。忘加 b 得 11（A）；漏乘某项得 12（C）；把 b 当成乘 4 得 19（D）。

2.2多元梯度下降

概念★

从单变量到多变量，梯度下降更新规则的实质变化是：

  1. A. 算法框架变了，要换成另一种优化器
  2. B. 学习率 α 必须随特征数 n 等比例增大
  3. C. 公式形式不变，只是 w 变成向量：每个 wj 一条同构的更新式
  4. D. 偏导数不再需要计算
显示答案与解析
答案：C

「多元」与「一元」只差一个维度：wj := wj − α·(1/m)Σ(f−y)·xj⁽ⁱ⁾，j = 1…n，逐维同构。写成矩阵后 dj_dw = X.T @ err / m 一行算完全部偏导。框架不动、只换模型函数——这个「换皮不换骨」的模式后面还会在逻辑回归、神经网络反复出现。

概念★★

向量化实现中 dj_dw = X.T @ err / m（X 为 m×n 矩阵，err 为 m 维残差向量）。这一行矩阵乘法算出的是：

  1. A. m 个样本各自的预测误差
  2. B. 全部 n 个参数各自的偏导数 ∂J/∂wj
  3. C. 成本函数的当前值 J
  4. D. 新的参数向量 w
显示答案与解析
答案：B

X.T 是 n×m，与 m 维 err 相乘得 n 维向量——恰好每个分量是一个参数的偏导（维度检查：(n×m)·(m×1) = (n×1)）。A 是 err 本身；C 要用 err 的平方和；D 还需再乘 α 做更新。这是「维度消失了，公式不再随 n 膨胀」的具体体现。

计算★★★

两个训练样本：x⁽¹⁾ = (1, 2), y⁽¹⁾ = 3；x⁽²⁾ = (2, 1), y⁽²⁾ = 3。当前参数 w = (1, 1), b = 0。求两个偏导 ∂J/∂w₁、∂J/∂w₂ 与 ∂J/∂b，并说明这意味着什么。

给定　m = 2; f(x) = w·x + b; w = (1,1), b = 0
显示答案与解析
答案：三个偏导全为 0 —— 已处于成本函数的驻点（不动点）

f⁽¹⁾ = 1×1 + 1×2 + 0 = 3 = y⁽¹⁾；f⁽²⁾ = 1×2 + 1×1 + 0 = 3 = y⁽²⁾。残差全为 0 → ∂J/∂w₁ = ∂J/∂w₂ = ∂J/∂b = 0。梯度全零意味着梯度下降原地不动：这个 (w, b) 已是（至少局部的）最优解——两条样本恰好被 y = x₁ + x₂ 完美拟合，J = 0。

2.3特征缩放与学习率

概念★

面积 x₁ ∈ [300, 3500] 与卧室数 x₂ ∈ [1, 5] 相差三个数量级时，梯度下降收敛极慢。原因是：

  1. A. 大特征会覆盖小特征的信息，模型学不到卧室数
  2. B. 计算机无法存储这么大的数字
  3. C. 学习率会自动变大导致发散
  4. D. 成本函数等高线被拉成又扁又长的峡谷，梯度下降在峡谷里反复弹跳
显示答案与解析
答案：D

量纲悬殊 → 碗被压扁成峡谷：w₁ 稍动 J 就剧变、w₂ 怎么动都无所谓 → 只能贴着峡谷壁小步弹跳。A 是误解：信息并没丢，各特征对模型的贡献由 w 调节，慢的只是优化路径。缩放改变的是「到达最优解的效率」，不改变最优解本身。

概念★

z-score 标准化（首选的缩放方法）的公式是：

  1. A. x ÷ max(x)
  2. B. (x − μ) ÷ (max − min)
  3. C. (x − μ) ÷ σ
  4. D. x × σ + μ
显示答案与解析
答案：C

z-score：减均值、除标准差，缩放后约 68% 样本落在 [−1, 0]，95% 落在 [−2, 2]。A 是「除以最大值」（最简单）、B 是均值归一化——都可用，但 z-score 是课程首选。D 是「反标准化」（预测还原原量纲时会用到类似操作）。

概念★★★

关于缩放参数 μj、σj 的来源与使用，正确做法是：

  1. A. 每次处理新数据时，都用新数据重新计算 μ、σ
  2. B. 只从训练集统计 μ、σ；验证 / 测试 / 线上新数据一律用同一套参数变换
  3. C. 从全部数据（含测试集）统计，信息更充分
  4. D. μ、σ 由用户手工指定为 0 和 1
显示答案与解析
答案：B

μ、σ 属于「从训练集学到的预处理参数」：训练时算一次，之后同一套参数处理所有数据（sklearn 的 `scaler.transform(X_new)` 正是如此）。A 会让不同批次数据处于不同坐标系；C 造成测试集信息泄露；D 无意义。这是新手榜一大坑：训练时标准化、预测时忘标准化。

图像★★

下图简化重绘自笔记图 2-2：左右两幅是同一成本函数缩放前后的等高线。左右两图的关系是：

  1. A. 缩放改变了最优解 (w*, b*) 的位置，所以收敛更快
  2. B. 缩放后不再需要梯度下降，可以直接读出最优解
  3. C. 缩放不改变问题的最优解，只改变梯度下降到达它的效率
  4. D. 左图更快，因为路径更短
显示答案与解析
答案：C

缩放是坐标系的「整形手术」：碗还是那个碗（最优解对应的模型不变），只是从峡谷整成了圆碗，下降路径变短变直。注意缩放后得到的 w 是在新坐标系下的，预测新样本时要用同一套 μ、σ 先变换再代入（呼应上题）。

  1. A. 学习率 α 过大 —— 缩小 α（例如 ÷3~÷10）重试
  2. B. 学习率 α 过小 —— 加大 α
  3. C. 特征缩放做错了
  4. D. 已经收敛，可以停止训练

α 过大 → 每步跨过碗底、越荡越高甚至发散（数值溢出 / NaN），处方是缩 3~10 倍重试。③ 才是 α 太小（B）。实践套路：α 从 0.001 起，×3 步进（0.003 → 0.01 → 0.03 …）直到 J 开始「翻脸」，退回上一档。C：缩放问题通常表现为「慢」而非「震荡升高」。

计算★

某特征训练集均值 μ = 100、标准差 σ = 20。用 z-score 标准化：x = 130 变换后是多少？x = 80 呢？

答案：130 → +1.5；80 → −1

(130 − 100) / 20 = 1.5（高出均值 1.5 个标准差）；(80 − 100) / 20 = −1。变换后特征大致落在 [−1, 1] 附近，两个不同量纲的特征从此在同一坐标系里公平竞争。

2.4特征工程与多项式回归

概念★

「特征工程」（feature engineering）指的是：

  1. A. 用领域知识把已有特征组合出新特征（如 长 × 宽 = 面积），再喂给模型
  2. B. 给特征做 z-score 标准化
  3. C. 删除取值异常的特征
  4. D. 用神经网络自动提取特征
显示答案与解析
答案：A

特征工程 = 人类出手「造变量」：长 × 宽 = 面积，一进模型直线立刻更贴合现实。B 是特征缩放（2.3）；C 是数据清洗；D 是神经网络自动学特征（4.3「特征再发明」）——恰好是特征工程的自动化对手。

概念★★

f(x) = w₁x + w₂x² + w₃x³ + b 属于多项式回归。它仍能用「线性回归 + 梯度下降」求解，原因是：

  1. A. 梯度下降不关心模型长什么样
  2. B. 多项式的次数通常不高，可以暴力搜索最优解
  3. C. x² 和 x³ 可以近似忽略
  4. D. x²、x³ 只是三个新特征，f 对参数 w₁、w₂、w₃ 依然是线性组合
显示答案与解析
答案：D

3.1动机与 Sigmoid 模型

概念★

「逻辑回归」（Logistic Regression）这个名字里的「回归」常常误导初学者。它实际解决的问题类型是：

  1. A. 连续值预测（回归）
  2. B. 聚类
  3. C. 二分类（输出 0/1 或概率）
  4. D. 强化学习
显示答案与解析
答案：C

名字是历史遗留（它「回归」了一个概率值），干的却是分类的活：f(x) = sigmoid(w·x+b) = P(y=1|x)。这是官方测验最爱的送分陷阱——见到「预测肿瘤良性/恶性」「判断是否垃圾邮件」，一律逻辑回归。

概念★★

为什么不用线性回归直接做分类（拟合直线、取 0.5 处为分界）？笔记给出的两个「致命伤」是：

  1. A. 训练太慢 + 无法处理多特征
  2. B. 输出可越界（<0 或 >1）+ 一个极端样本就能把分界线拖跑
  3. C. 成本函数不凸 + 梯度下降发散
  4. D. 概率没有意义 + 必须用 GPU
显示答案与解析
答案：B

两个致命伤：① 直线输出可以跑出 (0,1) 区间，当概率没有意义；② 一个良性的超大肿瘤样本就能把分界线硬拖进恶性区（笔记图 3-1 左）。sigmoid 的 S 形把输出压进 (0,1)，天然当概率用。C 是「平方误差套 sigmoid」的问题（3.3 节），不是线性回归做分类的问题——层次别混。

图像★★

下图是 sigmoid 函数 g(z) = 1/(1+e⁻ᶻ) 的图像（简化重绘自笔记图 3-1 右）。观察图像，g(0)、z→+∞、z→−∞ 的取值分别是：

  1. A. 0；1；1
  2. B. 0.5；0；1
  3. C. 0.5；1；0
  4. D. 1；0.5；0
显示答案与解析
答案：C

g(0) = 1/(1+e⁰) = 0.5（曲线正中央，也是决策的默认门槛）；z→+∞ 时 e⁻ᶻ→0，g→1；z→−∞ 时 e⁻ᶻ→∞，g→0。S 形 + 值域 (0,1)，让它天然输出概率。

计算★★

（1）g(0) = ?（2）利用 e⁻⁴ ≈ 0.018，计算 g(4) ≈ ?（3）g(−4) ≈ ?

给定　g(z) = 1 / (1 + e⁻ᶻ)；e⁻⁴ ≈ 0.018
显示答案与解析
答案：0.5；约 0.982；约 0.018

（1）g(0) = 1/(1+1) = 0.5。（2）g(4) = 1/(1+0.018) ≈ 0.982。（3）g(−4) = 1/(1+e⁴) = e⁻⁴/(1+e⁻⁴) ≈ 0.018/1.018 ≈ 0.018。也可用对称性：g(−z) = 1 − g(z)，所以 g(−4) = 1 − 0.982 = 0.018。z=±4 时输出已接近 0/1——离边界越远，模型越自信。

3.2决策边界

概念★

逻辑回归的「决策边界」（decision boundary）在数学上是：

  1. A. sigmoid 曲线本身
  2. B. 训练集中两类样本的分隔线
  3. C. 成本函数 J 的等高线
  4. D. 让 g(z) = 0.5 的点的集合，即 z = w·x + b = 0
显示答案与解析
答案：D

预测规则：g(z) ≥ 0.5 ⇔ z ≥ 0 时判 1。两类预测的分界发生在 z = 0 处，所以边界 = {x : w·x + b = 0}，是参数与特征共同决定的模型属性，不是数据的属性（B 说的是「希望它分开什么」，不是「它是什么」）。

概念★★

模型预测 ŷ = 1 的充要条件（默认阈值 0.5）是：

  1. A. f(x) > 0 且 w·x + b > 1
  2. B. f(x) ≥ 0.5，等价于 w·x + b ≥ 0
  3. C. f(x) ≥ 0.5，等价于 w·x + b ≥ 0.5
  4. D. f(x) > 1
显示答案与 解析
答案：B

sigmoid 在 z=0 处取 0.5 且单调，所以 f ≥ 0.5 ⇔ z = w·x+b ≥ 0。C 是最常见的错误：把 0.5 的门槛从「概率空间」错搬到「z 空间」。

图像★★

下图简化重绘自笔记图 3-2 右：手工加入 x₁²、x₂² 特征后，逻辑回归画出的边界是：

  1. A. 任意复杂形状的边界
  2. B. 只能是水平或竖直的直线
  3. C. 圆或椭圆 —— 这也是它能力的天花板；任意复杂边界要交给神经网络
  4. D. 没有边界，因为特征取了平方
显示答案与解析
答案：C

取平方特征后 z = w₁x₁² + w₂x₂² + b，z=0 即 w₁x₁² + w₂x₂² = −b，是二次曲线（典型为圆/椭圆）。想拼出任意形状（异或、圆环、猫脸），要靠隐藏层自动组合特征——第 4 章「每个隐藏神经元画一条小边界，输出层再组合」。

计算★★

参数 w₁ = 1, w₂ = 1, b = −3。（1）写出决策边界方程；（2）边界与两条坐标轴的交点是？

给定　z = x₁ + x₂ − 3
显示答案与解析
答案：（1）x₁ + x₂ = 3；（2）(3, 0) 与 (0, 3)

令 z = 0：x₁ + x₂ − 3 = 0 → x₁ + x₂ = 3，一条斜率 −1 的直线。令 x₂=0 得 x₁=3，令 x₁=0 得 x₂=3。边界上任意点 z=0 → g=0.5，恰在「最犹豫」处。

计算★★★

承上题参数（z = x₁ + x₂ − 3）：点 P(1, 1) 与点 Q(2, 2) 分别被判为哪一类？各自的预测概率约是多少？

给定　g(−1) ≈ 0.27, g(1) ≈ 0.73
  1. A. 都判 0，因为 x₁、x₂ 都小于 3
  2. B. P 判 1（概率≈0.73），Q 判 0（概率≈0.27）
  3. C. 都判 1，因为概率都大于 0
  4. D. P 判 0（概率≈0.27），Q 判 1（概率≈0.73）
显示答案与解析
答案：D

P：z = 1+1−3 = −1 < 0 → 判 0，f = g(−1) ≈ 0.27；Q：z = 2+2−3 = +1 → 判 1，f = g(1) ≈ 0.73。要点：判断只看 z 的符号（等价 f 与 0.5 比），概率告诉你模型多自信。A 是把坐标值与边界方程混为一谈的典型错误。

3.3成本函数：交叉熵登场

概念★★

逻辑回归为什么不沿用线性回归的平方误差成本？

  1. A. 因为平方误差算出来可能为负数
  2. B. 因为 sigmoid 的弯曲使 J(w,b) 变成非凸函数，梯度下降会卡在局部最优
  3. C. 因为平方误差对分类问题来说计算太慢
  4. D. 因为 sklearn 不支持平方误差
显示答案与解析
答案：B

把平方误差直接套在弯曲的 sigmoid 上，J 的地形从「一个碗」变成「群山连绵」（非凸）——起点不好就滚进局部极小。换成对数损失 / 交叉熵后 J 恢复凸性，且「赏罚分明」。A：平方项恒非负；C、D 均非本质原因。

概念★★

交叉熵损失「赏罚分明」的含义是：

  1. A. 预测错误的样本一律罚 1 分
  2. B. 押对且自信（f 靠近真实 y）几乎不罚；押错且自信则罚到天文数字
  3. C. 损失永远不超过 1
  4. D. 对每个类别的惩罚力度相同
显示答案与解析
答案：B

一行话记住：Loss = −log(你押在正确答案上的概率)。押 90% 正确只罚 −log 0.9 ≈ 0.105；押 1% 在错误方向罚 −log 0.01 ≈ 4.6——错得越自信，罚得越指数（−log 在 0 附近趋于 ∞，C 错）。凸性是选它而非平方误差的根本原因，赏罚分明是它的性格红利。

图像★★

下图简化重绘自笔记图 3-3：两条单样本损失曲线。关于这两条曲线，正确的读图结论是：

  1. A. 真实 y=1 时，f 越接近 1 损失越接近 0；f 趋向 0 时损失趋向无穷
  2. B. 两条曲线在 f=0.5 处损失最大
  3. C. 真实 y=0 时，f 越大损失越小
  4. D. 损失最大不超过 1
显示答案与解析
答案：A

红曲线（y=1）从左上（f→0, L→∞）一路降到右下（f→1, L→0）；蓝曲线（y=0）恰好镜像。B：f=0.5 处损失约 0.693，是「最犹豫」但远非最大；C 说反——y=0 时 f 越大错得越狠；D：−log 在 0 附近无上界。

计算★★

真实标签 y = 1。（1）模型预测 f = 0.9，损失 = ?（2）若模型把方向押反，f = 0.01，损失 = ?（ln 0.9 ≈ −0.105, ln 0.01 ≈ −4.6）

给定　y = 1; L = −log(f)；ln 0.9 ≈ −0.105, ln 0.01 ≈ −4.6
显示答案与解析
答案：（1）0.105；（2）4.6

（1）L = −log 0.9 ≈ 0.105——押对且自信，几乎不罚。（2）L = −log 0.01 ≈ 4.6——押错且自信，罚金是上一问的 44 倍。这就是「错得越自信，罚得越指数」的数值版本。

计算★★★

同一个预测 f = 0.9：（1）若真实 y = 1，损失 = ?（2）若真实 y = 0，损失 = ?（ln 0.1 ≈ −2.303）（3）这说明交叉熵的什么性质？

给定　L = −y·log(f) − (1−y)·log(1−f)；ln 0.9 ≈ −0.105, ln 0.1 ≈ −2.303
显示答案与解析
答案：（1）0.105；（2）2.303；（3）损失取决于「押在正确答案上的概率」，同一个预测对错两判、赏罚悬殊

（1）y=1：L = −log 0.9 ≈ 0.105。（2）y=0：L = −log(1−0.9) = −log 0.1 ≈ 2.303。同一句「我预测 0.9」，真值不同命运天差地别——因为损失永远在数「你给正确答案分配了多少概率」。这个视角到 5.3 节 softmax 的多类交叉熵原样放大。

3.4梯度下降：熟悉的公式再现

概念★★

逻辑回归的梯度更新式 wj := wj − α·(1/m)Σ(f−y)·xj 与线性回归「逐字相同」。两者的全部区别在于：

  1. A. 学习率 α 的取法不同
  2. B. 逻辑回归不需要同步更新
  3. C. f 的定义不同：线性回归 f = w·x+b，逻辑回归 f = sigmoid(w·x+b)
  4. D. 逻辑回归要用 Adam 优化器
显示答案与解析
答案：C

求导时 sigmoid 的导数 g′ = g(1−g) 恰好被对数损失消掉，剩下的更新式与线性回归同形——唯一的差别是残差里的 f 要先过 sigmoid。这正是课程先教线性回归的深意：梯度下降框架不动，只换模型函数，将来换成神经网络同样成立。

概念★

训练好的模型对某封邮件输出 f(x) = 0.7。按默认规则，预测类别与模型给出的「垃圾邮件概率」分别是：

  1. A. 类别 1（垃圾），概率 0.7
  2. B. 类别 0（正常），概率 0.7
  3. C. 类别 1（垃圾），概率 0.3
  4. D. 无法判断，需要再训练
显示答案与解析
答案：A

f ≥ 0.5 → 判 1；而 f 本身就是 P(y=1|x) 的估计，即 70% 概率是垃圾邮件。0.3 是「正常邮件」的互补概率（C 的说法把类别与概率配错了对）。代码里 `sigmoid(X@w+b) >= 0.5` 一行完成两件事。

计算★★

某样本真实 y = 1，当前模型预测 f = 0.8。（1）残差 (f − y) = ?（2）∂J/∂wj 中与该样本相关的项 (f−y)·xj 当 xj = 2 时的符号与值？（3）这一步更新会让 wj 增大还是减小？

给定　y = 1, f = 0.8, xj = 2
显示答案与解析
答案：（1）−0.2；（2）−0.4；（3）增大

（1）f − y = 0.8 − 1 = −0.2（预测不足）。（2）(f−y)·xj = −0.2×2 = −0.4。（3）wj ← wj − α×(−0.4) = wj + 0.4α → 增大。直觉：预测 0.8 还不够自信（真值是 1），加大 wj 让 z 变大、f 更靠近 1。残差的符号自动指明「该加还是该减」——这就是 (f−y) 这一项的全部人格。

3.5过拟合问题

概念★

「过拟合」（overfitting / high variance）的典型症状是：

  1. A. 训练误差极低，新数据上一塌糊涂
  2. B. 训练误差就很高，新数据上也差
  3. C. 训练误差和验证误差都很低且接近
  4. D. 模型收敛太慢
显示答案与解析
答案：A

过拟合 = 模型把训练集的噪声也当规律背了下来——训练集满分选手、考场翻车。B 是欠拟合（high bias）；C 是理想状态；D 是优化问题不是拟合问题。术语对照要背熟：过拟合 = high variance，欠拟合 = high bias（第 6 章诊断的主角）。

图像★★

下图简化重绘自笔记图 3-4 的三联图。三张图的诊断从左到右是：

  1. A. 三张都是过拟合，程度不同
  2. B. 过拟合、恰好、欠拟合
  3. C. 恰好、欠拟合、过拟合
  4. D. 欠拟合（高偏差）、恰好、过拟合（高方差）
显示答案与解析
答案：D

图①直线压不住数据的弯曲 → 欠拟合（模型太笨，连训练集规律都没学会）；图②平滑曲线穿过趋势 → 恰好；图③七拐八绕穿过每个点 → 过拟合（把噪声也背了）。分类问题同理：过拟合的决策边界会「绕着每个点画迷宫」。

概念★★

笔记给出应对过拟合的三条对策，其中「本课主角」是：

  1. A. 收集更多训练数据（稀释噪声）
  2. B. 只用最相关的特征（特征选择，砍掉噪声养料）
  3. C. 正则化 —— 特征不删、参数还在，只是被按住不许变大
  4. D. 换一个更小的学习率
显示答案与解析
答案：C

A、B、C 都是正解对策，但吴恩达明确说正则化是本课主角（3.6 节整节）：不动特征、不删数据，只在成本里加「罚款」——它对神经网络这种特征没法手动删的模型尤其关键。D：α 只影响优化速度与稳定性，不改变模型复杂度，治不了过拟合。

3.6正则化：给参数戴上镣铐

概念★

正则化成本 J = 原成本 + (λ/2m)·Σwj² 中，λ 的角色是：

  1. A. 学习率，控制每步走多远
  2. B. 特征数量
  3. C. 训练样本数
  4. D. 罚款力度：λ 越大，参数被压得越小、模型越平滑
显示答案与解析
答案：D

λ 是「罚款力度」旋钮：λ 越大，Σw² 的罚款越疼，最优解里参数越小、曲线越不敢扭。记住分工口诀：α 管每步多大（方向与步长），λ 管参数允许长多大（体格）——一个管走法、一个管身材。调法与 α 一样按数量级扫描（0.01, 0.1, 1, 10, 100 …），用验证集选。

概念★★

正则项 Σwj² 中 j 从 1 到 n，不包含偏置 b。课程给出的理由是：

  1. A. b 的值通常比 w 小得多，罚不罚无所谓
  2. B. b 只做平移、不放大特征，惩罚它没有实际意义（惯例上不罚）
  3. C. 罚 b 会让成本函数变成非凸
  4. D. b 不是学习出来的参数
显示答案与解析
答案：B

过拟合的元凶是「巨大的参数扭动高次曲线」——那放大特征的一族，正是 w。b 只是上下平移，不参与放大，惯例不罚（有的教材罚 b，实践影响不大）。C：加 b² 不破坏凸性；D：b 也是学习出来的参数，只是不进罚款单。

图像★★

下图简化重绘自笔记图 3-5：同一数据、同一个模型族，只有 λ 不同。从左到右三张图的演变说明：

计算★★

正则化线性回归：m = 2，两个样本的残差平方和 Σ(f−y)² = 4，参数 w = (3, 4)，λ = 2。总成本 J = ?

  1. A. 13.5

  3. C. 2

显示答案与解析
答案：A

正则化更新式可改写为 wj := wj(1 − αλ/m) − α·(1/m)Σ(f−y)xj。取 λ = 1, m = 2, α = 0.1。（1）缩水因子 (1 − αλ/m) = ?（2）它每一轮迭代都对 wj 做什么？（3）为什么说正则化「软化」而非「删除」参数？

给定　λ = 1, m = 2, α = 0.1
显示答案与解析
答案：（1）0.95；（2）每轮先把 wj 乘 0.95（缩小 5%），再沿梯度走；（3）参数只是被持续压小、永不强制归零

（1）1 − (0.1×1)/2 = 0.95。（2）每一步更新 = 「先缩水、再下山」：wj ← 0.95·wj − α·梯度。（3）缩水因子 > 0，w 只是渐近变小，没有任何参数被硬性删掉——对比特征选择「一刀砍掉」，正则化是「给每个参数戴镣铐」。λ 越大缩水越狠，这就是 λ 控制模型复杂度的微观机制。

4.1神经元与大脑

概念★

笔记把「人工神经元」一步还原成你已经会的东西——它数学上就是：

  1. A. 一个带参数的线性回归：f = w·x + b
  2. B. 一个 K-means 中心
  3. C. 一棵单结点决策树
  4. D. 一个带参数的逻辑回归：a = g(w·x + b)，g 通常为 sigmoid
显示答案与解析
答案：D

神经元 = 加总（胞体）+ 阈值放电（轴突）→ 数学化就是 z = w·x + b、a = g(z)。1943 年 McCulloch–Pitts 的抽象到今天没变。A 少了非线性 g（那就成了线性回归）；「激活值 a」这个词专指神经元的输出。

概念★★

需求预测（T 恤会不会畅销）例子里，笔记刻意引入了「价格感知」「购买欲」这类中间概念。在神经网络里，它们对应：

  1. A. 输入特征 x
  2. B. 输出层的预测 ŷ
  3. C. 隐藏层的激活值 a⁽¹⁾
  4. D. 人工标注的标签 y
显示答案与解析
答案：C

与其从原始特征直接瞎猜，不如先算「价格感知」这类更有用的中间量——这正是隐藏层激活值的角色。注意：这些概念没有人标注正确答案（所以叫「隐藏」层），它们是网络自己学出来的。

图像★★

下图简化重绘自笔记图 4-1 的需求预测网络。看图回答：① 输入特征有几个？② a₁⁽¹⁾、a₂⁽¹⁾ 是哪一层的输出？③ 最右侧的 a⁽²⁾ 是什么？

  1. A. ① 4 个；② 隐藏层（第一层）；③ 输出层的激活值 = 预测 ŷ
  2. B. ① 2 个；② 输出层；③ 隐藏层的中转值
  3. C. ① 4 个；② 输出层；③ 隐藏层学到的中间概念

4.2网络模型：层、层、层

概念★

笔记对「一层」的严格定义是：

  1. A. 任意若干神经元，各自随便吃不同的输入
  2. B. 一排神经元，各自有自己的 (w, b)，但吃同一个输入向量，共同输出激活向量 a⁽ˡ⁾ = g(W⁽ˡ⁾a⁽ˡ⁻¹⁾ + b⁽ˡ⁾)
  3. C. 只要有 sigmoid 就算一层
  4. D. 一层 = 一次前向传播的全过程
显示答案与解析
答案：B

「吃同一个输入、各自算各自的」是层的关键——所以一层才能写成一个矩阵乘法（4.6 节）。A 的描述对应「各自为战」，不是层；网络 = 层的串联，上一层的输出 a⁽ˡ⁻¹⁾ 即下一层的输入。

概念★★

逻辑回归只能画一条（直）边界，神经网络却能拼出异或、圆环、猫脸等任意形状边界。笔记给出的机制解释是：

  1. A. 隐藏层的神经元数总是足够多，暴力穷举所有区域
  2. B. 每个隐藏神经元先各自画一条小边界，输出层再把它们「与 / 或」组合起来
  3. C. sigmoid 的曲线天然弯曲，所以边界可以弯
  4. D. 梯度下降会把直线边界掰弯
显示答案与解析
答案：B

每个隐藏神经元本质上是一个小逻辑回归（一条自己的边界），输出层拿这些 0/1 激活做逻辑组合——线性不可分的问题在「中间概念」的新坐标系里就分开了。C 是常见误解：单个 sigmoid 神经元的决策边界仍是 z=0 的直线/平面，弯的是激活曲面，不是边界。

图像★★

下图是一个「3 – 4 – 4 – 1」的网络（简化重绘）。按课程惯例，它被称为几层网络？其中隐藏层几个？

  1. A. 4 层网络，其中隐藏层 3 个
  2. B. 4 层网络，其中隐藏层 2 个
  3. C. 3 层网络，其中隐藏层 2 个
  4. D. 5 层网络，因为输入层也要数
显示答案与解析
答案：C

课程惯例：「N 层网络」= 有权重可学的层数 = 隐藏层 + 输出层；输入层 a⁽⁰⁾ 只是数据入口，不计。图中 2 列隐藏（各 4 单元）+ 1 个输出 = 3 层网络。口诀：数「3 – 4 – 4 – 1」里除第一个外的所有数字。若有人把它叫 4 层，那是把输入层也算进去了——考试按课程惯例来。

计算★★

4.3前向传播

概念★

「前向传播」的「前向」是什么意思？

  1. A. 向前看：预测未来时间步
  2. B. 信息从输入流向输出：逐层计算 a⁽¹⁾ → a⁽²⁾ → … → ŷ
  3. C. 先算输出层再算隐藏层
  4. D. 梯度从输出流回输入
显示答案与解析
答案：B

「传播」= 信息在网络里流动，「前向」= 从输入到输出。D 说的是反向传播（5.5 节，算梯度用），方向恰好相反。前向传播只做一件事：a⁽ˡ⁾ = g(W⁽ˡ⁾a⁽ˡ⁻¹⁾ + b⁽ˡ⁾) 一层层套下去。

计算★★

单神经元（sigmoid 激活）：w = [2, 1]，b = 1，输入 x = [1, 2]。求激活值 a = g(w·x + b)。（e⁻⁵ ≈ 0.0067）

给定　z = w·x + b；a = 1/(1+e⁻ᶻ)；e⁻⁵ ≈ 0.0067
显示答案与解析
答案：z = 5，a ≈ 0.993

z = 2×1 + 1×2 + 1 = 5；a = 1/(1+0.0067) ≈ 0.993。z 离 0 越远，输出越贴近 0 或 1——这个神经元对当前输入「非常确定地放电」。

计算★★★

两层网络（1 → 2 → 1，全部 sigmoid）。输入 x = 1。隐藏层：单元 1 的 w = 1、b = −1；单元 2 的 w = 1、b = 0。输出层：w = [1, 1]、b = 0。求最终 ŷ。

给定　g(0) = 0.5；g(1) ≈ 0.731；g(1.231) ≈ 0.774
显示答案与解析
答案：a₁⁽¹⁾ = 0.5，a₂⁽¹⁾ ≈ 0.731，ŷ ≈ 0.774

逐层算：z₁ = 1×1 − 1 = 0 → a₁⁽¹⁾ = 0.5；z₂ = 1×1 + 0 = 1 → a₂⁽¹⁾ = 0.731。输出层：z = 1×0.5 + 1×0.731 + 0 = 1.231 → ŷ = g(1.231) ≈ 0.774。这就是前向传播的全部：每层「乘、加、压」三连。数值不必背，套路必须熟。

概念★

用 tf.Sequential 做推理（暂时不训练），笔记总结的三步是：

  1. A. 归一化 → 训练 → 导出
  2. B. 搭网络（Sequential([...]) → compile → predict
  3. C. predict → fit → evaluate
  4. D. 定义损失 → 求梯度 → 更新参数
显示答案与解析
答案：B

D 是手写梯度下降的三动作，TF 把它们藏进 compile/fit（第 5 章）。本节只要推理：Sequential 声明结构 → compile 声明损失 → predict 出结果。训练细节（fit 的解剖）是 Week 2 的内容。

概念★★

笔记「深坑」提醒：烤咖啡豆实验里温度 175~260℃、时长 12~15 分钟的原始数据，必须先做什么再 fit？为什么？

  1. A. 先 shuffle——否则梯度顺序错乱
  2. B. 先 one-hot——温度是类别特征
  3. C. 先 z-score 归一化——特征数值太大，不归一化训练慢到怀疑人生（梯度下降要迭代很多轮才能把 w 压到合适尺度）

与 2.3 节同理：特征尺度悬殊 → 等高线变成细长椭圆 → 梯度下降绕远路。z-score 归一化（x−μ)/σ 把两维都拉回 ±2 左右，网络立刻好训。这是贯穿全课程的工程铁律。

TF 中数据按「行堆叠」：X 的第 i 行是第 i 个样本的特征向量。烤咖啡豆数据集有 200 个样本、2 个特征（温度、时长），网络输出层 1 个单元。（1）X 的形状？（2）model.predict(X) 输出的形状？

显示答案与解析
答案：（1）(200, 2)；（2）(200, 1)

X 是 (200, 2)；一次矩阵化前向传播算完全部 200 个样本，输出 (200, 1)——每行一个「烤得好」的概率。「并行是矩阵乘法的免费赠品」：不必写 for 循环逐样本 predict。

4.6向量化与矩阵乘法

概念★

矩阵乘法的「维度检查」规则是：

  1. A. (m×n)·(n×u) = (m×u)：内维必须相等，外维成为结果形状
  2. B. (m×n)·(u×n) = (m×n)：行数必须相等
  3. C. 任意两个矩阵都能相乘，形状取较大者
  4. D. (m×n)·(n×u) = (n×n)
显示答案与解析
答案：A

「内维相等才能乘，外维成为结果」是写网络代码的编译器——shape 对了，代码基本就对了。笔记：GPU 只会两件事（矩阵乘 + 逐元素非线性），深度学习的全部算力都烧在这里。

图像★★

下图重绘自笔记图 4-2 的「维度守恒律」。若 A 是 (5×3)、B 是 (3×7)，AB 的形状是？

  1. A. 5 × 7
  2. B. 3 × 3
  3. C. 5 × 3
  4. D. 无法相乘
显示答案与解析
答案：A

内维 3 = 3 ✓，外维 5 和 7 落下来 → (5×7)。心算口诀：「吃掉内维，留下外维」。若内维不等（如 (5×3)·(5×3)），直接报错——先查 shape 再 debug，能省一半时间。

计算★★

判断以下乘法哪些合法，合法的写出结果形状：① (4×3)·(3×2)；② (2×3)·(2×3)；③ (200×2)·(2×3)。

显示答案与解析
答案：① (4×2)；② 不合法；③ (200×3)

① 内维 3=3 → (4×2)。② 内维 3≠2 → 不合法（常见于把 W 用错转置——TF 与课程板书的 W 互为转置，读代码先 get_weights()[0].shape）。③ 内维 2=2 → (200×3)：一批 200 个样本同时过一层 3 单元的网络。

计算★★★

A 是 3×2 的全 1 矩阵，B 是 2×4 的全 1 矩阵，C = AB。（1）C 的形状？（2）C 的每个元素是多少？（3）C 一共有多少个非零元素？

显示答案与解析
答案：（1）3×4；（2）2；（3）12

（1）(3×2)·(2×4) → 3×4。（2）每个元素 = 对应行·列的内积，长度 2 的全 1 点积 = 2。（3）3×4 = 12 个，全是 2。小矩阵手算一遍，矩阵乘「行乘列、求和」的手感就有了——4.5 的 a_in @ W 就是这个操作批量版。

5.1TensorFlow 训练三部曲

概念★

手写梯度下降的三个动作「算损失、求梯度、更新参数」，在 TF 里被固化成一条流水线。正确的对应关系是：

  1. A. 定义 f(x;w,b) ↔ model.compile；J(w,b) ↔ Sequential；更新参数 ↔ predict
  2. B. 定义 f ↔ fit；J ↔ predict；更新 ↔ compile
  3. C. 定义 f ↔ Sequential([...])；J ↔ compile(loss=...)；更新 ↔ fit(X, y, epochs)
  4. D. 三者顺序无关，随意搭配
显示答案与解析
答案：C

Sequential 声明结构与参数；compile 选损失函数（决定「学什么」）与优化器；fit 里框架自动「前向 → 算损失 → 反向传播求梯度 → 优化器更新」循环 epochs 遍。手写三动作一个不少，只是被 API 藏起来了。

概念★★

model.fit(X, Y, epochs=100) 里的 1 个 epoch 指：

  1. A. 更新 100 次参数
  2. B. 完整遍历一遍全部训练数据
  3. C. 训练 100 个批次
  4. D. 网络一共 100 层
显示答案与解析
答案：B

epoch = 全数据集过几遍。一遍之内每个样本都参与过至少一次梯度更新（mini-batch 时一遍 = m/batch_size 次更新，所以 A、C 都把 epoch 和步数搞混了）。epochs=100 → 整个数据集反复学 100 轮。

概念★★★

课程代码里，多分类网络的输出层写的是 Dense(10, activation='linear')，损失函数却配 SparseCategoricalCrossentropy(from_logits=True)。输出层为什么不用 activation='softmax'？

  1. A. 因为 linear 计算更快，softmax 反正不影响结果
  2. B. 因为标签是整数编码而不是 one-hot
  3. C. 因为 softmax 只能用于二分类
  4. D. 为了数值稳定：让损失函数从 logits（未过 softmax 的 z）一步算完，避免「先 softmax 再 crossentropy」在 z 很大/很小时的浮点上溢或下溢；概率留到预测时再算
显示答案与解析
答案：D

吴氏课程最著名的工程细节：「两段式」（网络里先 softmax，损失再算交叉熵）在 z 很大时 eᶻ 上溢、很小时下溢。标准写法三件套：① 输出层 activation='linear' 只算 z；② 损失加 from_logits=True 内部一步完成「归一 + 对数」；③ 预测时才 tf.nn.softmax(logits)。B 说的是「Sparse」的含义（整数标签），是另一个知识点。

5.2激活函数的选择

图像★★

下图重绘自笔记图 5-1 的三大激活函数。①②③ 分别是什么？（选项按 ①②③ 顺序给出）

  1. A. ① tanh；② linear；③ sigmoid
  2. B. ① sigmoid；② ReLU；③ tanh
  3. C. ① linear；② sigmoid；③ ReLU
  4. D. ① ReLU；② sigmoid；③ linear（恒等）
显示答案与解析
答案：D

① 折线：z<0 输出 0、z>0 输出 z，z=0 处直角折弯 → ReLU；② S 形过 (0, 0.5)、值域 (0,1) → sigmoid；③ 直线 y=z → linear（恒等激活），即「不激活」。认形状是基本功：考试常给曲线让你反写 g(z) 表达式。

概念★★

按课程经验法则连线：隐藏层默认用 ______；输出层做二分类用 ______；输出层做回归（预测房价）用 ______；输出层做 10 选一多分类用 ______。

  1. A. ReLU / sigmoid / linear / softmax
  2. B. sigmoid / ReLU / softmax / linear
  3. C. tanh / linear / sigmoid / ReLU
  4. D. linear / softmax / ReLU / sigmoid
显示答案与解析
答案：A

口诀「隐藏层先试 ReLU；输出层看答案的类型」：要概率 → sigmoid；要任意实数分数 → linear；要 N 选一的概率分布 → softmax。图片网络偶尔试 tanh（输出居中在 0），但默认答案永远是 ReLU。

概念★★★

「没有非线性 = 大号线性回归」：若网络每层都用线性激活 g(z) = z，则无论堆多少层，整个网络等价于：

  1. A. 一个更深的非线性网络
  2. B. 一个决策树
  3. C. 一个线性函数（对输入的一次式）：W⁽³⁾W⁽²⁾W⁽¹⁾x 仍是 x 的线性组合，隐藏层全部白堆
  4. D. 一个常数函数，输出与输入无关
显示答案与解析
答案：C

矩阵乘矩阵还是矩阵，一次式复合一次式还是一次式——多层恒等复合仍是恒等。神经网络的全部表达力来自非线性激活的逐层复合，这正是 4.2「每层再做一次特征再发明」的前提。官方测验的原话：linear activation everywhere → network collapses to linear regression。

计算★★

（1）ReLU(−3) = ?（2）ReLU(2.5) = ?（3）ReLU 为什么比 sigmoid 训练得快？给出笔记里的两条理由。

给定　ReLU(z) = max(0, z)
显示答案与解析
答案：（1）0；（2）2.5

（1）0；（2）2.5。（3）① 计算快：一次 max 判断，没有指数运算（sigmoid 要算 e⁻ᶻ）；② 梯度不易消失：正区梯度恒为 1，而 sigmoid 在 |z| 大的两端导数 ≈ 0，深层几乎学不动（梯度消失）。负区梯度为 0 的「死区」在实践里基本无碍。

概念★★

交通监控要同时判断画面里「有没有车、有没有行人、有没有信号灯」——三个答案可以同时为真。输出层三个神经元该怎么设计？

  1. A. 一个 softmax，三类的概率加和为 1
  2. B. 三个独立的 sigmoid 输出，各答各的 0/1 概率（多输出分类 multiple outputs）
  3. C. 一个 linear 输出
  4. D. 三个 ReLU 输出
显示答案与解析
答案：B

关键判断：标签是否互斥。互斥单标签（手写数字 0–9 十选一）→ softmax；可同时为真（车 + 行人同时出现）→ 每个输出神经元独立过 sigmoid。A 会让「有车」和「有行人」互相抢概率，语义就错了。

5.3多分类与 Softmax

概念★★

softmax 的两个关键性质是：

  1. A. 输出全为正数；且加和恒为 1（天然是概率分布），指数还会放大大 z 的优势
  2. B. 输出可正可负；加和恒为 0
  3. C. 输出在 (−1, 1)；加和恒为 1
  4. D. 输出全为正数；加和可以任意大
显示答案与解析
答案：A

aⱼ = e^zⱼ / Σₖ e^zₖ：分子分母都是正数 → 输出全正；同除分母 → 加和为 1；指数「赢者通吃」的放大效应 → 大 z 独占鳌头（「软最大值」soft-argmax 的名字由来）。这正是把任意实数向量变成概率分布的标准姿势。

图像★★

下图重绘自笔记图 5-2：某个 4 分类网络的输出层 logits z = [5, 2, −1, 3]，柱高是 softmax 后的概率。看图回答：哪个类别胜出？模型对它的把握大约多大？

  1. A. 类别 1 胜出，把握约 84%
  2. B. 类别 4 胜出，因为 z₄ 比 z₂、z₃ 大
  3. C. 类别 1 胜出，把握约 50%（概率对半分）
  4. D. 四类平分，各 25%
显示答案与解析
答案：A

z₁ = 5 最大 → softmax 后 0.842，一家独大；z₃ = −1 垫底只剩 0.002。注意 z₁ 与 z₄ 只差 2，概率却差了 7 倍多——这就是「指数让大 z 独占鳌头」。验证加和：0.842+0.042+0.002+0.114 = 1。

计算★★

二分类升级小实验：softmax([2, 1]) = ?（e² ≈ 7.39，e¹ ≈ 2.72）

给定　aⱼ = e^zⱼ / Σₖ e^zₖ；e² ≈ 7.39；e¹ ≈ 2.72
显示答案与解析
答案：[0.73, 0.27]

分母 = 7.39 + 2.72 = 10.11；a₁ = 7.39/10.11 ≈ 0.73，a₂ = 2.72/10.11 ≈ 0.27。彩蛋：两类 softmax 恰好还原 sigmoid——a₁ = e²/(e²+e¹) = 1/(1+e⁻¹) = g(1) ≈ 0.73。sigmoid 是 softmax 的 N=2 特例。

计算★★★

手写数字识别（10 类）。某个样本真实是数字 0（one-hot y = [1,0,0,…]），网络 softmax 输出 a = [0.7, 0.2, 0.1, 0, …, 0]。多类交叉熵损失 L(a, y) = ?（ln 0.7 ≈ −0.357）

给定　L = −Σₖ yₖ·log(aₖ)；只有 y₁ = 1，其余 yₖ = 0
显示答案与解析
答案：L ≈ 0.357

one-hot 的妙处：求和里只剩一项，L = −log(a₁) = −log 0.7 ≈ 0.357。本质与二分类交叉熵同构：「罚的就是你没押在正确答案上的概率」。若 a₁ = 0.98，L ≈ 0.02——押对且自信几乎不罚；a₁ = 0.05，L ≈ 3.0——错且自信重罚。

5.4高级优化与层类型

概念★★

Adam 优化器「自适应」的对象是：

  1. A. 学习率 α 随训练轮数自动衰减
  2. B. 每个参数各自的步长——梯度一直同号就加速冲（动量），忽正忽负就刹车（除以梯度平方的滑动平均）
  3. C. 自动选择网络层数
  4. D. 自动在梯度消失时换成 ReLU
显示答案与解析
答案：B

Adam = Adaptive Moment Estimation：m 是梯度一阶矩（方向/动量），v 是二阶矩（波动大小），w := w − α·m̂/(√v̂+ε)。直觉版：同一个参数的梯度若连续同号，说明方向对了，加速冲；来回振荡说明在峡谷两壁弹跳，就除以波动幅度踩刹车。A 是另一门手艺（学习率调度），别混。

概念★★

课程给出的实践建议：新起一个神经网络项目时，优化器默认用：

  1. A. 纯随机梯度下降 SGD（α = 0.0001）
  2. B. 不用优化器，直接闭式解
  3. C. Adam（学习率 1e-3 起步），比 SGD 更耐粗糙的学习率
  4. D. 必须先网格搜索 100 组 α 再训练
显示答案与解析
答案：C

「Adam(lr=1e-3) 是神经网络默认起步优化器」。它对 α 不那么敏感，帮你省掉大量调参时间；SGD+momentum 是后期精调的选项。另一个考点：Dense（全连接）之外，课程只点名了卷积层（Conv，图像）与循环层（RNN，序列）——「乐高的异形积木」，不展开。

5.5反向传播（选修）

概念★★

一句话概括反向传播的本质：

  1. A. 逐个参数做数值扰动，看 J 变多少（数值微分）
  2. B. 链式法则 + 动态规划：沿计算图反向逐节点乘「下游导数」，一次反向扫描同时得到全部参数的偏导
  3. C. 把网络反过来跑一遍：从输出层向输入层做前向传播
  4. D. 随机初始化参数的技巧
显示答案与解析
答案：B

反向传播 = 在计算图上机械地应用链式法则；「动态规划」体现在中间结果（各节点的局部导数）被复用，不用重复算。A 是数值微分——每参数扰动一次要跑一遍前向，慢 n 倍，只用来验证梯度写对没有。C 是字面误解：反向流动的是梯度，不是数据。

图像★★★

下图重绘自笔记图 5-3 的最小计算图：c = a·b，a = w²，b = w+1，取 w = 2。沿图反向把局部导数连乘相加，dJ/dw = ?

  1. A. 7 = 3 + 4（只把 ∂c/∂a 和 ∂c/∂b 加起来）
  2. B. 48 = 3 × 4 × 4（把所有导数全乘起来）
  3. C. 12 = 3 × 4（只走上面那条路）
  4. D. 16 = (3 × 4) + (4 × 1)：两条路径各自连乘，再相加
显示答案与解析
答案：D

多路径法则（多元链式法则）：同一条路径连乘，不同路径相加。路径 1（经 a）：∂c/∂a × ∂a/∂w = 3×4 = 12；路径 2（经 b）：∂c/∂b × ∂b/∂w = 4×1 = 4；合计 dc/dw = 16。验证：c = w²(w+1) = w³+w²，dc/dw = 3w²+2w = 12+4 = 16 ✓。神经网络只是把这张图换成几百万个节点，原理一个字不变。

概念★★

前向传播与反向传播在计算图上的分工是：

  1. A. 前向算激活（网络「想」），反向算梯度（网络「学」）——fit 的每一步都是先前后反
  2. B. 两者都只算激活，方向不同而已
  3. C. 反向传播在前向传播之前运行
  4. D. 前向用于训练，反向用于预测
显示答案与解析
答案：A

fit 的每一步 = 前向（算出 ŷ 和 J）→ 反向（沿图把 ∂J/∂每个参数 全部拿到）→ 优化器更新。预测（predict）只用前向。梯度消失/爆炸是深网络反向流动的宿命——Adam 与 ReLU 是第一代解药（5.2、5.4）。

6.1模型评估与选择

概念★

「在训练集上算正确率」为什么毫无意义？

  1. A. 因为训练集太小，算不准
  2. B. 因为正确率只能算一次
  3. C. 因为过拟合的模型在训练集上是满分选手——必须留出模型没见过的数据来考核
  4. D. 因为训练集没有标签

给定　train_test_split(X, y, test_size=0.40) → 再对 40% 切 test_size=0.50
显示答案与解析
答案：（1）6000 / 2000 / 2000；（2）9 个模型；J_cv 最小的 d 获胜

6.2偏差与方差诊断

概念★★

两把尺子一比，病名自现。空格处依次应填：

「J_train 高、J_cv 也高且接近 J_train → ______；J_train 低、J_cv 高（差距大）→ ______」

  1. A. 高方差（过拟合）；高偏差（欠拟合）
  2. B. 高偏差；也高偏差
  3. C. 高偏差（欠拟合）；高方差（过拟合）
  4. D. 高方差；也高方差
显示答案与解析
答案：C

口诀：「训练差 = 太笨（高偏差，欠拟合）；训练好、考试差 = 太嗨（高方差，过拟合）」。J_train 与 J_cv 的绝对高低看偏差、差距看方差。两者都高 = 双重打击（J_train 高、J_cv 更高）。

计算★★★

四个模型的误差（人类水平基线 = 10.5%）：① J_train = 15.0%，J_cv = 16.0%；② J_train = 0.5%，J_cv = 15.0%；③ J_train = 15.0%，J_cv = 30.0%；④ J_train = 10.7%，J_cv = 11.0%。分别诊断：高偏差？高方差？还是都没病？

给定　基线 10.5%；判据：J_train vs 基线（偏差）；J_train 与 J_cv 差距（方差）
显示答案与解析
答案：① 高偏差；② 高方差；③ 双重打击；④ 基本健康

① 训练误差比基线高 4.5 个点 → 学不动（欠拟合），但 cv 与 train 接近 → 没有过拟合 → 高偏差，药方：加特征 / 加次数 / 减 λ / 上神经网络。② 训练贴地板、考试掉 14.5 个点 → 高方差，药方：加数据 / 减特征 / 加 λ / 正则化。③ 两样全占 → 双重打击，先治偏差（换更强模型）再治方差。④ 两项都贴着人类基线 → 没病，可以收工。

概念★★

λ 从小到大扫描时，J_train(λ) 与 J_cv(λ) 的典型走向是：

  1. A. λ 很小：train 低 cv 高（方差大）；λ 很大：两者都高（偏差大）；中间某处 J_cv 最小
  2. B. λ 越大两者越低，单调下降
  3. C. λ 只影响训练速度，不影响误差
  4. D. λ 很小：两者都高；λ 很大：train 低 cv 高
显示答案与解析
答案：A

λ→0 等于不正则 → 放任过拟合（train 低 cv 高）；λ 巨大 → 参数全被压成 0 附近 → 欠拟合（双高）。与第 3.6 节「λ 是双向旋钮」呼应：最优 λ 就在 J_cv 的谷底。D 把方向说反了。

概念★★★

「加大神经网络」能同时降偏差和方差吗？课程的回答是：

  1. A. 不能——网络越大方差必然越大
  2. B. 能——更大的网络可以降 J_train；只要 λ 恰当管住复杂度，J_cv 也会跟着降。「大网络 + 恰当正则」是用算力换性能的正解
  3. C. 能，但必须同时加数据
  4. D. 不能——网络大小与偏差方差无关
显示答案与解析
答案：B

课程原话（Q&A）：能。直觉上「更大 = 更容易过拟合」，但只要正则化得当，大网络几乎单调地更好——这正是深度学习时代「大力出奇迹」的理论底气。C 是常见保守误答；实践中算力往往比数据便宜。

6.3基线与学习曲线

概念★★

判断 J_train = 10.8% 算高还是低，笔记的做法是先找「基线」。合格的基线不包括：

  1. A. 人类水平的误差（如语音识别 10.6%）
  2. B. 竞争对手产品的误差
  3. C. 上一版系统的误差
  4. D. 随机猜的期望误差（比如 50%）
显示答案与解析
答案：D

基线 = 这个任务「应该」能做到多好：人类水平 / 对手 / 上一版。随机猜的水平太宽泛，不能当基线。例：J_train = 10.8% 看着很高，但人类是 10.6% → 训练误差其实贴着天花板 → 不是高偏差。先定基线，再判偏差方差。

6.5误差分析与数据增强

概念★★

「误差分析」（error analysis）的标准动作是：

  1. A. 把损失函数改成更复杂的公式
  2. B. 把验证集里预测错的那批样本拉出来人工过一遍，分桶归类，看最大的桶是什么——先治占比最大的错误来源
  3. C. 立刻换更大的神经网络
  4. D. 删掉预测错的样本，重训一遍
显示答案与解析
答案：B

OCR 例：100 个错样本里 61 个「遮挡」、17 个「多字母粘连」、12 个「低对比度」→ 结论立现：先治遮挡（占 61%），别先花三个月调网络结构。D 是数据造假——把考砸的卷子烧了，成绩单不会变好。

计算★★

OCR 项目验证集 1000 张图，模型错了 100 张。分桶：61 张遮挡、17 张多字母粘连、12 张低对比度、10 张其他。（1）「遮挡」占错误的多大比例？（2）若只解决遮挡问题（假设全修对），错误率从 10% 降到多少？（3）优先修哪个桶，为什么？

给定　验证集 1000；错误 100；桶：61 / 17 / 12 / 10
显示答案与解析
答案：（1）61%；（2）3.9%；（3）遮挡——性价比最高

（1）61/100 = 61%。（2）剩 100 − 61 = 39 张错 → 39/1000 = 3.9%（准确率 96.1%）。（3）修「遮挡」一个桶就能砍掉六成错误；而「其他」桶修完只降 1 个点。误差分析的价值就在把「直觉」变成「占比」——数据说话，别凭感觉调网络。

概念★★

「数据增强」与「合成数据」都为了多弄数据，它们的区别与共同底线是：

  1. A. 增强 = 对已有图片做旋转 / 放缩 / 亮度 / 扭曲等「变形不换标签」的变换；合成 = 用渲染引擎 / PS 全新造数据；底线：造出的样本要贴近真实世界的分布
  2. B. 两者是一回事，都指多拍照
  3. C. 增强会引入标签噪声，永远不要用
  4. D. 合成数据必须 1:1 复制真实数据，否则违法
显示答案与解析
答案：A

增强吃的是「已有样本 × 真实世界会发生的变换」（旋转后的猫还是猫）；合成是从零造（Course 3 的火星车 / 月球着陆器全是模拟器合成）。共同底线：模拟真实、变形不换标签——把猫上下翻转成「倒吊」现实中几乎不出现，这种增强反而有害。判断该不该加数据：先看学习曲线（图 P6-2）。

6.6迁移学习与全周期

概念★★

迁移学习的两种用法：「只重训输出层」与「微调全部层」。数据量极少时该选哪种？为什么？

  1. A. 微调全部层——学得更多
  2. B. 都不行，必须从头训练
  3. C. 只重训输出层（冻结前面所有层）——预训练层学到的「边缘 → 纹理 → 部件」层次结构对新任务照样有用，数据极少也稳
  4. D. 两种用法数据量需求相同
显示答案与解析
答案：C

规则：数据少 → 冻结；数据多 → 微调。预训练（如 ImageNet）学到的低层视觉特征几乎通用，冻结后只需训练一个小输出层，参数少、不易过拟合；数据充足时再整体小步微调，效果上限更高。GPT / BERT 的「预训练 - 微调」范式正是它的登峰登顶之作。

概念★★

迁移学习能成立的前提是：

  1. A. 源任务与目标任务的输入同构（比如同为图片），且预训练学到的特征对新任务有用
  2. B. 两个任务的标签必须完全相同
  3. C. 目标任务的数据必须比源任务多
  4. D. 只能用同一种优化器
显示答案与解析
答案：A

「输入同构」是硬前提：图片网络迁移到图片任务顺理成章；拿图片预训练网络去做音频任务，前面的层学的东西基本用不上。B 反了——恰恰是输出层要换掉（新任务新标签）；C 也反了——迁移学习正是因为目标任务数据少才有价值。

概念★★

模型上线半年后准确率悄悄下滑。全周期（MLOps）视角下，最该怀疑的是：

  1. A. 代码有 bug——先重装框架
  2. B. 准确率本来就会随机下滑，正常现象
  3. C. GPU 老化，算力下降
  4. D. 数据漂移或概念漂移：世界变了（用户口味、欺诈手法、经济环境），训练时的数据分布不再代表今天——需要监控与回流再训练
显示答案与解析
答案：D

全周期 = 数据 → 模型 → 部署 → 监控 → 回流再训练。模型没变、世界在变：数据漂移（输入分布变了，如新品类商品图）与概念漂移（同样的输入、正确的答案变了，如口罩后「人脸」的含义）。伦理也在这一节：招聘 / 信贷 / 医疗系统要像安全审计一样做偏见审计。

6.7倾斜数据集：精确率与召回率

概念★★

只有 0.5% 的邮件是垃圾邮件。一个「全部判正常」的笨模型准确率是多少？这说明什么？

  1. A. 0.5%——说明它完全没用
  2. B. 0%——因为它一封垃圾邮件都没抓住
  3. C. 50%——说明它在瞎猜
  4. D. 99.5%——说明稀有类别下准确率会说谎，必须换精确率 / 召回率来评估
显示答案与解析
答案：D

全判正常：99.5% 的正常邮件全对 → 准确率 99.5%，但一封垃圾邮件都没抓到。「准确率会说谎」是倾斜数据集的第一课——分母被占绝大多数的负类稀释了。8.6 的异常检测同理（0.1% 异常率时空模型 99.9% 准）。

计算★★★

某疾病筛查模型在 10000 人上测试：真实患者 90 人，其中 80 人被检出；模型总共报警 100 人。求精确率 P、召回率 R 与 F1。

给定　TP = 80；FP = 100 − 80 = 20；FN = 90 − 80 = 10；P = TP/(TP+FP)；R = TP/(TP+FN)；F1 = 2PR/(P+R)
显示答案与解析
答案：P = 0.80；R ≈ 0.889；F1 ≈ 0.842

P = 80/100 = 0.80（「我报警的有多准」）；R = 80/90 ≈ 0.889（「坏蛋抓全了没」）；F1 = 2×0.8×0.889/(0.8+0.889) ≈ 0.842。F1 是两者的调和平均——短板受罚，P 或 R 有一个很低时 F1 会被狠狠拉下来。

概念★★★

精确率与召回率天然此消彼长（阈值越高 P 越高、R 越低）。两个应用场景该偏谁？① 癌症初筛；② 垃圾邮件拦截。

  1. A. ① 偏高召回（宁可误报，别漏掉真患者）；② 偏高精确（宁放过，别把正常信扔进垃圾桶）
  2. B. ① 偏高精确；② 偏高召回
  3. C. 两者都应死守 50% 阈值
  4. D. 两者都该追 F1 最大，不必考虑代价
显示答案与解析
答案：A

该偏谁 = 看两种错误的代价：漏诊（FN）可能致命 → 癌症初筛容忍误报、要求高召回；误拦正常邮件（FP）让用户错过重要信息 → 邮件拦截宁可放过、保高精确。F1 只是「一个数概括两者」的默认选项，不是终极目标——代价不对称时，阈值向代价低的那一侧倾斜。

7.1决策树模型

概念★

决策树本质上是：

  1. A. 一个多层神经网络
  2. B. 一棵真的生物树状数据库
  3. C. 一个自动生成的 if-else 程序：非叶结点 = 特征提问，边 = 答案，叶子 = 分类结果；预测 = 从根往下走一条路
  4. D. 一种聚类算法
显示答案与解析
答案：C

同一条树逻辑写成代码就是嵌套 if-else。与神经网络「全局参数共享」不同，树的每个结点只关心局部数据子集——这既是它的可解释性，也是它不稳定（换一批数据结构就大变）的根源。

图像★★

下图重绘自笔记图 7-1 的猫分类树。一只「耳朵尖、脸不圆、有胡须」的动物，沿树走到哪个叶子？判它是不是猫？

  1. A. 左二叶子（不是猫）
  2. B. 耳朵尖 → 脸不圆 → 「不是猫」
  3. C. 耳朵尖 → 脸圆 → 「猫」
  4. D. 无法判断，必须三个特征都问完
显示答案与解析
答案：B

沿树走：耳朵尖？是 → 左子树；脸圆？否 → 右叶子「不是猫」。注意树没问「胡须」就下了结论——决策树的一条路径只经过部分特征，这正是它比全特征模型可解释的原因。C 错在把「脸圆吗」的答案答反了。

7.2熵与信息增益

概念★★

笔记给「熵」的直觉解释是：

  1. A. 系统的热力学温度
  2. B. 树的深度
  3. C. 数据集的行数
  4. D. 最少要问几个是/否问题才能猜中标签——5:5 时要 1 bit（最乱），全猫时 0 个（最纯）
显示答案与解析
答案：D

熵 = 不纯度：H(p₁) = −p₁log₂p₁ − p₀log₂p₀。9:1 时只要 0.469 个问题——大部分时候一问就中。信息增益 IG = 「这一问帮我省下了几个问题」：省得最多的问法就是最好的切分。另一把等价尺子：基尼不纯度 1 − Σp²（sklearn 默认，二类时与熵形状几乎重合）。

图像★★

下图重绘自笔记图 7-2 左的熵曲线。看图回答：H(0.5)、H(0)、H(0.9) 大致是多少？曲线说明「乱」与「纯」各在哪头？

  1. A. H(0.5)=0.5，H(0)=0.5，H(0.9)=0.9；熵随 p₁ 线性增长
  2. B. H(0.5)=0，H(0)=1，H(0.9)=1；两端乱、中间纯
  3. C. H(0.5)=1，H(0)=0，H(0.9)≈0.47；两端纯、中间乱
  4. D. H 恒等于 1
显示答案与解析
答案：C

钟形：p₁=0.5 处 H = 1 bit（五五开，最没底）；p₁=0 或 1 时 H = 0（全同类，不用问）；H(0.9) = −0.9log₂0.9 − 0.1log₂0.1 ≈ 0.469。记忆锚点：0.469 就是课程猫例「9 猫 1 狗」的熵。建树的目标就是让子结点往两端跑。

计算★★

手算熵：（1）H(0.5) = ?（2）H(1)（全猫）= ?（3）H(0.25) = ?（log₂0.25 = −2，log₂0.75 ≈ −0.415）

给定　H(p₁) = −p₁log₂p₁ − p₀log₂p₀；log₂0.75 ≈ −0.415
显示答案与解析
答案：（1）1；（2）0；（3）0.811

（1）H = −0.5×(−1) − 0.5×(−1) = 1。（2）log 1 = 0 → H = 0。（3）H = −0.25×(−2) − 0.75×(−0.415) = 0.5 + 0.311 ≈ 0.811。三问连起来正是熵曲线从峰到坡的三个采样点。

计算★★★

10 个样本（5 猫 5 狗）。候选切分「耳朵尖吗？」：耳朵尖的 4 个全是猫，不尖的 6 个里 1 猫 5 狗。求该切分的信息增益。（H(1/6) ≈ 0.65）

给定　IG = H(父) − Σ (nₖ/n)·H(子ₖ)；H(0.5)=1；H(1/6) ≈ 0.65
显示答案与解析
答案：IG ≈ 0.61

父熵 H(0.5) = 1。子集加权熵 = (4/10)×H(1) + (6/10)×H(1/6) = 0.4×0 + 0.6×0.65 = 0.39。IG = 1 − 0.39 = 0.61。解读：「耳朵尖吗」这一问平均省下 0.61 个问题——若另一特征（如「脸圆吗」）IG = 0.2，则先劈「耳朵尖」。每个结点都对所有候选特征算 IG，挑最大者劈叉。

7.3构造完整决策树

概念★★

决策树递归建树的三个停止条件是：

  1. A. 熵为 1；信息增益为 0；树宽超过屏幕
  2. B. 准确率 100%；数据超过 1 万行；CPU 过热
  3. C. 熵为 0（结点已纯）；候选特征用尽；到达 max_depth 深度上限
  4. D. 只要时间够，永远不该停
显示答案与解析
答案：C

三个条件都在防过拟合，其中 max_depth 最常用——它是树的「复杂度旋钮」，对应神经网络的层数。sklearn 五行版：DecisionTreeClassifier(max_depth=3, criterion='entropy')。

概念★★

为什么单棵决策树「不稳定」——换 10% 数据，整棵树可能变样？

  1. A. 因为 if-else 有执行顺序
  2. B. 因为熵的计算有随机性
  3. C. 因为决策树必须用 GPU
  4. D. 因为每个结点只关心局部数据子集：根部劈叉选了别的特征，下面整棵子树全部长歪
显示答案与解析
答案：D

「局部性」是双刃剑：好处是可解释，坏处是误差沿树放大——根部一个不同的选择，子树全变。这个不稳定（高方差）正是 7.5 要用「森林」来平均的动机。

7.4类别、连续特征与回归树

概念★★

耳朵形状有「尖 / 圆 / 软」三个取值。决策树（以及神经网络）处理这类类别特征的通用预处理是：

  1. A. 直接编码成 1 / 2 / 3，让算法自己看出大小关系
  2. B. one-hot 编码：拆成 is_pointy、is_floppy、is_round 三个 0/1 特征
  3. C. 删掉这个特征
  4. D. 全部填 0
显示答案与解析
答案：B

one-hot 把「三选一」拆成三个布尔问题，树照常问「=1 吗」。A 是经典陷阱：1<2<3 凭空引入了假的顺序关系（「圆」比「尖」大是什么意思？）。这是与神经网络共享的通用预处理（sklearn：pd.get_dummies）。

概念★★

关于「连续特征」（如体重）与「回归树」，正确的说法是：

  1. A. 连续特征要先取整才能用；回归树叶子输出投票结果
  2. B. 回归树不存在
  3. C. 连续特征必须先 one-hot
  4. D. 连续特征沿数值扫阈值（「体重 ≥ 9？」「≥ 7.5？」……），每个阈值一个候选切分，算 IG 挑最优；回归树叶子输出落在该叶子的训练样本 y 的均值，分裂目标是让叶内方差尽量小
显示答案与解析
答案：D

两件配套的事：分类树用「熵 / 信息增益」，回归树把「纯度」换成「方差」——分裂目标是方差缩减（连续版的熵增益）。叶子的预测 = 叶内样本 y 的平均（比如落在该叶的猫体重均值 3.9 kg）。

计算★★

回归树的某个叶子落进了 4 个训练样本，体重 y = [3.0, 4.0, 4.4, 4.6]。（1）该叶子的预测值？（2）该叶子的方差（除以 m）约为多少？（保留两位小数）

给定　预测 = 叶内样本均值；方差 = (1/m)Σ(y⁽ⁱ⁾−ȳ)²
显示答案与解析
答案：（1）4.0；（2）0.36

（1）ȳ = (3.0+4.0+4.4+4.6)/4 = 4.0。（2）离差平方 = 1 + 0 + 0.16 + 0.36 = 1.52 → 方差 = 1.52/4 = 0.38（若按 m−1=3 除则 0.51；考试默认按笔记口径 m）。回归树的「纯」= 方差小：分裂就是让左右两叶的加权方差总和最小。

7.5树集成与随机森林

概念★★

随机森林的三要素（笔记图 7-3 的配方）是：

  1. A. 自助抽样（bagging，有放回采样）+ 每棵树只用随机子集的特征 + 多数投票 / 平均
  2. B. 全量数据训练一棵巨树 + 剪枝 + 可视化
  3. C. 串行种树，每棵修前面的残差
  4. D. 把树换成神经网络再平均
显示答案与解析
答案：A

有放回采样让每棵树见到略有不同的数据；特征子集让树与树去相关（不会全部劈同一个特征）；投票把个别树的怪癖平均掉。C 是 boosting（XGBoost，7.6）的配方——「平行种树 vs 串行修错」是本章最大的辨析点。B 大 = 只慢不坏，CPU 可并行。

图像★★

下图重绘自笔记图 7-3。看图回答：单棵树的高方差为什么被森林「平均掉」了？被 63.2% 抽中的样本比例从哪来？

  1. A. 森林让每棵树更准；63.2% 是经验常数
  2. B. 各树错得「各不相同」（数据与特征都被随机化），投票时正负误差相互抵消；单条样本被抽中的概率 = 1 − (1 − 1/m)^m → 1 − 1/e ≈ 63.2%
  3. C. 森林靠更多参数过拟合，然后互相抵消
  4. D. 63.2% 是投票阈值
显示答案与解析
答案：B

集成的数学：若各树误差互不相关，平均后方差按 ~1/B 缩小——随机化（数据 bagging + 特征子集）正是在制造「互不相同」。63.2% 的来历：一条特定样本「一次都没被抽到」的概率是 (1−1/m)^m，m→∞ 时 → e⁻¹ ≈ 0.368，所以被抽到 ≈ 63.2%；剩下的 36.8% 天然成为「袋外」（OOB）免费验证样本。

计算★★★

100 条训练数据，做一次有放回抽样（抽 100 次）。（1）期望大约多少条不同的原始样本被抽中？（2）没被抽中的那部分叫什么、有什么用？（3）若 B = 100 棵树，OOB 评估的成本是多少？

给定　1 − 1/e ≈ 0.632；e⁻¹ ≈ 0.368
显示答案与解析
答案：（1）约 63 条；（2）袋外样本 OOB——免费验证；（3）零额外标注成本

（1）100 × 0.632 ≈ 63 条（剩下 ~37 条一次没中）。（2）每棵树自己的「袋外」样本它从没见过 → 天然的小测试集，免费做验证（不占正式测试集）。（3）OOB 不需要任何新标注，只是复用没抽中的那 ~37%——「免费的午餐」。

7.6XGBoost 与选型

概念★★

XGBoost（提升法 boosting）与随机森林（装袋法 bagging）最核心的区别是：

  1. A. XGBoost 串行种树：每棵新树专门去修「上一批树合起来还错的地方」（对残差拟合）；随机森林并行种树，各自独立投票
  2. B. XGBoost 用 GPU，随机森林用 CPU
  3. C. XGBoost 只能做回归，随机森林只能分类
  4. D. 没有区别，只是名字不同
显示答案与解析
答案：A

「平行种树（独立 + 平均，治方差）vs 串行修错（残差 + 累加，治偏差）」。XGBoost 在 boosting 之上再加正则化、二阶梯度、列抽样、并行分裂等工程改良——表格类竞赛常年屠榜的默认起点，两行代码：XGBClassifier().fit()。

概念★★★

你的任务分别是：① Kaggle 表格赛（用户流失预测，2 万行 × 50 列）；② 猫狗图片分类（10 万张图）。按课程选型表，各先试什么？

  1. A. ① 先试 XGBoost（树集成擅长结构化 / 表格数据）；② 无脑深度学习（神经网络擅长图像等非结构化数据）
  2. B. 两者都先试 XGBoost
  3. C. 两者都先试神经网络
  4. D. 两者都先试 K-means
显示答案与解析
答案：A

一句话选型：「表格 → 树；非结构化（图 / 音频 / 文本）→ 网络」。树的优势：训练快、CPU 友好、单棵树可解释；网络的优势：大数据与非结构化信号。D 是无监督算法，连监督任务都接不住。

8.1什么是聚类

概念★

聚类与分类（监督学习）最本质的区别是：

  1. A. 聚类不训练模型，分类要训练模型
  2. B. 聚类的数据没有标签 y，连「应该分成几类」都未必有标准答案；分类的数据有明确类别标签
  3. C. 聚类只能处理二维数据
  4. D. 聚类的结果一定比分类准确
显示答案与解析
答案：B

聚类的输入只有 x 没有 y——Google News 把同事件报道自动聚簇、市场按消费行为分客群、DNA 序列分组，全都事先无人标注。A 错：K-means 也在「学」（中心位置）；C、D 无中生有。监督 / 无监督的分界就在「有没有 y」。

概念★★

以下四个任务：① 新闻网站把同一事件的几千篇报道归成一组；② 邮件是垃圾还是正常；③ 电商把消费者分成若干客群做精准营销；④ 判断患者肿瘤良性恶性。属于聚类（无监督）的是：

  1. A. ① ② ③
  2. B. ② 和 ④
  3. C. ① 和 ③
  4. D. 全部
显示答案与解析
答案：C

② 垃圾邮件有历史标注（大量已标注的垃圾 / 正常邮件）→ 监督分类；④ 肿瘤有病理确诊标签 → 监督分类。① ③ 事先没有任何「正确分组」的标签——分几组、怎么分都没有唯一答案，正是聚类的用武之地。

8.2K-means 算法

概念★

K-means 每一轮循环依次做两件事，正确的顺序与内容是：

  1. A. 两步顺序可以任意交换，结果完全一样
  2. B. ① 移动：中心搬到均值处；② 分配：样本就近站队
  3. C. ① 分配：每个样本归入编号最小的中心；② 移动：中心搬到离它最近的样本处
  4. D. ① 分配：每个样本归入最近的中心；② 移动：每个中心搬到本簇成员的均值处
显示答案与解析
答案：D

公式版：c⁽ⁱ⁾ := argmink‖x⁽ⁱ⁾ − μk‖²（分配），μk := mean(x⁽ⁱ⁾ with c⁽ⁱ⁾=k)（移动）。循环直到分配不再变化或达到迭代上限。C 的「编号最小」「最近样本」都是错的；A 的两步虽然每步都降 J，但交替对象不同（轮流固定 c 或 μ），交换顺序会改变轨迹。

概念★★

移动步中，某个簇一个成员都没分到（空簇）。笔记给出的标准处理是：

  1. A. 报错终止整个算法
  2. B. 删除该簇（少一个 K），或把离所有中心都最远的离群点设为新中心
  3. C. 把该中心随机重新撒一次，直到簇非空
  4. D. 让它停在原地不动即可
显示答案与解析
答案：B

空簇的均值没有定义（0 个点没法平均）。课程的两条出路：① 直接淘汰这个中心；② 「惩罚性地」把最远的离群点提拔为新中心——那个点本来就没被任何簇好好照顾。A 过于悲观；C 可能死循环；D 会让 K 名不副实。

图像★★

下图简化重绘自笔记图 8-1，是 K-means 的三格连环画。关于三个面板之间的推进，正确的是：

  1. A. 面板 1→2 是分配步（c := argmin‖x−μ‖²），面板 2→3 是移动步（μ := 簇均值，绿色新中心）；若下一轮分配结果与上一轮完全相同，算法收敛
  2. B. 面板 1→2 是移动步，面板 2→3 是分配步；收敛条件是 J 开始变大
  3. C. 面板 2→3 中心移动的方向由学习率 α 决定
  4. D. 三格画的是同一次迭代的三个视角，K-means 实际只执行一步
显示答案与解析
答案：A

看箭头：绿色 μ′ 是各簇成员的均值位置——这正是移动步的定义；而面板 2 里蓝红两色是「就近站队」的分配结果。收敛判据 = 分配不再变化（此时移动步也移动不了中心）。B 把两步说反且收敛条件错误（J 单调不增，不会变大）；C 无中生有——K-means 没有学习率；D 显然不对，两步交替正是算法本体。

计算★★

一维数据 x = {1, 2, 3, 10, 11, 12}，K = 2，初始中心取自样本：μ₁ = 1，μ₂ = 10。（1）执行一次分配步：各样本归哪个簇？（2）执行移动步：新的 μ₁′、μ₂′ = ?（3）再跑一轮分配，结果会变吗？

给定　距离用 ‖x − μ‖²；μ_k := 簇成员均值
显示答案与解析
答案：（1）{1,2,3}→簇1，{10,11,12}→簇2；（2）μ₁′=2，μ₂′=11；（3）不会变——已收敛

（1）逐点比距离：x=3 离 μ₁=1 距离 2、离 μ₂=10 距离 7 → 簇 1；x=10,11,12 同理全归簇 2。（2）μ₁′ = (1+2+3)/3 = 2；μ₂′ = (10+11+12)/3 = 11。（3）新中心下每点到同簇中心仍最近（如 x=3：|3−2|=1 < |3−11|=8），分配不变 → 收敛，两步都「无事可做」。

计算★★★

同一组数据 x = {1, 2, 3, 10, 11, 12}，换一个「坏」的初始化：μ₁ = 2，μ₂ = 3。（1）第一轮分配 + 移动的结果？（2）第二轮分配发生了什么、最终收敛到哪两个中心？（3）这个例子说明 K-means 的什么性质？

给定　K = 2；μ_k := 簇成员均值
显示答案与解析
答案：（1）簇1={1,2}→μ₁=1.5，簇2={3,10,11,12}→μ₂=9；（2）x=3 改投簇1 → μ₁=2、μ₂=11，再无变化；（3）结果依赖初始化（可能局部最优），需多次初始化取 J 最小

（1）x=1,2 离 μ₁=2 更近；x=3 离 μ₂=3 距离 0 → 簇 2！移动：μ₁ = 1.5，μ₂ = (3+10+11+12)/4 = 9。（2）重分配：x=3 离 1.5 距离 1.5、离 9 距离 6 → 叛逃到簇 1；新中心 μ₁ = (1+2+3)/3 = 2，μ₂ = (10+11+12)/3 = 11，此后不再变化。（3）同一份数据、不同初始化走出了不同轨迹——K-means 不保证全局最优，工程上跑 50~1000 次初始化、取失真 J 最小的一次（sklearn 的 n_init）。

8.3优化目标与初始化

概念★

K-means 的失真函数 J = (1/m) Σ‖x⁽ⁱ⁾ − μc⁽ⁱ⁾‖² 度量的是：

  1. A. 中心之间的距离
  2. B. 每个样本到自己簇中心的平方距离的平均——簇内「抱团紧不紧」
  3. C. 簇与簇之间分得开不开
  4. D. 算法运行了多少轮
显示答案与解析
答案：B

J 只看「点到自己中心」的距离（sklearn 里叫 inertia_）。J 越小 = 每个点被自己的中心代表得越好。C 描述的是另一种聚类目标（如谱聚类最大化间隔），K-means 并不直接优化它；A、D 与 J 无关。J 是选 K（肘部法）与挑初始化（取 J 最小那次）的统一尺子。

概念★★

分配步与移动步其实都在最小化同一个 J。两步各自「固定一半变量、优化另一半」的具体方式是：

  1. A. 分配步固定 μ 优化 c（每点挑最近中心必然使该项最小）；移动步固定 c 优化 μ（均值恰是该簇平方距离的最小点）
  2. B. 两步都同时优化 c 和 μ
  3. C. 分配步固定 c 优化 μ；移动步固定 μ 优化 c
  4. D. 只有移动步在优化 J，分配步只是打标签
显示答案与解析
答案：A

这是坐标下降法：轮流只动一半变量。两个「必然最优」值得记住：给定中心，就近站队是每个样本的最优选择；给定成员，均值 μ = (1/n)Σx 恰好最小化平方距离和（对 μ 求导为零即得）。所以每步 J 都单调不增 → K-means 必然收敛（可能停在局部最优）。B 每步只动一半；C 说反了；D 小看了分配步。

计算★★

接 8.2 的收敛结果：簇 1 = {1, 2, 3}（μ₁ = 2），簇 2 = {10, 11, 12}（μ₂ = 11）。失真 J = ?

给定　J = (1/m) Σi ‖x⁽ⁱ⁾ − μc⁽ⁱ⁾‖²，m = 6
显示答案与解析
答案：J = 2/3 ≈ 0.67

逐点平方距离：簇 1 → (1−2)² + (2−2)² + (3−2)² = 1 + 0 + 1 = 2；簇 2 → (10−11)² + (11−11)² + (12−11)² = 2。J = (2 + 2)/6 = 4/6 = 2/3 ≈ 0.67。把 J 算出来，肘部法（8.4）与多初始化选优才有数字可比较。

概念★★

关于 K-means 的初始化，课程推荐的做法是：

  1. A. 在数据范围外均匀撒 K 个点，逼算法多走几轮
  2. B. 必须把所有样本都选一遍当中心
  3. C. 初始化不重要，K-means 总能找到全局最优
  4. D. 随机挑 K 个训练样本当初始中心，并跑 50~1000 次不同初始化、取失真 J 最小的那次结果
显示答案与解析
答案：D

初始中心从样本里随机挑（撒在外面容易造出空簇和怪轨迹）。由于 J 只保证收敛到局部最优，多次初始化 + 取 J 最小是廉价而有效的保险——sklearn 里就是一个参数 n_init=50。C 是对「必然收敛」的误读：收敛 ≠ 全局最优。

计算★★★

同一份数据跑两次 K-means：运行 A 收敛后 J_A = 2/3（两簇 {1,2,3} 与 {10,11,12}）；运行 B 收敛后 J_B = 25.25（两簇 {1,2,3,10} 与 {11,12}）。（1）该采用哪次的结果？（2）J_B 对应的分配还可能被改进吗——运行 B 的 K-means 真的「收敛」了吗？（3）工程上如何避免拿到运行 B 这种结果？

给定　J_A = 2/3，J_B = 25.25（均为各自局部最优）
显示答案与解析
答案：（1）采用 A；（2）确实收敛了——J_B 是那个初始化下的局部最优，分配不再变化、中心不再移动；（3）多次随机初始化取 J 最小（n_init）

（1）J_A ≪ J_B，A 的簇「抱得更紧」，采用 A。（2）关键辨析：收敛 ≠ 全局最优。运行 B 内部完全稳定（再跑一万轮也不动），只是被坏初始化带进了平庸的局部山谷——K-means 的两步每步都只降不升，一旦分配不变就彻底锁死。（3）答案还是那句：多次初始化 + 以 J 为裁判。这也是 8.2 坏初始化手算题的工程意义。

8.4选择簇数 K

图像★★

8.5异常检测与高斯分布

概念★

高斯分布 p(x; μ, σ²) = (1/√(2πσ²))·exp(−(x−μ)²/2σ²) 中，μ 与 σ² 分别决定：

  1. A. μ 决定曲线高度，σ² 决定曲线颜色
  2. B. μ 决定胖瘦，σ² 决定中心
  3. C. μ 决定钟形的中心（峰值在哪），σ² 决定钟形的胖瘦（数据散得多开）
  4. D. 两者都只影响峰值高度
显示答案与解析
答案：C

μ 平移钟形（对称轴），σ 越大越矮胖（散）、越小越高瘦（集中）。注意 σ 变大时峰值反而变低（总面积恒为 1 的守恒）——D 说「只影响高度」漏掉了平移与伸缩的分工。

概念★★

用 m 个样本估计一维高斯的参数，课程采用的最大似然估计是：

  1. A. μ = (1/m)Σx⁽ⁱ⁾，σ² = (1/m)Σ(x⁽ⁱ⁾−μ)²
  2. B. μ = (1/m)Σx⁽ⁱ⁾，σ² = (1/m)Σ(x⁽ⁱ⁾−μ)（不平方）
  3. C. μ = 中位数，σ² = 极差平方
  4. D. μ = (1/m)Σx⁽ⁱ⁾，σ² = (1/(m−1))Σ(x⁽ⁱ⁾−μ)²
显示答案与解析
答案：A

均值 + 除 m 的方差（MLE）。D 的除 m−1 是无偏修正——课程提过 m 小时可用，但标准写法是 A。B 少了平方（Σ(x−μ) 恒为 0）；C 与高斯无关。这两行公式是异常检测的「参数学习」全部内容。

图像★★

下图简化重绘自笔记图 8-3：一维高斯与阈值 ε。正确的读图结论是：

  1. A. 三个红点 p(x) < ε 判为异常；蓝点 p(x) 高判为正常；ε 调小 → 漏报变多、误报变少，ε 调大反之
  2. B. 红点异常是因为它们离原点太远
  3. C. ε 调大只会减少误报，不会带来任何代价
  4. D. 蓝点也应该报警，因为它们不服从高斯分布
显示答案与解析
答案：A

异常的判据是概率低而非「数值大」——本图的 μ 居中，两肩都是异常区（B 只对右肩成立）。ε 是权衡旋钮：调大 ε = 判异常的标准放宽 → 报警变多（召回升、误报也升）；调小则相反（C 的「没有任何代价」不成立）。D 显然反了：蓝点正是「正常长什么样」的样本。

计算★★

某特征的一维样本：x = {2, 4, 4, 4, 5, 5, 7, 9}。（1）μ = ?（2）σ² = ?（3）新样本 x = 5 的 p(x) = ?

给定　μ = (1/m)Σx，σ² = (1/m)Σ(x−μ)²；p(5) = 1/√(2πσ²)；1/√(2π) ≈ 0.399
显示答案与解析
答案：（1）μ = 5；（2）σ² = 4（σ = 2）；（3）p(5) = 1/(2√(2π)) ≈ 0.200

（1）Σx = 40，μ = 40/8 = 5。（2）偏差 = {−3,−1,−1,−1,0,0,2,4}，平方和 = 9+1+1+1+0+0+4+16 = 32，σ² = 32/8 = 4。（3）x=5 恰好落在峰上：指数部分 e⁰ = 1，p(5) = 1/(√(2π)·σ) = 0.399/2 ≈ 0.200——这正是该分布能给出的最高概率，最「正常」的取值。

计算★★★

二维异常检测：特征 x₁ ~ N(0, 1)，特征 x₂ ~ N(0, 4)，两维独立。（1）新样本 x = (2, 4) 的 p₁(x₁) = ?（2）p₂(x₂) = ?（3）联合 p(x) = ?（4）若 ε = 0.01，报警吗？

给定　p(x) = Πⱼ p(xⱼ)；1/√(2π) ≈ 0.399；1/√(8π) ≈ 0.200；e⁻² ≈ 0.135
显示答案与解析
答案：（1）0.399 × e⁻² ≈ 0.054；（2）0.200 × e⁻² ≈ 0.027；（3）p(x) ≈ 0.0015；（4）0.0015 < 0.01 → 报警

（1）x₁=2：(z/σ)² = 4 → p₁ = 0.399·e⁻² ≈ 0.054。（2）x₂=4：σ=2，(4/2)² = 4 → p₂ = 0.200·e⁻² ≈ 0.027。（3）独立性假设下连乘：p = 0.054 × 0.027 ≈ 0.00146。（4）低于 ε=0.01 → 异常。看点：每一维单独看都只是「有点偏低」（0.054 不算小），连乘后联合概率骤降——多维异常检测的威力正在于「多处轻微不对劲」的乘法放大。这也解释了 8.6 的坑：若两维强相关，独立性假设会失真，需要造组合特征。

8.6异常检测系统与特征

概念★★

四个任务：① 信用卡欺诈检测（历史欺诈样本 30 条，骗术层出不穷）；② 垃圾邮件过滤（已积累 10 万封标注邮件，垃圾邮件类型相对稳定）；③ 数据中心机器监控（故障罕见且形式多样）；④ 天气预报。适合用异常检测（而非监督学习）的是：

  1. A. ① ② ③
  2. B. ② 和 ④
  3. C. ① 和 ③
  4. D. 全部
显示答案与解析
答案：C

选型表两问：负样本多不多？未来的坏法像不像过去的？① ③ 负样本极少（0~50 条）且「新坏法」层出不穷——监督学习没有足够的反例可学，只能反过来学「正常长什么样」。② 负样本充足且形态稳定 → 监督分类；④ 是回归 / 分类任务，与异常无关。

概念★★

异常检测系统评估：数据里只有 0.1% 是异常。为什么不能用 accuracy，而要用 P / R / F1？

  1. A. 因为异常检测模型输出的是概率，没法算 accuracy
  2. B. 因为 accuracy 计算太慢
  3. C. 因为 P / R / F1 不需要标签
  4. D. 因为 accuracy 在这里会严重虚高——「永远报正常」的空模型也有 99.9% 准确率，却一个异常都抓不到
显示答案与解析
答案：D

倾斜数据集的老问题（呼应 6.7）：正例极少时 accuracy 被「全预测多数类」绑架。P（报警里多少真异常）与 R（真异常里抓到多少）各自盯着漏报误报，F1 = 2PR/(P+R) 一把尺子综合。C 错——P/R/F1 恰恰需要留出的带标签验证集；A 错——p(x) 与 ε 一比就是 0/1 判决。

概念★★★

异常检测系统上线后发现：某台真异常的机器 p(x) = 0.05，不报警（ε = 0.01）。课程给的「特征三招」不包括以下哪一项？

  1. A. 画直方图检查各特征是否近高斯；长尾的用 log(x)、√x、x² 等变换掰成钟形
  2. B. 分析漏网案例，为其造新特征（如 x₃ = x₁/x₂ 的比值特征）
  3. C. 目标是让正常样本 p 大、异常样本 p 小的两极分化
  4. D. 把 ε 一路调小，直到这台机器报警为止
显示答案与解析
答案：D

A、B、C 正是特征三招：变换非高斯、为漏网案例造特征、追求两极分化。D 是「为了考题改答案」——ε 只对验证集整体指标（F1）负责，为单个案例硬调 ε 会引入一大片误报。正确做法是回头改特征：让这台机器的「不对劲」在某个新维度上显形（比如 CPU / 磁盘负载的比值失衡）。

计算★★

验证集 10,000 台机器，其中 20 台真异常。系统共报警 50 次，其中 15 次命中真异常。（1）Precision = ?（2）Recall = ?（3）F1 = ?（4）「永远不报警」的模型 accuracy 是多少、F1 是多少？

给定　P = TP/(TP+FP)，R = TP/(TP+FN)，F1 = 2PR/(P+R)
显示答案与解析
答案：（1）0.30；（2）0.75；（3）≈ 0.43；（4）accuracy 99.8%，F1 = 0

TP = 15，FP = 50 − 15 = 35，FN = 20 − 15 = 5。（1）P = 15/50 = 0.30（报警里三成是真的）。（2）R = 15/20 = 0.75（真异常抓到四分之三）。（3）F1 = 2×0.30×0.75/(0.30+0.75) = 0.45/1.05 ≈ 0.43。（4）空模型 accuracy = 9980/10000 = 99.8%（看着很美），F1 = 0（一个异常都没抓到）——这一对数字就是「别用 accuracy」的最强论据。

9.1协同过滤：评分矩阵

概念★

推荐系统里的两个矩阵 Y 与 R 分别是：

  1. A. Y 是特征矩阵，R 是评分矩阵
  2. B. Y 是评分矩阵（用户 × 电影，格子里是打分），R 是同形状的 0/1 矩阵——标记该格「是否评过」（? 与数字的区别）
  3. C. Y 是评分矩阵，R 是相关系数矩阵
  4. D. 两者都是评分矩阵，只是转置关系
显示答案与解析
答案：B

Y⁽ⁱʲ⁾ = 用户 j 给电影 i 的分；R⁽ⁱʲ⁾ = 1 表示「评过」（该格参与训练），0 表示「?」（留待预测）。所有求和都带条件 (i,j): r(i,j)=1——没打分的地方既不算损失也不算均值。C 的 R 是 recycle 了一字母的干扰项。

图像★★

下图简化重绘自笔记图 9-1：评分矩阵与「特征已知 → 学用户参数」的思路。正确的读图结论是：

  1. A. 高分集中在左上、右下两个方块——评分矩阵自带「人群 × 口味」的结构；若电影特征已知，每个用户的 (w, b) 就是一个小线性回归，可预测 ? 格
  2. B. 矩阵里的 ? 是数据错误，应当删除
  3. C. Alice 和 Dave 的 (w, b) 应当完全相同，因为他们都是用户
  4. D. 该方法的前提是每部电影的特征向量由人工预先标注——特征哪来正是它的软肋
显示答案与解析

9.2协同过滤算法

概念★★

协同过滤的「妙手」在于让电影特征 x 与用户参数 w 互相学习。这句话的准确含义是：

  1. A. w 从 x 的特征值里直接读出来，不用训练
  2. B. x 和 w 各自独立训练，互不相干
  3. C. 固定 w 学 x、再固定 x 学 w，交替下降；最终把两者一起优化进同一个成本函数 J(w, b, x)
  4. D. 先训练完所有 w，再重新随机初始化 x
显示答案与解析
答案：C

电影特征由全体用户的口味合力学出（没有人工标注任何属性），用户参数由全体电影的评分学出——鸡生蛋、蛋生鸡，交替下降直到收敛。这就是 2009 年 Netflix 百万美元大奖的核心思想：整个评分矩阵自己解释自己。B/A/D 都割裂了两条互相喂养的线。

概念★★

协同过滤成本 J = ½Σr(i,j)=1(w·x + b − y)² + (λ/2)Σ‖w‖² + (λ/2)Σ‖x‖²。两处正则项各自惩罚谁、防止什么？

  1. A. 两项都惩罚 w，写两遍是为了对称好看
  2. B. 一项管用户参数 w、一项管电影特征 x——同时防止两组参数被个别高分撑得过大（过拟合）
  3. C. 两项都惩罚评分 y，让评分更平滑
  4. D. 正则项惩罚偏置 b，防止截距过大
显示答案与解析
答案：B

与第 3 章的正则化同一个思想，只是现在有两组可学参数：Σⱼ‖w⁽ʲ⁾‖² 管全体用户、Σᵢ‖x⁽ⁱ⁾‖² 管全体电影。求和只对 r(i,j)=1 的格子（评过的才算数）。y 是数据不是参数（C 错）；b 通常不正则（D 错）。

计算★★

「找相似电影」：电影 A 的特征 x⁽ᴬ⁾ = [0.9, 0.1]，电影 B 的 x⁽ᴮ⁾ = [0.8, 0.2]，电影 C 的 x⁽ᶜ⁾ = [0.1, 0.9]。（1）‖x⁽ᴬ⁾ − x⁽ᴮ⁾‖² = ?（2）‖x⁽ᴬ⁾ − x⁽ᶜ⁾‖² = ?（3）用户看过 A，「因为你看过 A」该推 B 还是 C？

给定　相似度 = 距离平方 ‖x⁽ⁱ⁾ − x⁽ᵏ⁾‖²，越小越相似
显示答案与解析
答案：（1）0.02；（2）1.28；（3）B

（1）(0.9−0.8)² + (0.1−0.2)² = 0.01 + 0.01 = 0.02。（2）(0.9−0.1)² + (0.1−0.9)² = 0.64 + 0.64 = 1.28。（3）A→B 距离远小于 A→C → 推 B。学出来的特征空间里「爱情片挨着爱情片」——协同过滤的副产品：相似推荐不需要任何人工分类。

概念★★★

把协同过滤从「评 0~5 星」搬到「点赞 / 点击 / 停留」（二元标签）时，正确的改造是：

  1. A. 无法改造，协同过滤只支持星级评分
  2. B. 把平方差损失换成第 3、5 章同款的交叉熵（对数损失）——骨架不变，损失换皮
  3. C. 必须先把点赞转成 5 星评分才能训练
  4. D. 换成交叉熵后，w 与 x 就不用交替学习了
显示答案与解析
答案：B

「0/1 结果用对数损失」的课程铁律在推荐系统原样生效：J = Σ 交叉熵项 + 两组正则。交替学习的骨架（w 与 x 互为标签）完全不变（D 错）。现代推荐系统的真实标签大多是点击 / 停留这类隐式反馈——这一步改造是从课程走向工业的关键一步。

9.3均值归一化

概念★★

一个从没评过任何电影的新用户（评分行全是 ?），直接扔进协同过滤训练会发生什么？

  1. A. 他的 w 会随机初始化到某个老用户身上
  2. B. 系统自动给他推荐热门电影
  3. C. 他的 w 没有任何梯度信号 → 学成 0 → 所有电影预测 0 分，永远推荐不出东西
  4. D. 训练会报错终止
显示答案与解析
答案：C

成本函数只对 r(i,j)=1 的格子求和——他的格子全是 0，损失项为零，梯度为零，正则项又把 w 往 0 拉 → w = 0，预测全 0。零数据 → 零参数 → 零推荐。B 是我们「希望」系统做的，但要靠均值归一化才能实现；D 不会——只是安静地失效。

概念★★

均值归一化的具体做法与效果是：

  1. A. 删除评分最少的用户
  2. B. 每个用户减去自己的均分——效果一样，习惯不同
  3. C. 把所有评分线性缩放到 [0,1]
  4. D. 每部电影先减去自己的均分，在去均值后的矩阵上训练；预测时再加回 μ_i——零数据用户对每部电影的预测 = 该电影的均分
显示答案与解析
答案：D

沿电影（物品）方向归一化：y − μ_i。零数据用户的 w 仍学成 0，但预测 0 + μ_i = 该电影均分——新用户先推大众口碑片，而不是清一色 0 分。B 方向反了：按用户归一化的话，零数据用户的均分没有定义（他没有评分）；C 是特征缩放，不解决零数据；A 是逃避问题。

计算★★★

电影 1 收到四个评分：5, 3, 4, 4（还有一个 ?）。（1）μ₁ = ?（2）均值归一化后这四个评分变成多少？（3）从未评分的新用户 Eve 对电影 1 的最终预测分 = ?（4）如果没有均值归一化，Eve 的预测是多少、后果是什么？

给定　μ_i = 该电影已评分数的均值；预测 = 模型输出 + μ_i
显示答案与解析
答案：（1）4；（2）+1, −1, 0, 0；（3）4 分（该电影均分）；（4）预测 0 分——电影被排到队尾，永远推不出去

（1）μ₁ = (5+3+4+4)/4 = 4。（2）5−4=+1，3−4=−1，4−4=0，4−4=0。（3）Eve 的 w 学成 0 → 去均值预测 0 → 加回 μ₁ = 4——大众口碑分。（4）无归一化则预测 0，一部 4 分好评片在 Eve 的候选列表里垫底——冷启动用户被系统性推出空推荐，这正是均值归一化要修的 bug。

概念★★

协同过滤的「冷启动」软肋与内容过滤（content-based）的解法，正确的配对是：

  1. A. 两者没有区别，只是名字不同
  2. B. 软肋：训练太慢；解法：内容过滤用更少的参数
  3. C. 软肋：只能推荐电影；解法：内容过滤能推荐任何商品
  4. D. 软肋：新电影没有任何评分 → 特征学不出来；解法：内容过滤吃电影的真实属性（类型 / 导演 / 演员 / 简介），不依赖历史评分

  1. A. 语义可迁移——同一套 embedding 既能推荐也能搜索、聚类做相似品
  2. B. 冷启动缓解——新电影没有评分，但有文本与图像，照样算 v_m
  3. C. 与第 5、6 章完全同构的训练循环（Adam + 小批量 + 早停），工程栈复用
  4. D. 训练完全不需要任何历史行为数据
显示答案与解析

A、B、C 正是笔记列的三点红利。D 夸大了：内容过滤缓解的是物品侧冷启动（新电影有属性可编码），但训练仍然需要用户的观看 / 点击历史当正负样本——「用户喜欢什么」这件事没有行为数据就无从学起。

概念★★★

  2. B. 算法没有恶意，所以工程师没有责任
  3. C. 放大效应只是理论问题，真实系统观测不到
  4. D. 只要准确率高，伦理问题自然消失
显示答案与解析
答案：A

算法没有恶意，但目标函数有盲区：它反映口味的同时也在塑造口味。协同过滤没有语义，刷量刷好评即可操纵排名；内容过滤能把「看过一次」发酵成信息茧房。B 是推卸：目标函数是工程师写的；C 与 CTR 优化的诸多实证相悖；D 是唯指标论——指标恰是问题的一部分。

9.6主成分分析 PCA

概念★★

PCA 与线性回归「最小化距离」的根本区别是：

  1. A. 没有区别，两者是同一算法
  2. B. 线性回归最小化竖直距离（沿 y 方向到直线的残差）；PCA 最小化正交距离（点到主轴的垂直投影距离）
  3. C. PCA 最小化竖直距离，线性回归最小化正交距离
  4. D. PCA 不最小化任何距离，它最大化距离
显示答案与解析
答案：B

线性回归有明确的 y（标签），误差只算「预测 y 与真实 y 的竖直差」；PCA 没有 y，把所有维度一视同仁，误差是点到投影轴的正交距离。等价说法：PCA 找的是使投影后方差最大的方向。两件事形似而神异——考试与面试的高频陷阱。

图像★★

下图简化重绘自笔记图 9-3 左图：2D → 1D 的 PCA 投影。正确的读图结论是：

  1. A. 红点是蓝点在主轴 u₁ 上的正交投影；虚线段是被「丢掉」的垂直噪声；主轴方向 = 投影后方差最大的方向
  2. B. 红点是蓝点竖直下落的投影，和线性回归一样
  3. C. 主轴方向由数据的均值决定
  4. D. 蓝点必须先归一化才能画在这张图里
显示答案与解析
答案：A

读图两件套：投影方向正交于主轴（B 是线性回归的投影方式）；主轴选「投影后方差最大」（C：均值只定中心 μ，不定方向）。降维流程 z = u·(x−μ)，k 的选择看保留方差百分比（99% 常用）；μ 与主轴都只能用训练集估计（别用测试集拟合！）。D：特征缩放是常见的预处理（尤其量纲悬殊时），但不是这张图的必要条件。

概念★★

PCA 的三个正当用途与一个常见误用。其中误用是：

  1. A. 50 维特征降到 2 维做可视化
  2. B. 训练太慢，先降维再跑监督学习（用训练集拟合 PCA）
  3. C. 用来防止过拟合——降掉一些维度就少一些参数
  4. D. 图像压缩与去噪（特征脸实验）
显示答案与解析
答案：C

防过拟合请先试正则化——它直接针对「参数太多」建模，PCA 只是无监督地压方差，压掉的可能恰是判别信息。吴恩达的忠告：把 PCA 当防过拟合工具是最常见的误用，应作为最后手段。A、B、D 是课程点名的三大正当用途（B 注意只用训练集拟合 PCA）。

计算★★★

二维数据的均值 μ = (1, 1)，第一主轴 u₁ = (0.6, 0.8)。（1）样本 x = (3, 4) 去均值后的向量 = ?（2）投影 z₁ = u₁·(x−μ) = ?（3）z₁ 的几何含义是什么？（4）若保留 99% 方差需要 k=2 而 k=1 只剩 90%，该取几？

给定　z = u · (x − μ)；u₁ 已单位化
显示答案与解析
答案：（1）(2, 3)；（2）3.6；（3）x 在主轴上的坐标（一维表示）；（4）k=2

（1）x − μ = (3−1, 4−1) = (2, 3)。（2）z₁ = 0.6×2 + 0.8×3 = 1.2 + 2.4 = 3.6。（3）二维点被压成一个数：它在主轴方向上的「位置」——重建时 x̂ ≈ μ + z₁·u₁，丢掉的只是垂直分量。（4）经验法则保留 99% 方差：k=1 的 90% 不够 → 取 k=2（此时 PCA 无压缩意义，但这是数据本身的话）。

10.1什么是强化学习

概念★

强化学习与监督学习的根本区别，一句最准确的话是：

  1. A. 强化学习不需要训练数据
  2. B. 监督学习每条数据配正确答案 y（批改作业）；强化学习只有奖励信号（做对了给零食）——从「做了之后好不好」里自己悟出该做什么
  3. C. 强化学习比监督学习更先进，总能取得更好效果
  4. D. 监督学习用 CPU，强化学习用 GPU
显示答案与解析
答案：B

教小狗握手的类比：没人教它每块肌肉怎么收缩，做对了给零食。直升机特技飞行没有「每片旋翼该多少转」的标准答案，只有「飞得好不好」。A 错——RL 的数据是试错轨迹；C 是常见误解——RL 商业部署远少于监督学习（见 10.7）；D 无关紧要。

图像★★

下图简化重绘自笔记图 10-1：智能体与环境的交互循环。正确的读图结论是：

  1. A. 环境返回的是每个动作的正确取值
  2. B. 上行箭头发送动作 a；下行箭头返回新状态 s′ 和奖励 R——回程带的不是正确答案 y，这是与监督学习唯一的结构性差别
  3. C. 策略 π 是环境的一部分
  4. D. 智能体可以直接观察环境的内部参数
显示答案与解析
答案：B

整个 RL 就这四样东西的循环：状态 s →（策略 π）→ 动作 a →（环境）→ 新状态 s′ + 奖励 R。环境从不告诉智能体「最优动作是什么」，只给分数（A 错）；π 属于智能体（C 错）；D 错——智能体只拿到 s′ 与 R，环境内部（转移概率）是黑盒。

概念★★

RL 术语配对：① 状态 s；② 动作 a；③ 奖励 R；④ 回报 G；⑤ 策略 π(s)。下列配对全部正确的是：

  1. A. ① 智能体可做的事；② 环境当前情形；③ 折扣累计；④ 即时打分；⑤ 转移概率
  2. B. ① 环境当前情形；② 智能体可做的事；③ 即时打分；④ 折扣后的累计奖励；⑤ 状态 → 动作的规则
  3. C. ①③④ 是一回事，都指奖励
  4. D. ⑤ 是环境到状态的映射
显示答案与解析
答案：B

五件套一句话：看到状态（火星车在几号格），按策略挑动作（向左 / 向右），环境给奖励（+100 / +40 / 0），把沿途奖励打折加总成回报 G。R 是「眼前一步的零食」，G 是「整条路线的总账」——别混（C）；π 是智能体自己的规则（D）。

概念★★★

四个任务：① 用历史股价数据预测明日收盘价；② 数据中心冷却系统的实时调度（做完才知道能耗高低）；③ 手写数字识别；④ 机械臂学习抓取（每次抓取成功与否可测）。适合强化学习的是：

  1. A. ① 和 ③
  2. B. ② 和 ④
  3. C. ① ② ④
  4. D. 全部
显示答案与解析
答案：B

判据：有没有「做了之后才知道好坏」的反馈闭环。② 调度决策 → 能耗反馈；④ 抓取动作 → 成功 / 失败反馈——都是「从奖励中学」。① 有带标签的历史数据 → 监督回归；③ 有标注图片 → 监督分类。注意 ① 容易误判成 RL：「预测」不是「决策」，没有环境交互闭环。

10.2火星车、回报与折扣

概念★

折扣回报 G = Σ γᵏ⁻¹R_k 中折扣因子 γ ∈ [0,1) 的作用，下列哪组说法全部正确？

  1. A. γ 越大越近视；γ 的作用是加快训练
  2. B. γ 越小越「近视」（眼前的奖励越值钱）；γ 保证无限长序列收敛成有限值；未来不确定（机器人可能中途坏掉），早到的奖励更可靠
  3. C. γ 必须严格等于 1 才公平
  4. D. γ 是学习率的一种
显示答案与解析
答案：B

γ 是「远见的旋钮」，三重身份：偏好调节（γ↑ 更远视）、数学收敛（γ<1 使无穷级数有界）、风险折价（未来可能被中断）。课程常用 0.9~0.99。C：γ=1 时无限序列可能发散；D：γ 折的是奖励的时间，α 是参数步长——完全两码事。

图像★★

下图简化重绘自笔记图 10-2：火星车的世界。按图读数，若 γ = 0.9，从状态 4 出发两条路线的回报各是多少？

  1. A. 向左 G = 0.9×100 = 90；向右 G = 0.81×40 = 32.4
  2. B. 向左 G = 100；向右 G = 40 → 向左（不打折）
  3. C. 向左 G = 0.81×100 = 81；向右 G = 0.9×40 = 36 → 向左更优

10.3状态-动作值函数

概念★★

  2. B. 在状态 s 执行动作 a 得到的即时奖励
  3. C. 在状态 s 执行动作 a、此后每一步都执行最优动作所获得的折扣回报——「先走这步、后面全走最优，总共能拿多少」
  4. D. 状态 s 本身的价值，与动作无关
显示答案与解析
答案：C

Q 是一张报价单：每个 (s, a) 格子报一个价——这步走 a、之后全走最优的总回报。B 只是眼前的 R（Q 的一部分）；A 是另一种函数（平均策略下的值）；D 是状态值函数 V(s)。有了 Q 表，策略一步读出：π(s) = argmaxa Q(s,a)。学强化学习 ≈ 学这张表。

10.4Bellman 方程

概念★★

Bellman 方程 Q(s,a) = R(s′) + γ·maxa′ Q(s′,a′) 被称为「Q 自己定义自己」。它的本质是：

  1. A. 一条只对终止状态成立的边界条件
  2. B. 用未来的 Q 去更新过去的 Q，方向说反了
  3. C. 把「无限期的未来」拆成「眼前一步 + 折扣后的下一格最优报价」——递归自指，整张 Q 表是这同一个方程的联立解
  4. D. 一种神经网络结构
显示答案与解析
答案：C

动态规划的最优子结构在决策问题上的化身：一步的报价 = 眼前奖励 + γ×(下一状态的最优报价)。对每个 (s,a) 各写一条方程，联立求解（笔记的循环刷表代码就是迭代解这个方程组）。B：方向没错，从「更靠近终点」的格子往回传染正确性；A：终止态恰是「max 项取 0」的特例；D：DQN 是 10.6 用网络近似这张表的手段。

  1. A. 格 3 相加的结果是即时奖励 100
  2. B. 格 2 里的 50 是 Q(4,→)，不是 Q(3,·) 的最大值

答案：C

三格读法：R(s′=3)=0（注意课程把奖励记在到达的状态上）＋ 0.5×max Q(3,·)=25 → Q(4,←)=25。B：50 是 max(Q(3,←), Q(3,→)) = max(50, 12.5) = 50，取的是下一格的最优；A：100 要再走两步才有，且要打折两次；D：向右同样适用：Q(4,→) = R(5) + 0.5×max Q(5,·) = 0 + 0.5×40 = 20。

概念★★★

火星车「打滑版」：选「左」只有 0.9 概率左移、0.1 滑向右。随机环境（MDP）下的 Bellman 方程如何修改？

  1. A. 在奖励上直接乘 0.9 即可，与下一状态无关
  2. B. 把 γ 换成 P(s′|s,a)
  3. C. 随机环境下 Bellman 方程不再成立
  4. D. 右端对可能的下一状态 s′ 按转移概率 P(s′|s,a) 取期望：Q(s,a) = Σs′ P(s′|s,a)·[R(s′) + γ·max Q(s′,·)]；确定版只是 P 取 one-hot 的特例
显示答案与解析
答案：D

决策问题升级为马尔可夫决策过程（MDP）：转移从确定变成概率分布，方程从「单点取值」变成「加权平均」——每个可能的 s′ 都贡献一份「概率 × (奖励 + 折扣最优报价)」。B 混淆了折扣（时间）与概率（随机）；C：方程形式仍成立，只是取了期望；A 只对「打滑后恰好到达的格子」打折，漏算了另一条支路。

10.5连续状态与月球着陆器

概念★★

月球着陆器的状态是 8 维连续向量（位置、速度、角度、角速度、两条腿是否触地），动作是 4 档喷射。为什么「查 Q 表」在这里彻底失效、课程给出的对策是什么？

  1. A. 失效是因为奖励太稀疏；对策：多发奖励
  2. B. 表太大内存放不下；对策：用更大的硬盘
  3. C. 连续状态没法度量距离；对策：先离散化成 6 格
  4. D. 状态空间 ℝ⁸ 无穷多、表永远列不完；对策：让神经网络当「Q 表的插值器」——输入 s，输出各动作的 Q 值
显示答案与解析
答案：D

火星车 6 个格子用表刚好；ℝ⁸ 里的状态「数不过来也存不下」——不是硬件问题而是数学问题（B）。神经网络的泛化能力恰好补位：相邻状态共享同一套参数，见过的状态能给没见过的状态「报价」（插值）。C 的离散化在低维勉强可行、8 维会遭遇维度灾难；A 说的是另一个困难（稀疏奖励），不是查表失效的原因。

  1. A. 没有，失败会污染经验池导致网络学坏
  2. B. 没有，失败的轨迹应当全部丢弃
  3. C. 有，但必须先等策略达到 50% 成功率
  4. D. 有——每条轨迹（无论成败）都在积累 (s, a, R, s′) 经验；摔得多的姿势恰好标记出「哪些动作报价该调低」，训练数据全靠模拟器试错
显示答案与解析
答案：D

RL 的冷启动哲学：试错本身就是数据。摔进经验池的 (s, a, R, s′) 告诉网络「这个状态下这个动作的报价该往下修」——失败被梯度消化成知识。这正是与监督学习最大的不同：没有人给你「正确动作」，只有环境的打分。B/A 把失败当噪声丢掉，等于扔掉大半训练信号；C 陷入鸡生蛋（策略变好需要先学习，学习需要先试错）。

10.6深度 Q 学习

概念★★

DQN 网络的设计：输入 8 维状态，输出层 4 个单元（线性）。这样设计的用意是：

  1. A. 一次前向传播同时算出 4 个动作的报价 Q(s,a₁)…Q(s,a₄)，选动作 = argmax 输出层——比「跑 4 次网络」快，也让动作间的比较共享同一套特征
  2. B. 4 个输出是状态价值的 4 次独立估计
  3. C. 输出层必须接 softmax 变成概率
  4. D. 只是工程习惯，输出 1 个数再循环 4 次完全等价
显示答案与解析
答案：A

把「Q 表的一列」打包成一次前向：Dense 64 → 64 → 4。选动作（argmax）与算目标（对下一状态取 max）都一次搞定。B：4 个输出对应 4 个不同动作的报价，不是同一量的重复测量；C：Q 值是「报价」不是概率，无界且不归一（softmax 会破坏 Bellman 的加法结构）；D：等价的是数学，不等价的是效率与共享特征。

10.7算法精化与现状

概念★★

课程点名的三件「稳定器」与各自治的病，配对正确的是：

  1. A. ε-greedy 探索（ε 从 ~1 衰减到 0.01）治「早熟锁死次优路线」；小批量 + 经验回放治「样本浪费与时序相关」；软更新（τ≈0.001）治「目标漂移导致的震荡」
  2. B. ε-greedy 治过拟合；经验回放治欠拟合；软更新治梯度爆炸
  3. C. 三件都是为了提高准确率
  4. D. ε 固定不衰减才是最佳实践
显示答案与解析
答案：A

三件套各自的病根：① 只会贪心（argmax）会被初期运气锁进次优路线——ε 的随机探索保住可能性，随训练衰减（先广泛试、后精深用）；② 一条轨迹里的经验强相关且只用一次——回放池随机抽批量，老经验反复用；③ 已见 10.6。B/C：RL 没有「准确率」这个直接指标；D：ε 不衰减 = 永远抽风，学成也用不好。

概念★★

关于 RL 的现状，符合课程「冷静盘点」的是：

  1. A. 成熟战场在模拟与游戏（AlphaGo 自我博弈超人）；机器人与过程控制（数据中心冷却降耗约 40%）快速逼近实用；但商业部署总量仍远少于监督学习
  2. B. RL 已全面取代监督学习
  3. C. RL 无法在真实世界产生任何价值
  4. D. RL 的样本效率比监督学习高得多
显示答案与解析
答案：A

课程收官的清醒账本：模拟器便宜的领域（游戏、弈棋）已经超人；真实世界三大拦路虎——试错样本昂贵（真车不能拿去撞）、奖励难设计（怎么给「公平」打分？）、模拟器难造。B/C 两个极端都错；D 恰相反：RL 要千万次试错，样本效率远低于监督学习。

概念★★★

接到一个新项目，判断「该不该用 RL」的课程两问是：

  1. A. ① 模拟器免费吗（能不能低成本大量试错）？② 奖励写得出来吗（好坏能不能翻译成数字）？——两问有一个「否」，先回去用监督学习
  2. B. ① 数据多吗？② GPU 多吗？
  3. C. ① 有没有标签？② 模型够不够大？
  4. D. ① 竞争对手用不用 RL？② 论文里 RL 效果好不好？
显示答案与解析
答案：A

选型直觉的收口：手里有大量 (x, y) 历史数据 → 优先监督学习（第 1~7 章）；只有「做了之后才知道好坏」的反馈 → 才轮到 RL，且先过两问。模拟器贵（真车试错）或奖励写不出（「公平」「有用」难量化）都会让 RL 寸步难行。B/C 是监督学习时代的问题清单；D 是跟风不是决策。

① 连续值输出 → 回归（第 1 章）；② 0/1 标签 → 二分类（第 3 章）；③ 无 y 找结构 → 聚类（第 8 章）；④ 正例极少且未来故障形态未知 → 异常检测，用正常样本建模（第 8 章）；⑤ 只有奖励信号、没有标签 → 强化学习（第 10 章）；⑥ 评分矩阵稀疏 → 推荐系统（第 9 章）。C 是最常见的坑：K-means 处理不了「故障只有 10 个点」的极端不平衡，而异常检测天生为此而生。

概念★

公式 w := w − α·∂J/∂w 在线性回归、逻辑回归、神经网络的训练里反复出现。关于它，正确的是：

  1. A. α 越大收敛越快，所以永远选大 α
  2. B. 它只适用于线性回归，逻辑回归要用另一套完全不同的优化方法
  3. C. 它是梯度下降的通用更新模板：三种算法都用它（换成 Adam 前的区别只是 J 的形状——平方误差 / 交叉熵 / 层层复合的交叉熵——导致 ∂J/∂w 的表达式不同）；对 b 同样有 b := b − α·∂J/∂b
  4. D. 该公式只更新 w；b 必须靠别的机制更新
显示答案与解析
答案：C

这是贯穿第 1、3、5 章的「同一招」：定义 J，算梯度，沿负梯度小步走。B 错——逻辑回归只是把损失换成交叉熵，梯度下降照用（3.4 节）；A 错——α 过大会越过谷底来回震荡甚至发散（1.5 节）；D 错——b 与 w 同步更新，只是 b 的梯度少掉 x 那一项。

概念★★

正则化参数 λ 出现在线性回归、逻辑回归与神经网络里。关于 λ 的说法，正确的是：

  1. A. λ 调大可以同时治高偏差和高方差
  2. B. b 也必须一起正则化，否则公式不成立
  3. C. 正则化是神经网络专属，线性 / 逻辑回归没有这个机制
  4. D. λ 调大 → 惩罚项压小各 w → 模型更平滑，治高方差；λ 过大 → 欠拟合（高偏差）；λ = 0 退回普通拟合；正则项只罚 w、不罚 b
显示答案与解析
答案：D

λ 的旋钮方向要背熟：方差大 → 升 λ；偏差大 → 降 λ（第 3、6 章）。A 不可能——λ 压小 w 使模型变简单，只会把方差往下、偏差往上推，一石二鸟不存在。B：惯例不罚 b（少一个参数无伤大雅，且不罚也照样有效）。C 显然错：J + (λ/2m)Σw² 对三类模型通用。

概念★★

关于训练集 / 交叉验证集 / 测试集的使用纪律，错误的做法是：

  1. A. 数据量小按 6 : 2 : 2 切分；百万级数据可以 98 : 1 : 1，甚至更极端
  2. B. 误差分析应该在测试集上做，因为测试集最像真实数据
  3. C. 测试集只在最后「上线前」评估用一次；拿它反复挑模型等于偷看答案
  4. D. 训练集全是网图、验证集全是手机实拍，这种分布错位会拖累效果——验证集要贴近部署环境
显示答案与解析
答案：B（错误做法）

误差分析、调超参、选模型都在训练集 + 交叉验证集上循环（第 6 章的迭代循环）；测试集是「封存的期末考」，碰多了它就退化成第二个验证集，给出的分数虚高。A、C、D 都是课程原话：切分比例随数据量伸缩；测试集一次性使用；训练 / 验证分布要一致（著名的「网图猫 vs 手机猫」教训）。

概念★★

「无监督学习」的边界辨析：K-means、PCA、异常检测、协同过滤。正确的是：

  1. A. K-means（找簇结构）、PCA（保方差降维）、异常检测（建模正常密度）三者都不用标签 y；协同过滤其实「有标签」——评分矩阵里已知的评分就是它要拟合的 y，只是标签极度稀疏
  2. B. 四者全都不用标签，全是无监督学习
  3. C. 异常检测是监督学习，因为报警最终要人工确认
  4. D. PCA 需要标签才能选出主成分
显示答案与解析
答案：A

辨析题的坑就在协同过滤（第 9 章）：它看起来像无监督，但「已知评分」确实扮演了 y 的角色——协同过滤更像自监督：用已有评分互相当标签（w 与 x 互为老师）来学出用户 / 商品向量，再去预测缺失评分。异常检测虽然最后有人工复核，训练阶段只喂正常样本（无标签）。PCA 完全不需要 y——它只找方差最大的方向。

概念★★★

损失函数大乱斗。五个损失函数：① J = (1/2m)Σ(f(x(i)) − y(i))²；② J = −(1/m)Σ[y(i)log f(x(i)) + (1−y(i))log(1−f(x(i)))]；③ J = (1/m)Σ‖x(i) − μc(i)‖²；④ J = ½Σ(i,j)∈R(y(i,j) − (w(j))ᵀx(i))² + λ(Σ‖x(i)‖² + Σ‖w(j)‖²)；⑤ J = (y − Q(s,a))²。与算法的正确配对是：

  1. A. ① 逻辑回归　② 线性回归　③ K-means　④ 协同过滤　⑤ DQN
  2. B. ① 线性回归　② 逻辑回归　③ K-means（失真函数）　④ 协同过滤（双重正则）　⑤ DQN（Q 学习）
  3. C. ① 线性回归　② 逻辑回归　③ 异常检测　④ K-means　⑤ 协同过滤
  4. D. ① 线性回归　② 逻辑回归　③ K-means　④ DQN　⑤ 协同过滤
显示答案与解析
答案：B

看三处指纹即可破案：平方误差 + 1/2m 是线性回归（第 1 章）；log 组合的交叉熵 是逻辑回归（第 3 章）；③ 量的是「每个点到其所属中心 μ 的距离平方」——K-means 的失真 J（第 8 章）；④ 有两套参数同时被正则（用户向量 w 与商品向量 x），只可能是协同过滤（第 9 章）；⑤ (y − Q)² 是 DQN 用 Bellman 目标 y 当回归标签的 MSE（第 10 章）。一个损失函数就是一种算法的 DNA。

softmax 三步（第 5.3 节）：逐项取指数 → 求和 → 相除。e² ≈ 7.39，总和 = 7.39 + 1 + 1 = 9.39，a₁ = 7.39/9.39 ≈ 0.79，a₂ = a₃ ≈ 0.11。三个输出自动归一成概率分布（和恒为 1），这是它当多分类输出层的本钱。D 是把 sigmoid 硬套到每一维——各算各的，和是 1.88 不是 1，没法当「三选一」的概率用；B 忘了除以总和；A 想当然。顺带复习：TF 里写 from_logits=True、输出层用 linear，把 softmax 留给损失函数内部做，是为了数值稳定（5.3 节）。

计算★★

一维高斯异常检测：特征「风扇转速偏差」在正常机上服从 N(μ=0, σ²=1)。① 转速偏差 x = 2 的 p(x)？② x = 1 的 p(x)？③ 若阈值 ε = 0.1，哪台机器被标记异常？

给定　p(x) = (1/√(2π))·e^(−(x−μ)²/2)；1/√(2π) ≈ 0.399; e⁻² ≈ 0.135; e⁻⁰·⁵ ≈ 0.61; ε = 0.1
  1. A. ① p(2) ≈ 0.399×0.135 ≈ 0.054；② p(1) ≈ 0.399×0.61 ≈ 0.24；③ x = 2 的机器异常（0.054 < 0.1），x = 1 的正常（0.24 > 0.1）
  2. B. ① 0.054；② 0.24；③ 两台都异常，因为 p 都小于 1
  3. C. ① p(2) ≈ 0.399×e⁻⁴ ≈ 0.0073 异常；② p(1) ≈ 0.399×e⁻¹ ≈ 0.147 也异常
  4. D. ① p(2) ≈ 0.054；② p(1) ≈ 0.24；③ x = 1 的机器异常（p 更大说明波动更大）
显示答案与解析
答案：A

套钟形公式（第 8.5 节）：指数部分是 −(x−μ)²/2，别漏了「平方再除 2」——x = 2 → e⁻²，x = 1 → e⁻⁰·⁵。p(2) ≈ 0.054 < ε = 0.1 → 亮红灯；p(1) ≈ 0.24 > 0.1 → 放行。判决方向是「p 小于 ε 才异常」——离均值越远 p 越小（D 把方向看反了）；C 把指数记成 −(x−μ)²（忘了除 2）；B 的「p < 1」没有意义，ε 才是门槛。多特征时把各维概率连乘（或用多元高斯），这一题是一维的骨架。

计算★★★

决策树信息增益手算（课程原版数据）：10 只动物，5 猫 5 狗。按「耳朵形状」分裂：尖耳朵 5 只（4 猫 1 狗），垂耳朵 5 只（1 猫 4 狗）。① 分裂前的熵？② 分裂后的加权熵？③ 该分裂的信息增益？

给定　H(p) = −p·log₂p − (1−p)·log₂(1−p)；log₂0.8 ≈ −0.322; log₂0.2 ≈ −2.322
  1. A. ① 1 bit；② 0.722 bit；③ IG = 0.722 bit（分裂后的熵就是增益）
  2. B. ① H(0.5) = 1 bit；② H(0.8) ≈ 0.722，左右各占一半 → 加权熵 ≈ 0.722 bit；③ IG = 1 − 0.722 ≈ 0.278 bit
  3. C. ① 0.722 bit；② 0.722 bit；③ IG = 0（前后一样，白分裂）
  4. D. ① 1 bit；② 0.5 bit（左右都被当成 4:1 纯净簇算错）；③ IG = 0.5 bit
显示答案与解析
答案：B

三步走（第 7.2–7.3 节）：① 五五开是最混乱的分布，H = −(0.5×(−1) + 0.5×(−1)) = 1 bit；② 每一侧 4:1，H(0.8) = −(0.8×(−0.322) + 0.2×(−2.322)) = 0.258 + 0.464 ≈ 0.722，加权 = (5/10)×0.722 + (5/10)×0.722 = 0.722；③ IG = 分裂前 − 分裂后 = 1 − 0.722 ≈ 0.278 bit。A 把「分裂后熵」直接当增益——信息增益必须做减法；C 把第一步的熵就写成 0.722；D 想象成了 4:0 的完美分裂。贪心建树每一层都算各特征 IG、挑最大的那个特征开刀（7.3 节）。

计算★★★

Q 学习一步更新手算：当前 Q(s, a) = 3；执行 a 得奖励 r = 1，进入 s′，s′ 上所有动作的最大 Q 值 maxₐ′ Q(s′, a′) = 2。① Bellman 目标 y = ? ② 用学习率 α = 0.1 做一次梯度下降后的新 Q(s, a) = ?

给定　y = r + γ·maxₐ′Q(s′,a′)；Q := Q − α·(Q − y)；γ = 0.9; α = 0.1
  1. A. ① y = 1 + 2 = 3；② Q_new = 3（目标与旧值相等，无需更新）
  2. B. ① y = 2.8；② Q_new = 2.8（一步把旧值直接替换成目标）
  3. C. ① y = 2.8；② Q_new = 3 − 0.1×3 = 2.7（梯度写成 Q 本身）
  4. D. ① y = 1 + 0.9×2 = 2.8；② Q_new = 3 − 0.1×(3 − 2.8) = 3 − 0.02 = 2.98
显示答案与解析
答案：D

Bellman 目标（第 10.4 节）：y = r + γ·maxₐ′Q(s′,a′) = 1 + 0.9×2 = 2.8——「眼下的奖励 + 打折后的最好未来」。更新（10.5 节）不是一步到位，而是朝目标挪一小步：Q := Q − α(Q − y) = 3 − 0.1×0.2 = 2.98。B 是 α = 1 的特例——每次硬着陆到目标上，训练会震荡；A 忘乘折扣 γ；C 把 (Q − y) 写成了 Q。DQN 里这一步换成「神经网络 + 软更新」（新网络 := (1−τ)·旧 + τ·目标网络），思想同源：小步走，稳着走（10.6 节）。

X.4场景选型 · 诊断与处方

概念★★

视频网站的新用户「小李」刚注册、一条评分都没有，协同过滤模型对他该输出什么？正确的工程做法是：

  1. A. 强制要求注册时先评满 30 部电影，否则不给用
  2. B. 直接输出全 0 分：没有信息就是零分，列表尾部也无所谓
  3. C. 用均值归一化：从评分矩阵里逐电影减去均分、再训练；对没任何行为的新用户，预测值落回电影均分——冷启动先推「大众口碑榜」，等他评过几部，协同过滤的个性化再接管
  4. D. 把他「没看过」的电影一律当 0 分负样本训练
显示答案与解析
答案：C

冷启动是协同过滤的命门（第 9.4 节）：全零预测会把新人永远钉在推荐列表的末尾（B 的方案等于劝退）；均值归一化让新人从「每部电影的平均分」起跳，至少能推热门佳作，行为数据积累后他自己的 w⁽ʲ⁾ 逐渐学出来。A 是产品自杀式设计；D 是推荐系统最经典的冤案——「没评分」≠「不喜欢」，用户只是还没遇到它（9.1 节反复强调 R 矩阵里 0 的含义是「没评过」）。

概念★★

信用卡反欺诈：历史数据 2 万条正常交易 + 40 条已确认欺诈，而且骗子的手法每月都在翻新。课程会建议：

  1. A. 异常检测：只用海量正常交易拟合高斯 p(x)，p < ε 就报警——正例太少喂不饱监督学习；新骗术「长得不像」旧骗术，反而更可能落在低密度区，恰好被抓住
  2. B. 逻辑回归：把 40 条欺诈当正例训练，40 条也够了
  3. C. K-means：把 2 万条交易聚成几类，异常的自然会被分出来
  4. D. 强化学习：让风控系统在线上边试错边学习
显示答案与解析
答案：A

第 8.5 节的选型分水岭：已标记异常「数量多」且「未来长得像过去」→ 监督学习；正例少 / 形态会进化 → 异常检测。两个条件此题全踩在异常检测一侧：40 个正例连逻辑回归的决策边界都撑不稳（B）；K-means 拿到的指令是「把 2 万条正常切成几堆」，簇心描述的是正常交易的日常形态，与那 40 条骗术无关（C）；D 文不对题——没有「动作 → 奖励」的序列交互结构。若题目改成「历史上有 1 万条标注欺诈、且骗术代代相传」，答案才翻向监督学习。

概念★★

你要做「车间里有没有戴安全帽」的二分类，但只凑得出 120 张标注照片。最合理的路线是：

  1. A. 用 GAN 生成一百万张合成照片，再从零训练一个大网络
  2. B. 从随机初始化训练一个 50 层深网：120 张虽少，多跑几百个 epoch 总能记住
  3. C. 放弃监督学习，改用 K-means：把照片聚成「戴帽 / 不戴帽」两簇
  4. D. 迁移学习：下载 ImageNet 预训练的大网络，冻结（或以极小学习率微调）前面所有层，只换上自己的输出层、用 120 张照片训练最后一层——别人学好的边缘 / 纹理 / 形状检测器直接复用
显示答案与解析
答案：D

小数据 + 大任务 = 迁移学习的主场（第 6.5 节）：预训练网络的浅层早已学会通用的视觉基元，「安全帽」这种小改动只需重训输出层（或轻微微调），120 张照片绰绰有余。B 是「用死记硬背治过拟合」——120 张背得滚瓜烂熟也没见过车间的千变万化；C：K-means 无监督地找「相似照片扎堆」，没人保证堆的边界恰好是戴帽 / 不戴帽，簇可能是「白天 / 夜晚」或「近景 / 远景」；A 合成数据可以辅助，但从零训练依然比不过站在预训练肩膀上，性价比远逊 D。

计算★★★

医学筛查模型部署在患病率仅 0.5% 的体检人群上。团队决定用 F₁ 作单一指标挑选报警阈值 θ。算一算三个阈值的 F₁，选出最优：

给定　F₁ = 2PR/(P+R)；θ=0.5：P=0.40, R=0.90；θ=0.9：P=0.75, R=0.60；θ=0.99：P=0.90, R=0.30
  1. A. 选 θ = 0.99：精确率 0.90 最高，误报最少，当然选它
  2. B. F₁(0.5) ≈ 0.55，F₁(0.9) ≈ 0.67，F₁(0.99) ≈ 0.45 → 选 θ = 0.9，单一指标下的最优平衡点
  3. C. 选 θ = 0.5：召回 0.90 最高，宁可错报不可漏报
  4. D. 三个阈值的 F₁ 相等，选哪个都一样
显示答案与解析
答案：B

调和平均专治「一高一低」（第 6.6 节）：θ=0.5 → 2×0.40×0.90/1.30 ≈ 0.55；θ=0.9 → 2×0.75×0.60/1.35 = 0.90/1.35 ≈ 0.67；θ=0.99 → 2×0.90×0.30/1.20 ≈ 0.45 → θ=0.9 胜出。A / C 各抱一条腿：只看 P 会漏诊一片、只看 R 会误报成灾，F₁ 把两头一起拉进成绩单。别忘了这道题的另一半：患病率 0.5% 时「准确率」彻底失效——全预测健康也有 99.5% 准确率（6.6 节的招牌反例）。实务上若漏诊代价极高，业务可以人为偏向高召回——那是业务决策凌驾于指标之上，不是 F₁ 算错了。

概念★★★

三个项目摆上桌：① 电商商品推荐——每天千万级「曝光 → 点击」日志；② 扫地机器人路径规划——有高保真仿真器，清洁率 / 耗时 / 电量都可量化；③ 小说写手助手——「写得好不好」迟迟没法变成数字。适合上强化学习的是：

  1. A. 只有 ②：仿真器免费 + 奖励可量化，两问全过；① 手里握着海量带反馈的历史数据，监督学习更对口更便宜；③ 奖励函数写不出来，第一关就倒
  2. B. ①②③ 都上：RL 是未来，早学早上
  3. C. ① 上 RL：推荐就是不断给用户试错的过程，本质就是 RL
  4. D. ②③ 上 RL：仿真器都可以造出来，两问都算过
显示答案与解析
答案：A

收官选型两问（第 10.7 节 + 第 10 章结尾）：① 模拟器免费吗？② 奖励写得出来吗？——一票否决制。② 两问全过（课程里的四旋翼、数据中心冷却降温 40% 都是这一类：模拟便宜、指标清晰）；① 已有千万级「行为 → 反馈」日志，监督学习 / 推荐系统直接见效，RL 从零试错反而昂贵（C 把「在线系统」误当「RL」——没有「动作改变环境状态」的闭环，就不是 RL 的地盘）；③ 的病根在奖励设计——「文学质量」翻译不成数字，仿真器再好也白搭（D 只救了一半）。B 是技术崇拜，不是工程决策。
