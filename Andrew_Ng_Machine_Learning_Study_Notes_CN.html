机器学习入门

Introduction to Machine Learning

看懂训练数据、预测直线与代价曲线，手算一轮同步梯度下降。

读一张面积与售价的表 → 用 f(x)=wx+b 预测 → 用 J 比较参数 → 沿负梯度更新

梯度下降小实验

改变学习率，观察平方代价在五次更新中怎样变化。

0.1
Python 实操 · 手算一次批量更新

先算第 0 轮残差，再算两个偏导，并验证一步后代价是否下降。

x = [1., 2.]
y = [2., 4.]
w = b = 0.
alpha = 0.1
m = len(x)

def cost(w, b):
    return sum((w * xi + b - yi)**2 for xi, yi in zip(x, y)) / (2 * m)

print("初始 J =", cost(w, b))
error = [w * xi + b - yi for xi, yi in zip(x, y)]
dw = sum(e * xi for e, xi in zip(error, x)) / m
db = sum(error) / m
w, b = w - alpha * dw, b - alpha * db
print(f"w={w:.2f}, b={b:.2f}, J={cost(w,b):.4f}")

核对输出　初始 J=5，更新后 w=0.50、b=0.30、J=2.1825。

本周自测 · 一轮更新里，为什么 b 的梯度不能用刚更新过的 w 重新计算？

这一轮的两个偏导必须对应同一个旧参数点，更新向量才是该点的负梯度。

什么是机器学习？

What is machine learning? · 5 分钟

一个程序可以借助经验 E，在任务 T 上改善按指标 P 衡量的表现。训练通过数据调整模型参数，推理使用训练好的参数处理新输入。学习效果要在没有参与参数拟合的例子上检查。

算例与应用

垃圾邮件过滤中，T 是判断邮件类别，E 是标注过的历史邮件，P 可以是新邮件上的召回率或误报率。改进目标不同，可能选出不同的模型。

理解检查与容易混淆之处

训练集表现提高只能证明模型更擅长现有样本。新样本表现仍需要验证。

深入阅读 · 补充算例与解释

假设你想写一个程序：输入房屋面积，输出房价。

最直接的办法是自己规定：「每平方米值多少钱，再乘面积。」但你可能不知道合理单价，也不知道卧室、位置该占多少比重。

机器学习的做法是：先收集已经成交的房子，把面积和真实成交价一起交给程序，让它从这些例子里寻找一种预测规则。

已成交房屋 面积 实际价格
A 50 平方米 £200,000
B 100 平方米 £400,000

这是为了方便计算而编的两条数据。你能看出：面积翻一倍，价格也翻一倍。程序也可以通过调整一个简单公式，学出这种关系。然后遇到一套 80 平方米、价格尚不知道的房子，它就可以试着预测。

这里的「学习」有非常具体的含义：根据已有例子，调整规则里的数字，让预测与真实结果更接近。我们后面会一步步算出这些数字如何调整。

课程中的三类学习

监督学习（supervised learning）：训练例子里带着参考答案。房屋面积是输入，成交价是答案；邮件内容是输入，是否垃圾邮件是答案。「监督」指数据带标签，不是有人一直盯着电脑。

无监督学习（unsupervised learning）：给数据，但没有现成的分组答案。例如给一批顾客的购买记录，让程序寻找消费习惯相似的人。程序发现的组不一定恰好对应你想象中的人群，需要进一步解释和评价。

强化学习（reinforcement learning）：程序选择动作，环境给奖励，而且动作会影响后面的局面。例如控制游戏角色向左或向右，最终要看累计得分。奖励告诉它结果好不好，通常不直接告诉它每一步应该按哪个键。

回归与分类有什么区别

预测「房价是多少」是回归，输出一个数值；判断「邮件是不是垃圾邮件」是分类，输出类别，或先输出属于某类的概率。

把「猫、狗、鸟」写成 0、1、2，任务仍然是分类。这些数字是类别编号，不表示狗位于猫与鸟之间。

Applications of machine learning 与 Jupyter Notebooks

识别照片中的文字、把语音转成文本、给用户推荐物品，都是输入数据后产生有用输出的例子。先明确具体输入与期望输出，比先决定用哪个时髦算法更重要。

课程代码常在 Jupyter Notebook 中运行。它把说明文字和代码分成不同单元；运行一个单元后，变量会保存在当前内核中。若后面用了前面没运行过的变量，就会报错。第一遍按从上到下顺序执行，修改定义后重新运行依赖它的单元；需要重现时，重启内核并运行全部单元，可以发现隐藏的顺序依赖。

停下来想一下：预测明天气温，与判断明天是否下雨，分别是什么？

预测气温是回归，因为要估计一个数值。判断是否下雨是二分类，因为最终要选「是」或「否」。如果输出下雨概率，那通常仍是在为分类决策提供依据。

线性回归模型（一）

Linear regression model part 1 · 10 分钟

课程用房屋面积与实际价格说明训练集。第 i 条记录写成 (x⁽ⁱ⁾, y⁽ⁱ⁾)，m 是样本数，x 是特征，y 是目标，模型输出写成 ŷ。上标括号标记第几条样本。

算例与应用

若三套房面积为 50、70、90，第 2 条样本的 x⁽²⁾ 是 70。模型对这一条可预测 200，该值写作 ŷ⁽²⁾。真实 y⁽²⁾ 仍是数据表里的 210。

理解检查与容易混淆之处

区分行号 i 和后面多特征中的列号 j。x⁽²⁾ 与 x 的平方含义不同。

深入阅读 · 补充算例与解释

上一章的房屋数据可以直接用 50、100 和 200000、400000，但这样手算很长。我们统一缩小单位：面积每 50 平方米记为 1，价格每 £100,000 记为 1。

房屋 面积输入 x 真实价格 y
A 1 2
B 2 4

现在，x=1 对应 50 平方米；y=2 对应 £200,000。它们不是实际面积变小了，只是换一种计量单位。后面房价章节一直使用这两条数据。

一个符号只负责一件事

x 是输入。你准备拿什么来预测？这里是面积。

y 是正确答案，也叫标签（label）。这套房子实际卖了多少钱？这里的答案已经记录在训练数据里。

一条样本（example）是一组输入和答案。A 房屋是一条，B 房屋也是一条。m 是样本数量，所以这里 m=2。

特征（feature）是输入中描述对象的一项信息。现在只用面积，因此有一个特征；若再加卧室数、楼层、离市中心距离，就有多个特征。特征数量通常记为 n。

上标括号不是乘方

课程用 x⁽¹⁾ 表示第一条样本的输入，用 x⁽²⁾ 表示第二条。这里 x⁽¹⁾=1，x⁽²⁾=2。括号里的 1、2 是「第几条」，不是让 x 做几次方。

相应地，y⁽¹⁾=2，y⁽²⁾=4。后面看到 Σᵢ，就把它读成「把各条样本的结果加起来」。暂时不用把它想得比普通加法复杂。

预测值与真实值必须分开

真实价格写作 y。模型给出的价格通常写作 ŷ，读作 y-hat；也可能写作 f(x)，意思是「把 x 交给预测规则 f 后得到的输出」。

如果模型预测 A 房屋值 1，而真实值是 2，那么 ŷ=1，y=2。模型训练的起点，正是这两个数还不相等。

两套房子，每套记录面积、卧室数和楼层。m 与 n 各是多少？

m=2，因为有两条房屋样本；n=3，因为每条样本有三个输入特征。若把成交价也放在表里，它是目标 y，不自动算作输入特征。

线性回归模型（二）

Linear regression model part 2 · 7 分钟

用直线 f(x) = wx + b 表示模型。w 是斜率，x 每增加 1，预测变化 w。b 是截距，调整 b 会整体平移直线。模型参数由训练确定。

算例与应用

把面积单位设成 10 平方米，价格单位设成千英镑。若 w=25、b=20，则 80 平方米对应 x=8，预测为 220。保留 w、把 b 提高 10，所有预测都提高 10。

理解检查与容易混淆之处

写参数前注明单位。零面积处的截距可能没有现实含义，超出训练范围的预测也要谨慎解释。

深入阅读 · 补充算例与解释

我们先让程序使用一种很简单的预测规则：

把它读成：预测价格 = 面积输入 × 一个比例 + 一个统一加上的数。

你已经知道 x 是面积、ŷ 是预测。新增的两个符号是 w 和 b。w 控制面积变化时价格增加多快；b 对所有房屋统一加上同一金额。它们叫参数（parameters），因为训练时要调整它们。

先试 w=1、b=0

对于 A 房屋，x=1，预测 1×1+0=1，也就是 £100,000。但它实际卖了 £200,000，少估了 £100,000。

对于 B 房屋，x=2，预测 1×2+0=2，也就是 £200,000。它实际卖了 £400,000，也低估了。

参数选择 A 的预测 B 的预测 和真实价格相比
w=1，b=0 1 2 都偏低
w=2，b=0 2 4 这两条恰好都对
w=2，b=1 3 5 都统一高了 1

因此你已经能凭直觉判断：这两条数据更适合 w=2、b=0。机器训练要做的，就是把这种「调旋钮、看结果、继续调」变成可以自动执行的步骤。

调整 w 与调整 b，有什么不同

如果 b 增加 1，每套房的预测都增加 1。若 w 增加 1，A 的预测增加 1，B 的预测增加 2；面积越大，受到 w 改动的影响越大。

所以 w 常叫权重（weight），b 常叫偏置或截距（bias/intercept）。这里的偏置参数与后面「偏差—方差」里的统计偏差，是两种不同含义。

训练好后，怎样预测新房屋

假设已经选定 w=2、b=0。一套 80 平方米的房子，对应 x=80/50=1.6。模型输出 ŷ=2×1.6=3.2，换回价格单位就是 £320,000。

这只是模型的估计。两条玩具数据恰好能被直线穿过，不足以证明真实市场也按这条规律运行。后面会专门讲怎样检查预测能力。

w=3、b=1，输入 x=2，输出是多少？改变 b 为 2 后又是多少？

原来 ŷ=3×2+1=7；改变 b 后为 8。你给定参数后代入输入算输出，这个过程叫预测或推理；现在还没有在更新参数。

代价函数公式

Cost function formula · 9 分钟

单条预测残差是 e⁽ⁱ⁾ = f(x⁽ⁱ⁾) − y⁽ⁱ⁾。课程使用 J(w,b) = Σ(e⁽ⁱ⁾)²/(2m)。平方使正负误差都增加代价，除以样本数得到可比较的量，1/2 让求导时的 2 抵消。

算例与应用

两条样本的真实值为 2、4，预测为 1、5。残差是 −1、1，平方和为 2，除以 2m=4 得 0.5。若直接求残差平均，则会错误地以 0 描述这组预测。

理解检查与容易混淆之处

J 是一批样本在同一组参数下的标量。单样本残差、单样本损失和总代价有三个层级。

深入阅读 · 补充算例与解释

要让电脑自动选择参数，不能只说「这条线看起来不错」。我们需要一种统一的评分办法，让它能比较两组参数。

继续用 w=1、b=0：A 预测 1、实际 2；B 预测 2、实际 4。先计算误差 = 预测 − 真实值，得到 −1、−2。负号表示低估。

为什么不直接把误差相加

假设另一个模型对两套房分别高估 1、低估 1。直接相加会得到 0，但两个预测显然并没有都正确。我们希望它们都被记为错误，因此不能让正负抵消。

一种常见方法是把误差平方：1²=1，(−1)²也等于1。平方还会让大错误受到更明显惩罚：误差翻倍，平方误差变成四倍。

完整算一次

步骤 A B
真实价格 y 2 4
模型预测 ŷ 1 2
预测减真实 −1 −2
误差平方 1 4

先把平方误差相加：1+4=5。再除以样本数 2：得到平均平方误差 2.5。课程还额外除以 2，得到代价 J=1.25。

这个额外的 1/2 主要让后面求导的式子更简洁；你对所有候选都乘同一个正数，不会改变哪组参数最好。就像考试成绩全班都统一除以 2，名次仍相同。

把长公式拆成刚才的动作

从括号最里面开始：wx⁽ⁱ⁾+b 是第 i 套房的预测；减去 y⁽ⁱ⁾ 得到误差；平方以后，把每套房的结果加起来；最后除以 2m。整个公式只是在压缩刚才那张计算表。

J(w,b) 的括号表示：给不同的 w、b，这个评分会改变。输入房屋数据固定时，我们希望找到使 J 更小的参数。

单条样本的误差评分通常叫 loss；一批样本汇总后的目标通常叫 cost 或 objective。资料用词可能不同，遇到时看它到底在计算单个还是整体。

如果改成 w=2、b=0，J 是多少？J=0 是否证明新房屋也能预测正确？

这两条训练数据的预测都正确，因此 J=0。它只说明这两条被拟合得很好；新房屋的价格仍可能受地段等未输入因素影响，不能直接保证。

算例与应用

理解检查与容易混淆之处

读图先认坐标轴。数据图的一个点是样本，代价图的一个点是一组参数。

深入阅读 · 补充算例与解释

现在已经有了两件工具：一个预测规则 ŷ=wx+b，一个比较好坏的分数 J。接下来要解决：怎样自动调整 w、b，让 J 降低？

最原始的办法是试很多组数字。例如 w=0、1、2、3，各配几个 b，逐一计算 J，然后挑最小的。这种试法直观，但参数一多就变得昂贵。

更有效的办法是观察：在当前位置，把某个参数稍微调大，J 会变大还是变小？如果调大能降低错误，就往大调；如果调大反而使错误增加，就往小调。

先只看 w，暂时固定 b=0

w A 的预测 B 的预测 J
0 0 0 5
1 1 2 1.25

从 w=0 出发，往大调可以接近好答案；但如果已经在 w=3，就应该往小调。同一个参数，更新方向取决于现在站在哪里。

把 w 放在横轴、J 放在纵轴，得到一条碗状曲线。低处代表错误小，我们想沿曲线走到低处。这里的横轴是参数 w，不是某套房子的面积 x；这是读图时很重要的区别。

一个训练循环的顺序

  1. 用当前 w、b 对所有训练房屋作预测。
  2. 比较预测与真实价格，计算 J。
  3. 计算参数分别应该朝哪个方向改变。
  4. 稍微修改参数，再重复。

第三步用到的数学工具叫导数或偏导数；把所有参数的偏导放在一起，叫梯度。下一章就用这个例子解释它们，而不是单独背定义。

预测是在当前参数下算答案；训练是在看到错误后修改参数。两者会在训练循环里反复出现，但不是同一个动作。

当 b=0、w=3 时，应该继续增大 w，还是减小 w？

应该减小。上表中 w 从 3 接近 2 时，J 从 1.25 接近 0。梯度的作用就是自动提供这种局部方向信息。

梯度下降

Gradient descent · 8 分钟

梯度下降反复计算当前点的梯度，再向反方向走一小步。通用写法是 θ ← θ − α∇J(θ)。在线性回归平方损失上，J 是凸函数。别的模型可能有多个局部极小值。

算例与应用

若 J(w)=(w−3)²，w=1 时导数为 −4。α=0.1 时下一点是 1−0.1×(−4)=1.4，向最低点 3 靠近。

理解检查与容易混淆之处

减的是导数乘以步长。导数为负时，更新会增大参数。

深入阅读 · 补充算例与解释

你可以先把导数理解成一个带正负号的数：在当前位置，参数增加一点点，代价会怎样变化？

仍固定 b=0。原来 w=0，J=5。试着把 w 增加到 0.1，此时 A 预测 0.1、B 预测 0.2，误差为 −1.9、−3.8，J=(3.61+14.44)/4=4.5125。

参数增加了 0.1，代价改变了 −0.4875，所以「每增加 1 单位 w，代价大约改变多少」可以近似写成 −0.4875/0.1=−4.875。负号说明：当前往右增加 w，会让代价下降。

把试探步长继续缩小，这个比值会越来越接近 −5。这个极限就是这里 J 对 w 的导数。你可以把它看成曲线在当前位置的局部斜率。

为什么叫偏导数

真实训练中 J 同时受 w 和 b 影响。若我们只改变 w、保持 b 不变，看 J 怎样变化，得到对 w 的偏导数，写作 ∂J/∂w；对 b 同理。∂ 只是提醒你还有别的变量，此时暂时固定它们。

第二条更容易读：把每条预测误差平均一下，就是 b 的梯度。如果整体都低估，平均误差为负，增加 b 就能把预测一起抬高。

第一条还多乘了面积输入 x。原因是 w 每增加一点，大面积房子的预测会变得更多；每条误差对 w 的影响因此要按 x 来加权。

手算当前梯度

从 w=0、b=0 出发，预测为 0、0，误差为 −2、−4。

对 w：先算 (−2)×1+(−4)×2=−10，再除以 m=2，得到 dw=−5。

对 b：先算 −2−4=−6，再除以 2，得到 db=−3。

「梯度」就是把这两个方向信息合在一起。在代码里常写 dw、db；它们表示代价对参数的敏感度，不是本次最终要移动的距离，距离还取决于学习率。

再往深一点：为什么平方误差求导后会出现「误差 × x」？

先看一条样本，令 e=wx+b−y，单条损失为 e²/2。

对 e 求导，e²/2 变成 e；而 e 对 w 的导数是 x。按照链式法则，两段影响相乘，得到 e×x。

对 b 则不同：e=wx+b−y，b 增加一点，e 同样增加一点，所以 e 对 b 的导数为 1，最终为 e×1=e。

把所有样本的导数相加并除以 m，就得到上面的两条公式。这也解释了代价中的 1/2 为什么方便：平方求导带来的 2 正好被消掉。

若当前 dw 是正数，要让 J 局部下降，w 应增大还是减小？

通常应减小，因为正导数表示 w 增大一点会使 J 增大。这里说的是足够小的局部变化；步子过大可能跨过低点。

实现梯度下降

Implementing gradient descent · 10 分钟

每轮先用同一组旧参数计算所有偏导，再一起写入新参数。用向量表示是一条赋值，用循环实现时可以先把梯度放在临时变量里。

算例与应用

在 (w,b)=(0,0) 上求得 ∂J/∂w=−5、∂J/∂b=−3。α=0.1，更新结果 (0.5,0.3)。若先写 w=0.5 再重算 b 的梯度，就变成了不同的更新规则。

理解检查与容易混淆之处

本课用同步更新。观察代码中计算梯度的函数被调用在参数写入前还是后。

深入阅读 · 补充算例与解释

上一章算出 dw=−5、db=−3。现在给每一步设置一个尺度 α，叫学习率（learning rate）。我们先取 α=0.1。

更新规则是「新参数 = 旧参数 − 学习率 × 对应梯度」。

从零开始算完整一步

原来 w=0，所以新 w=0−0.1×(−5)=0.5。原来 b=0，所以新 b=0−0.1×(−3)=0.3。减去负数，相当于增加参数，符合前面「两套房都低估，预测应抬高」的直觉。

新模型为 ŷ=0.5x+0.3。对 A：0.5×1+0.3=0.8；对 B：0.5×2+0.3=1.3。它还没有预测正确，但比原来的 0、0 更接近真实 2、4。

重新算代价：(0.8−2)²=1.44，(1.3−4)²=7.29；相加再除以 4，得到 J=2.1825。原来的 J=5，现在明显更小。之后重复这个过程。

学习率为什么重要

α 太小，每次改善很少，训练慢。α 太大，可能一下跨过低点，甚至越走越远。沿下坡方向并不意味着随便走多大步都安全。

例如仍从零出发，却取 α=1，那么得到 w=5、b=3。A 预测 8、B 预测 13，代价变成 ((8−2)²+(13−4)²)/4=29.25，比原来 5 更差。这不是公式给错方向，而是一步跨得过大。

两个参数要同时更新

先用同一组旧参数算好 dw 和 db，再一起更新。如果先改了 w，又拿新的 w 重算 db，这一步的含义就变了。代码中先保存两个梯度，可以避免这个错误。

什么时候可以停止

观察训练过程中 J 是否逐渐稳定，参数与梯度变化是否足够小，并设置最大迭代次数。真实训练里可能有噪声，神经网络的小批量损失也会波动；不必要求所有算法每一步都严格下降。

新 w=旧 w−αdw 中，负号是固定的；那 w 是否总会变小？

不会。dw 为正时通常减小，dw 为负时反而增大。算法要降低的是代价 J，不是要求所有参数都变小。

线性回归的梯度下降

Gradient descent for linear regression · 7 分钟

对平方代价按链式法则求导。设 eᵢ=wxᵢ+b−yᵢ，有 ∂J/∂w = Σ eᵢxᵢ/m、∂J/∂b = Σ eᵢ/m。w 的梯度多一个 xᵢ，因为提高 w 对预测的影响是 xᵢ。

算例与应用

样本 (1,2)、(2,4)，从 w=b=0 开始。e=[−2,−4]，两个梯度为 (−2−8)/2=−5、(−2−4)/2=−3。α=0.1 后参数为 (0.5,0.3)，J 从 5 降到 2.1825。

理解检查与容易混淆之处

梯度计算使用的是残差及输入。若把平均因子写成 1/(2m)，会漏掉求导带来的 2。

深入阅读 · 补充算例与解释

先用普通 Python 写训练循环，暂时不把所有计算压成矩阵运算。两套房仍是 (1,2)、(2,4)。

python
x = [1.0, 2.0]
y = [2.0, 4.0]
m = len(x)
w, b = 0.0, 0.0
alpha = 0.1

for step in range(2000):
    sum_dw, sum_db = 0.0, 0.0
    for i in range(m):
        prediction = w * x[i] + b
        error = prediction - y[i]
        sum_dw += error * x[i]
        sum_db += error

    dw = sum_dw / m
    db = sum_db / m
    w, b = w - alpha * dw, b - alpha * db

    if step < 3:
        cost = sum((w*x[i] + b - y[i])**2 for i in range(m)) / (2*m)
        print(step + 1, round(w, 4), round(b, 4), round(cost, 4))

new_area = 80 / 50
new_price = (w * new_area + b) * 100000
print('参数：', w, b)
print('80 平方米预测价格：', round(new_price))

内层 for i 逐套房作预测、算误差，再累计对参数的影响。sum_dw / m 和 sum_db / m 对应公式里的平均。外层循环则不断用新参数重做同一套动作。

第 1 次更新打印出的 w、b、J 应约为 0.5、0.3、2.1825，与手算一致。循环足够多次后，w 接近 2、b 接近 0，80 平方米预测接近 £320,000。

注意代码打印的 cost 是更新之后重新计算的，而梯度来自更新之前。没有必要强迫每一行代码都同时代表同一个时刻；关键是清楚它们的顺序。

真实任务还要划分训练与测试、检查数据质量。这里只用两条数据，是为了让训练过程透明可查，不是完整房价系统。

为什么 dw 不能写成所有 error 的平均，而要多乘一次 x？

因为改变 w 对不同输入的影响不同：x 大，预测随 w 改变得更快。而 b 对每条预测的影响都一样，所以 db 才是直接平均 error。

多个输入特征

Multiple features · 10 分钟

多元线性回归用一行向量表示一个样本，用权重向量为每列特征打分。预测是 f(x)=w·x+b=Σⱼwⱼxⱼ+b。将 m 条样本、n 种特征可组成 X∈ℝᵐˣⁿ。

算例与应用

单套房的面积和卧室数是 [8,3]，w=[25,5]、b=20，则 8×25+3×5+20=235 千英镑。换另一栋房时替换输入，沿用训练得到的 w 与 b。

理解检查与容易混淆之处

每列的输入顺序必须与权重顺序对应。面积改变计量单位后，权重的解释也变化。

深入阅读 · 补充算例与解释

只看面积不够。两套面积一样的房子，卧室数不同，价格也可能不同。因此把预测规则扩展为：面积×面积权重 + 卧室数×卧室权重 + 偏置。

这里 x₁ 是面积输入，x₂ 是卧室数；w₁、w₂ 分别表示模型怎样使用这两条信息。下标 1、2 现在是在编号特征，不是在编号样本。样本编号仍用上标括号。

先手算，再认识向量

假设某房面积输入 x₁=1.6、卧室 x₂=2；参数 w₁=1.5、w₂=0.2、b=0.1。预测为 1.5×1.6+0.2×2+0.1=2.9，即 £290,000。

把输入放成一个有顺序的列表 [1.6,2]，把权重放成 [1.5,0.2]，对应位置相乘，再全部相加，这就是点积。这个列表在数学里叫向量。顺序很重要：面积必须对应面积权重，卧室数对应卧室权重。

一批房子放在表里，就成为矩阵

X 的每一行是一套房，每一列是一项特征。如果有 100 套房、每套有 2 个特征，X 的形状就是 100×2。权重有 2 个，计算后每套房得到一个预测，共 100 个。

python
import numpy as np
X = np.array([[1.6, 2.0],
              [2.0, 3.0]])
w = np.array([1.5, 0.2])
b = 0.1
print(X @ w + b)  # [2.9 3.7]

@ 在这里对每行做刚才的点积。X * w 则只做逐项乘法，仍留下两列，不会自动把每行加起来。向量化的价值是用优化过的数组运算处理很多样本；它没有改变预测规则。

多个权重也需要分别求梯度。对第 j 个权重，把各条误差乘各自的第 j 个特征，再平均即可。矩阵写法 X.T @ error / m 是把这些平均一次算完；.T 表示交换行列。

X 有 30 行、4 列，这是什么意思？它应配几个特征权重？

30 条样本，每条 4 个特征，应配 4 个权重，再加一个偏置。如果得到 30×30 的误差数组，要检查是否把长度 30 的向量和 30×1 的列数组错误广播了。

特征缩放（一）

Feature scaling part 1 · 7 分钟

如果面积极大而卧室数很小，拟合对部分权重非常敏感，代价等高线常变得狭长。梯度会在狭长谷地里来回跳，限制可用的学习率。将特征转成量级较接近的数，常使优化更容易。

算例与应用

面积 2000 平方英尺与卧室数 3 直接参与梯度，一个残差对面积权重贡献为 2000e，对卧室权重贡献 3e。若将面积除以 2000、卧室数除以 5，对应输入变为 1 与 0.6。

理解检查与容易混淆之处

缩放是对输入列做变换。标签是否缩放取决于另一个建模决定。

深入阅读 · 补充算例与解释

如果一列面积大约是 50–150，另一列收入大约是 20,000–100,000，两列数字相差很多。梯度下降可能在某个方向变化很快、另一个方向变化很慢，难以选一个共同适合的步长。

特征缩放就是换一个更方便训练的计量方式。我们一开始把面积和房价改用较小单位，已经是在做类似的事情。

标准化怎样算

例如训练面积是 [50,100,150]。平均数是 100；标准差约为 40.825，它表示这些数围绕平均值的典型分散程度。标准化后，每个数先减 100，再除以 40.825。

于是 100 变成 0，50 约变成 −1.225，150 约变成 +1.225。数值的含义是「比训练平均水平高或低多少个标准差」。

μ 读作 mu，这里是训练平均数；σ 读作 sigma，这里是训练标准差。缩放不会自动让数据变成正态分布，也不保证每个数都在 −1 到 1 内。

新数据为什么还要用旧的平均数

假如模型在「100 平方米对应 0」的坐标系里训练，那么预测时也必须沿用这个坐标系。不能到测试集又重新定义一个平均水平。先划分数据，只在训练集计算统计量，再原样应用到其他集合。

特征工程是另一件事

缩放改变数值表示；特征工程则构造新的可用信息。例如给了房间长、宽，我们可以额外计算面积；给了交易时间，可以构造星期几、是否周末。

如果房价与面积关系明显弯曲，可以把 x²、x³ 当作新特征。这叫多项式回归。例如 ŷ=w₁x+w₂x²+b。它能画曲线，但对参数 w₁、w₂ 仍是线性组合，因此仍属于线性回归框架。

次数越高，模型越灵活，也更可能把训练噪声一起拟合。高阶列的尺度还可能变得很大，通常需要合理缩放；使用哪种表示和次数，应在验证集比较。

预测明日销量时，加入「明日最终退款数量」做特征，为什么有问题？

真正预测时，这个信息还没发生。它泄漏了未来信息，即使离线指标很好，也不代表系统能实际工作。特征首先要在预测时可用。

逻辑回归

Logistic regression · 10 分钟

先算分数 z=w·x+b，再用 sigmoid g(z)=1/(1+e⁻ᶻ)。可将 f(x)=g(z) 解释为模型估计的 P(y=1｜x)，P(y=0｜x)=1−f(x)。

算例与应用

z=0 时输出 0.5。z=2 时输出约 0.881，概率较偏向 y=1。z=−2 时输出约 0.119，两者的和为 1。

理解检查与容易混淆之处

z 是未经 sigmoid 的原始分数，也叫 logit。它可以为负，概率则不能。

深入阅读 · 补充算例与解释

现在改做一个新任务：判断邮件是不是垃圾邮件。设 y=1 表示垃圾邮件，y=0 表示普通邮件。

我们仍然可以先对输入特征加权，例如邮件是否包含某些词、链接数量等，得到分数 z=wx+b。但 z 可以是 −5、0、8，不适合直接当概率。

因此再接一个函数，叫 sigmoid。它把任意分数转换到 0 与 1 之间。

这里 e≈2.718 是自然常数；p 表示模型估计邮件属于正类 y=1 的概率。这个 σ 现在是函数名称，与上一章标准差符号长得一样，但含义不同，要看上下文。

分数 z sigmoid 后的 p 直观含义
−2 约 0.119 模型比较倾向普通邮件
0 0.5 两类概率各半
2 约 0.881 模型比较倾向垃圾邮件

你不用先掌握指数计算就能理解它的作用：分数越高，正类概率越大；分数很低，概率接近 0；分数很高，概率接近 1。

为什么还叫 regression

名字叫 logistic regression，但常用来做分类。它先给出连续概率，再由决策规则决定类别。不要通过名字里的 regression 推断它是在预测房价那种回归任务。

一条完整的数据流

邮件特征输入 → 加权相加得到 z → sigmoid 得到 p → 根据阈值决定是否拦截。

例如 z=2 得 p≈0.881，若规则是 p≥0.5 就拦截，则判为垃圾邮件。这里 0.881 是模型估计；模型可能出错，概率也需要通过新数据检验，不能因为输出在 0 到 1 内就认为它一定可靠。

模型输出 p=0.2，是指「有 20% 可能是垃圾邮件」，还是直接说明它一定不是？

它表达模型估计的正类概率较低，并不排除真实标签为 1。是否把它判成垃圾邮件，还要看实际阈值。

决策边界

Decision boundary · 11 分钟

默认阈值 0.5 时，sigmoid 的分界对应 w·x+b=0。输入为两个原始特征时，该边界是一条直线。若加入平方或交互项，原始平面上的边界可以弯曲。

算例与应用

若 z=x₁+x₂−3，边界是 x₁+x₂=3。(2,2) 预测为 1，(1,1) 预测为 0。改用 z=x₁²+x₂²−4，则边界是半径为 2 的圆。

理解检查与容易混淆之处

当概率阈值是 t，logit 边界变为 z=ln(t/(1−t))。等号归哪类由实现约定。

深入阅读 · 补充算例与解释

同一个模型输出 p=0.7，可以搭配不同的行动规则。阈值设为 0.5，它会判正类；阈值设为 0.8，它会判负类。

改变阈值是在改变决策要求，通常没有重新训练模型，也没有改变这个样本的概率。

为什么不用永远固定 0.5

漏掉一封垃圾广告和误拦一封重要通知，代价不同。某些任务希望少漏报，就把阈值降低，让更多样本进入正类；有些任务更怕误报，就提高阈值。最终还需要用验证数据检查效果。

对 sigmoid，p=0.5 恰好对应 z=0。因此当用 0.5 作为概率阈值时，模型实际上是在检查 wx+b 是否大于等于 0。

决策边界是什么

假设用两个特征 x₁、x₂，分数 z=x₁+x₂−3。边界是 x₁+x₂=3 这条线：线两侧的分数正负不同，预测类别也不同。

它叫边界，因为它分开模型作出不同决策的区域。训练样本是散点；决策边界是模型形成的分隔位置。边界不等于把所有样本依次连起来。

如果加入非线性特征，例如 z=x₁²+x₂²−1，边界是 x₁²+x₂²=1，也就是圆。逻辑回归在原始输入空间中不一定只能画直线，关键在你提供了什么特征。

概率阈值 0.5，是否应该在代码中直接检查 logit z≥0.5？

不应该。p≥0.5 对应 z≥0。若已经有原始分数 z，就用正确对应的分数阈值；不要把概率和 logit 混用。

逻辑回归的代价函数

Cost function for logistic regression · 12 分钟

实际 y=1 时单样本损失为 −ln(p)，y=0 时为 −ln(1−p)。正确类别的概率越接近 1，损失越小。用平方误差配合 sigmoid 通常会产生非凸目标，课程换用逻辑损失。

算例与应用

真实 y=1，给 p=0.9 则损失约 0.105。若给 p=0.1，损失约 2.303。越自信的错误受罚越重。

理解检查与容易混淆之处

概率为数学上的 0 或 1 时对数可能发散。代码可使用直接接收 logits 的稳定交叉熵。

深入阅读 · 补充算例与解释

分类训练需要比较预测概率与真实标签。假设真实是一封垃圾邮件，y=1。模型甲给它 0.9，模型乙给它 0.1。即便不看公式，你也知道甲更合理。

我们需要一种损失：给正确标签的概率越高，损失越小；给正确标签的概率越低，损失越大。交叉熵就是常用选择。

先看 log 在这里的作用

自然对数 log 满足 log(1)=0；当输入从 1 向 0 靠近，log 会变得越来越负。加一个负号后，−log(p) 就从接近 0 变成很大的正数。

若真实标签 y=1，就用 −log(p)。预测 p=0.9 时，损失约 0.105；p=0.1 时，约 2.303。若真实标签 y=0，则应关心模型给负类的概率 1−p，损失用 −log(1−p)。

不要被两个部分吓住：y 只有 0 或 1。y=1 时，第二部分乘 0 消失；y=0 时，第一部分乘 0 消失。一个公式只是把两种情况合在一起。

分类又怎样训练

对所有训练样本计算交叉熵并平均，再通过梯度下降修改 w、b。有一个很方便的结果：对于 sigmoid 配交叉熵，代价对 logit 的导数恰好为 p−y。

因此代码中的梯度仍是「误差乘特征再平均」，但这里的误差变成预测概率减 0/1 标签，不再是房价预测减成交价。

再往深一点：为什么这些损失还能叫最大似然？

真实标签为 1 时，模型给这条标签的概率是 p；真实标签为 0 时，是 1−p。我们希望模型给所有真实标签的联合概率尽可能大。

在训练样本条件独立的建模假设下，把这些概率相乘就是似然。取负对数后，乘积变成求和，最大化似然就等价于最小化交叉熵。

这解释了损失的统计来源，但实际训练时仍是在执行「预测→算损失→求梯度→更新」的循环。

数值实现需要再多一步考虑

如果先算 sigmoid 再取 log，极端分数可能被浮点数舍入成 0 或 1，导致 log(0)。实际库提供直接从 logits 算损失的稳定接口；NumPy 中二分类可用 np.logaddexp(0,z)-y*z。

真实标签 y=0，模型 p=0.9，损失应看 −log(0.9) 还是 −log(0.1)？

应为 −log(1−p)=−log(0.1)。模型给错误的正类很高概率，应受到较大惩罚。

过拟合问题

The problem of overfitting · 12 分钟

欠拟合通常连训练数据的规律也学不够。过拟合能解释训练集的偶然波动，面对新样本反而变差。用训练与验证的误差一起观察，避免只凭模型曲线形状下结论。

算例与应用

一个五次模型把五个带噪声的观测几乎拟合到零误差，验证误差却为 25。二次模型训练误差 3、验证误差 5。若目标是预测新样本，后者在该验证集上更好。

理解检查与容易混淆之处

高次数产生风险，但验证证据才说明是否过拟合。低训练误差本身也不等于高方差。

深入阅读 · 补充算例与解释

设想你只根据三套成交房屋训练模型。用一条直线可能大致描述价格趋势；用一条弯来弯去的复杂曲线，可以恰好穿过每个训练点。

复杂曲线的训练错误可能更小，但新房屋恰好落在两个点之间时，曲线可能给出很奇怪的价格。它把这些有限数据里的偶然波动也当成了规律，这叫过拟合（overfitting）。

相反，如果真实价格关系很复杂，但模型只会输出一个几乎不变的平均价，它连训练数据里的主要规律也没学好，叫欠拟合（underfitting）。

怎样知道发生了哪种情况

把一些已知答案的房屋先留出来，训练时不使用它们，之后再预测检查。如果训练表现很好、留出数据明显差，就要警惕过拟合；如果两边都差，先检查模型表示和训练是否充分。后面的评估章节会把这个过程展开。

正则化在限制什么

假设模型中有 x、x²、x³、x⁴ 等很多特征。某些很大的系数可能让曲线在数据间急剧摆动。L2 正则化给大权重增加额外代价，让模型在「拟合训练数据」和「避免过大的系数」之间做权衡。

第一部分是我们已经认识的数据损失；第二部分把各个权重平方后相加，再乘一个力度系数。λ 读作 lambda，越大越强调这份惩罚。b 通常不放进这一求和。

手算比较：两组参数的数据损失都是 1，一组权重 [1,1]，平方和 2；另一组 [10,10]，平方和 200。λ/(2m)>0 时，正则化目标更偏向第一组。

λ 过大也会限制过头，让模型连有用规律都学不出来。因此它不是越大越好。模型在训练中学 w、b；我们在外层比较 λ、学习率等设置，这类设置叫超参数（hyperparameters）。

这一段课程到这里连成了什么

我们先规定模型；用损失衡量它；用梯度下降训练；用新数据检查；必要时改变特征、容量或正则化。你已经认识了监督学习最重要的一条主线。

训练误差已经很低，新数据却很差，这时只把训练轮数翻倍，一定有效吗？

不一定，甚至可能继续拟合训练细节。应先检查划分与分布、正则化、模型容量和数据覆盖，而不是只追求更低训练损失。

神经元与大脑

Neurons and the brain · 11 分钟

神经网络的历史灵感之一来自神经元。机器学习中的单元执行可明确写出的数学操作：输入加权求和、加偏置、通过激活函数。一个 sigmoid 单元与逻辑回归有同样的计算形式。

算例与应用

若 x=[1,2]、w=[2,−1]、b=0，则 z=0，sigmoid 单元输出 0.5。若换成 ReLU 同一分数输出 0。

理解检查与容易混淆之处

生物类比用于引入网络概念。计算模型的学习规则和大脑机制属于不同的研究问题。

深入阅读 · 补充算例与解释

进入第二门课，我们开始认识神经网络。它最容易理解的起点，是你已经见过的逻辑回归：输入若干数，乘权重、相加，再过一个函数，输出一个数。这个计算单元可以看成一个人工神经元。

例如判断一件商品会不会热卖，输入可能是价格、运费、宣传力度。神经元给每项输入分配权重，得到一个综合分数，再转成概率。名字借鉴生物神经元，但你现在实现的是数学计算，不是完整复制人脑。

Demand Prediction（需求预测）在引出什么

有些问题不仅需要直接比较原始输入，还需要先形成中间判断。例如由价格和运费形成某种「购买负担」信息，由宣传形成另一种信息，再综合预测购买意愿。

神经网络把这些中间计算也变成可以训练的单元。给出真实购买标签后，训练过程同时调整前面和后面的权重，让整条计算链有利于最终任务。

这些中间输出叫表示或特征表示（representation）。你可以用「中间判断」建立直觉，但不能保证训练后每个单元都恰好有一个清楚的人类含义。

Example: Recognizing Images（例子：识别图像）为什么也能这样做

灰度图片的每个像素都可以写成一个表示明暗的数。一张 28×28 的图片共有 784 个像素，可以先排成长度 784 的输入列表。

网络经过多层计算，把这些像素转成有助于识别数字的中间表示，再输出「这是几」。对某些网络，前层可能对局部边缘有反应；但不能仅凭层号就断言每层一定学会了什么，仍要检查实际激活和行为。

这一组课程的核心变化：以前主要由你提供特征，网络则可以在训练目标推动下，同时学习中间表示。

一个神经元是否必须有一个人工事先规定的含义，比如「检测耳朵」？

不需要。你规定计算结构和训练目标，具体权重由训练学出。某些单元可能呈现可解释模式，另一些则是难以单独命名的混合信息。

一层有多个单元，每个都读前一层的输出。第 j 个单元的计算为 aⱼ⁽ˡ⁾=g(wⱼ⁽ˡ⁾·a⁽ˡ⁻¹⁾+bⱼ⁽ˡ⁾)。输入层可标作 a⁽⁰⁾=x。

输入 a⁽⁰⁾=[2,1]。两组权重 [1,−1]、[−1,3]，偏置都为 0，用 ReLU 得 [1,1]。这一层的参数彼此独立。

理解检查与容易混淆之处

层编号 l 与单元编号 j 不同。层中有 s 个单元，就产生 s 维向量。

深入阅读 · 补充算例与解释

一个神经元输出一个数；同一组输入同时送给多个神经元，就得到一层。层里的不同神经元有自己的权重，因此可以从同一输入里提取不同信息。

用两个输入、两个神经元手算

把一封邮件的两项特征记为 x₁=1、x₂=2：例如 1 个链接、2 次促销词。这里只用它们说明计算，不代表这样就能做出可靠邮件系统。

神经元 A 的权重设为 [1,−1]、偏置 0，分数为 1×1+(−1)×2=−1。神经元 B 的权重设为 [0.5,0.5]、偏置 0，分数为 0.5×1+0.5×2=1.5。

给两个分数使用 ReLU，意思是「负数变 0，非负数原样保留」。于是这一层输出 [0,1.5]。这是由原始输入 [1,2] 算出的新表示。

计算单元 加权相加 激活后的输出
第一层 A −1 0
第一层 B 1.5 1.5

下一层收到 [0,1.5]，假设权重 [1,2]、偏置 −1，就得到分数 1×0+2×1.5−1=2。最后过 sigmoid，概率约 0.881。

More complex neural networks（更复杂的神经网络）

把第一层输出交给第二层，再交给下一层，就形成多层网络。夹在原始输入与最终输出之间的层叫隐藏层；「隐藏」只是说它不是直接给定的输入或最终标签，并不是看不到计算。

输入多少项信息，叫输入维数；一层有多少个神经元，就是这一层的宽度；有多少层，就是深度。宽度与深度是结构选择，需要结合任务与数据，不是越大越好。

Forward propagation（前向传播）

刚才的 [1,2]→[0,1.5]→2→0.881，就是前向传播：参数已经给定，依次计算输出。此时我们还没根据正确标签修改权重，因此还不是完整训练。

第一层输出两个数，第二层收到的输入应该是原来的 [1,2]，还是 [0,1.5]？

在这个普通顺序网络中，第二层收到第一层的输出 [0,1.5]。网络的每一层都在使用前一层形成的表示。

python
import numpy as np
x = np.array([[1.0, 2.0]])  # 1 条样本，2 个特征
W1 = np.array([[1.0, 0.5],
               [-1.0, 0.5]])
b1 = np.array([0.0, 0.0])
z1 = x @ W1 + b1
a1 = np.maximum(z1, 0.0)
W2 = np.array([[1.0], [2.0]])
z2 = a1 @ W2 - 1.0
p = 1 / (1 + np.exp(-z2))
print(z1)  # [[-1.   1.5]]
print(a1)  # [[0.  1.5]]
print(p)   # 约 [[0.8808]]

这里 x 不是简单的 [1,2]，而是 [[1,2]]。外面多一层括号是在表达「一批数据，这一批只有一条样本」。它的形状是 (1,2)。若有 10 条同类样本，形状就是 (10,2)。

TensorFlow 把这类多维数组称为 tensor。先把二维 tensor 当成有行有列的表就够了；不要因为它换了名字，就以为必须另学一种神秘数据。

Matrix multiplication rules（矩阵乘法规则）

本笔记让每行放一条样本。输入 X 为 m×d，W 为 d×h，相乘后输出 m×h：m 条样本，每条 h 个神经元输出。中间的 d 必须相同，因为每个神经元都要对 d 项输入逐项加权。

上面第一层 W 的每一列对应一个神经元的权重。第一列 [1,−1] 是 A，第二列 [0.5,0.5] 是 B。这样再看 x@W，就能与刚才的两个手算对应起来。

用 TensorFlow 训练

TensorFlow implementation · 4 分钟

神经网络训练可以拆成定义结构、用 compile 指定损失和优化器、用 fit 在数据上迭代。课程的手写数字示例先做 0 与 1 的二分类，再扩展到十类。末层和损失必须采用一致的概率或 logits 约定。

算例与应用

一单元线性末层返回 logit，配合 BinaryCrossentropy(from_logits=True)。训练完成后应用 sigmoid 得到概率，随后按阈值作出分类。

理解检查与容易混淆之处

若末层已经是 sigmoid，应使用匹配概率输入的损失配置。将概率再次当 logits 会改变目标。

深入阅读 · 补充算例与解释

从前向预测变成训练，只需在概念上补三件事：知道正确标签；选择怎样计算损失；指定怎样修改权重。

建立模型、指定训练规则、执行训练，分别对应 Keras 中常见的模型构建、compile、fit。

下面是接口阅读示例，X_train、y_train、X_val、y_val 需要由你先准备；它不是可独立运行的数据实验。文件附带的 notebook 则有完整 NumPy 数据与实现。

python
import tensorflow as tf
model = tf.keras.Sequential([
    tf.keras.Input(shape=(2,)),
    tf.keras.layers.Dense(8, activation='relu'),
    tf.keras.layers.Dense(1)  # 原始分数 logit
])
model.compile(
    optimizer=tf.keras.optimizers.Adam(learning_rate=0.001),
    loss=tf.keras.losses.BinaryCrossentropy(from_logits=True)
)
# model.fit(X_train, y_train, validation_data=(X_val, y_val),
#           epochs=50, batch_size=32)

Input(shape=(2,)) 是每条样本有两个特征，不把这一批有几条写进去。Dense(8) 是隐藏层有八个神经元；Dense(1) 是最后给一个二分类分数。

Training Details（训练细节）在说明什么

框架会反复作前向计算、算损失、反向计算梯度、更新权重。你在第一门课里手写过的训练循环，没有因为调用 fit 就消失，只是由库管理。

batch_size=32 表示一次更新用约 32 条样本；epochs=50 表示大致把训练集完整遍历 50 轮。一次 epoch 通常包含很多次参数更新，所以它不等于一步梯度下降。

验证数据用于观察和选模型，不参与普通训练梯度。早停通常是：验证表现不再改善，就停止，并恢复验证最好的权重。它仍属于模型选择，应与最终测试分开。

为什么末层不写 sigmoid

这里末层输出原始分数，而损失设置 from_logits=True，让库用稳定的方式把 sigmoid 与交叉熵合起来算。推理时若需要概率，再对输出应用 sigmoid。

另一个正确搭配是末层 sigmoid、损失 from_logits=False。两种搭配都可以，关键是不能一边已经转换成概率，一边又告诉损失「这些是原始分数」。

epochs=10、每轮有 20 个批次，大约有多少次参数更新？

通常约 200 次，而不是 10 次。这个计数假设每个批次都执行一次普通更新，没有额外梯度累积等设置。

课程比较 sigmoid、ReLU 和线性函数。sigmoid 将实数映射至 (0,1)，ReLU 是 max(0,z)，线性激活直接返回 z。激活函数决定每个单元怎样输出计算结果。

算例与应用

输入 z=[−2,0,2]。ReLU 输出 [0,0,2]，sigmoid 输出约 [0.119,0.5,0.881]，线性输出 [−2,0,2]。

理解检查与容易混淆之处

ReLU 在 0 处不可导，框架通常选一个约定的梯度值。隐藏层的激活值一般不解释为类别概率。

怎样选择激活函数

Choosing activation functions · 8 分钟

隐藏层通常用 ReLU 作为起点。输出层按目标选：二分类需要 sigmoid 概率，多类互斥分类用 softmax，实数回归常用线性，目标已知非负时也可考虑 ReLU。训练中也可以输出 logits，再由损失或推理代码转换。

算例与应用

预测房屋温差可能有负值，线性输出可保留负数。预测是否违约需要一个二分类概率。新闻所属单一栏目需要各列加总为 1。

理解检查与容易混淆之处

看清输出值的取值范围。把 sigmoid 用于未缩放且跨越大范围的房价回归会限制输出。

深入阅读 · 补充算例与解释

你已经见过 sigmoid 与 ReLU。现在要理解：它们为什么放在不同位置，为什么网络不能每层都只做加权相加。

Alternatives to the sigmoid activation（sigmoid 之外的选择）

sigmoid 把分数压到 (0,1)，很适合作二分类概率。但在很正或很负的区间，输入改变一点，输出几乎不变；梯度也会变得很小。

ReLU 的规则更直接：g(z)=max(0,z)。z=−3 时输出 0，z=2 时输出 2。正区间不会像 sigmoid 那样逐渐压平，因此常用于隐藏层。负区间梯度为零也会带来问题，所以它同样不是万能选择。

Why do we need activation functions?（为什么需要激活函数）

先看只有一个数的例子：第一层算 a=2x+1，第二层算 y=3a+4。把第一式代入第二式，得到 y=6x+7。两层合在一起，仍是一条直线。

若每层都只做线性加权，叠更多层仍可合成一个线性变换。中间加入非线性激活，才可能表达超出单一线性模型的关系。网络的深度才有机会增加表示能力。

输出层该怎么选

目标 合适的常见输出方式 原因
普通实数预测 线性输出 允许正负和任意大小
二分类概率 1 个 sigmoid，或 1 个 logit 配稳定损失 概率在 0 与 1 之间
互斥多分类 多个 softmax 概率，或 logits 配稳定损失 一个样本属于一个类别
多个独立标签 每个标签各做 sigmoid 不要求各标签互相排斥

实际模型也可能为非负目标等使用其他输出参数化，但应根据任务约束选择，而不是因为某个函数流行就到处使用。

两个隐藏层都用线性激活，只有最后接 sigmoid，它的分类边界会自动变得很复杂吗？

不会。前面的线性层仍可合成一个线性分数，整体相当于对线性分数做 sigmoid。复杂边界需要非线性特征或隐藏层非线性等表示能力。

Course 2 · Week 2 / 第 07 节

Softmax

Softmax · 12 分钟

对所有 logits 取指数并除以指数之和，aⱼ=exp(zⱼ)/Σₖexp(zₖ)。概率合计为 1。真实类别 y 的损失为 −ln(aᵧ)，让训练针对正确类别的概率。

算例与应用

logits=[2,1,0] 得概率约 [0.665,0.245,0.090]。若标签为第二类，损失约 1.408。减去所有分数的共同常数后概率完全相同。

理解检查与容易混淆之处

softmax 概率取决于同一行里的所有类别。矩阵实现通常沿最后一维求和，避免把多个样本混在一起。

深入阅读 · 补充算例与解释

二分类只在两个类别里选一个。现在要识别图片是猫、狗、鸟，三者互斥，我们希望得到三个概率，而且加起来为 1。

让末层先输出三个分数 z=[2,1,0]。分数越大，模型越偏向对应类别，但它们还不是概率。Softmax 先对每个数求指数，再除以指数总和。

一步一步算

e²≈7.389，e¹≈2.718，e⁰=1，总和约 11.107。分别除以总和，得到 [0.665,0.245,0.090]。

因此模型估计猫约 66.5%、狗约 24.5%、鸟约 9.0%。若必须选一个，就选概率最大者。你也可以直接对原始分数求最大索引，因为 softmax 不会改变大小排序。

Neural Network with Softmax output（Softmax 输出网络）

真实标签若是狗，训练损失是 −log(狗的概率)，这里约为 −log(0.245)=1.408。模型要降低损失，就要提高对真实类别的概率。多分类交叉熵就是用这个原则评价。

标签若用一个整数 0、1、2 记录，常用 sparse categorical 交叉熵；若用 [0,1,0] 这样的 one-hot 列表记录，常用 categorical 交叉熵。类别含义没变，只是答案的存储方式不同。

Improved implementation of softmax（稳定实现）

若分数是 [1000,1001,1002]，直接求指数容易溢出。把全部分数减去最大值，变成 [−2,−1,0]，softmax 的结果不变，却更容易安全计算。实际训练还应尽量从 logits 直接计算交叉熵。

Classification with multiple outputs（多输出分类，可选）

若同一图片可以同时有猫和狗，这些标签就不互斥。应分别估计「有猫吗」「有狗吗」的概率，而不是用 softmax 强迫只能在几个对象里分配一份总概率。这是多标签任务。

在猫狗鸟三分类里，所有分数同时加 100，会改变概率吗？

不会，共同的指数倍数会在分子分母约掉。模型的相对分数决定概率，而不是三个分数共同的平移量。

进阶优化 · Adam

Advanced Optimization · 6 分钟

课程介绍 Adam 作为梯度下降的常用替代。它用梯度及平方梯度的移动统计量为不同参数调整有效更新幅度，保留一个全局学习率设置。

算例与应用

某个参数的梯度方向持续一致，另一个在正负之间震荡。Adam 能根据各自的历史调整更新。Keras 可通过 Adam(learning_rate=0.001) 设置优化器。

理解检查与容易混淆之处

Adam 不会自动选好网络结构、数据或一切学习率。对比优化器时使用相同的验证方案。

深入阅读 · 补充算例与解释

普通梯度下降对所有参数使用一个共同学习率。神经网络里的不同参数，梯度大小和变化方向可能很不相同；优化器尝试让更新更稳定、更有效率。

Adam 可以先理解为同时观察两件事：最近梯度通常往哪边走，以及最近梯度的量级有多大。它用这些历史信息，对不同参数调整更新尺度。

这里的「历史平均」会让最近信息占较大权重，较早信息逐渐衰减。由于刚开始没有历史记录，还需要修正从零初始化带来的偏差。这是 Adam 公式里那些平均与修正项的来源。

第一遍不必背完整公式。先掌握：Adam 最终仍在根据梯度改参数，仍需要选择学习率，仍可能训练失败，也不保证任何任务都优于普通随机梯度下降。

一次更新用多少数据

全批量使用全部训练数据算梯度；随机梯度下降每次用一条；小批量每次用一小组。小批量兼顾效率与梯度估计，是神经网络常见做法。

由于每批样本不同，损失会波动。应看整体趋势与验证表现，而不是因为某一步升高就判断算法出错。

Additional Layer Types（其他层类型）

全连接层让每个输出看所有输入。卷积层则在局部区域反复使用同一组权重，例如在图片不同位置检查相同局部模式。这样能利用图片的空间结构并减少某些参数重复。

课程这里只是引出其他层。你可以先知道「全连接不是唯一结构」，无需立刻把 CNN、RNN、Transformer 的全部内容都塞进这一节。

换成 Adam 后，是否就不需要检查数据和损失函数了？

仍需要。优化器无法修复错位标签、错误的输入尺度、泄漏或不匹配的损失。它只负责在给定目标下怎样更新参数。

计算图（可选）

Computation graph (Optional) · 19 分钟

把损失拆成几个简单运算节点。前向计算节点值，反向沿依赖传回梯度。串行路径乘上局部导数，有多个下游路径时对梯度贡献求和。

算例与应用

令 z=wx+b、J=(z−y)²。取 x=2、w=3、b=0、y=5，z=6、J=1。∂J/∂w=2(z−y)·x=4，∂J/∂b=2。

理解检查与容易混淆之处

反向传播计算梯度。改变参数的步骤由梯度下降或 Adam 等优化器执行。

深入阅读 · 补充算例与解释

这一组可选课程在解释：输出的错误怎样影响前面每一层。你已经在第一门课见过「参数改变一点，会让代价怎样变化」；反向传播把同样的问题沿着整条计算链重复计算。

先从一个神经元开始

输入 x=2、w=1、b=0，得到 z=2，sigmoid 输出 p≈0.881。真实标签 y=1，因此模型还应该把概率往上推一点。

对 sigmoid 配交叉熵，损失对 z 的导数为 p−y≈−0.119。改变 w 时，z=wx+b 对 w 的导数是 x=2，所以损失对 w 的导数约为 −0.119×2=−0.238。

α=0.1 时，新 w≈1−0.1×(−0.238)=1.0238。w 稍微变大，z 变大，正类概率也变大，符合真实标签为 1 的要求。

为什么叫「反向」

作预测时，信息从输入经过中间计算流向输出；求梯度时，从最终损失开始，问它对输出多敏感，再问输出对上一层多敏感，逐层往前乘。这就是链式法则。

你可以把中间量画成计算图：x、w 共同决定 z，z 决定 p，p 与真实标签共同决定 L。计算图帮助你确认每条依赖关系，避免漏乘或多乘某个导数。

Larger neural network example（更大网络的例子）

多层网络会把后层传来的敏感度，乘以当前层的权重与激活导数，再传给更前的层。矩阵公式只是把很多神经元、很多样本的同类计算写在一起。

自动微分框架替你沿图计算导数；有限差分则是把参数人为加一点、减一点，比较损失变化。后者很慢，但适合在小例子上核对手写梯度。附带 notebook 对逻辑回归、两层网络和协同过滤都做了这种核对。

再往深一点：一层权重的梯度怎样从单样本变成批量？

对一个神经元，权重梯度是「该神经元的误差信号 × 它收到的输入」。对一批样本，就把这些乘积平均。

若每行是一条样本，上一层输出为 A、当前误差信号为 D，矩阵写法是 AᵀD/m。这里 D 尚未包含 1/m；如果你提前在 D 中做了平均，后面就不能再除一次。

这个形状与多特征回归的 Xᵀerror/m 很相似，因为底层仍是加权相加的链式求导。

反向传播与梯度下降是同一件事吗？

不是。反向传播负责计算梯度；梯度下降或 Adam 使用这些梯度修改参数。两者通常相邻发生，因此容易混淆。

用同一组预测分数和标签，观察门槛变化时 TP、FP、FN 以及 P、R、F1。

0.50
Python 实操 · 从混淆矩阵算 P、R 和 F1

修改阈值，看看哪几个样本被重新判为正类。

scores = [0.95, 0.80, 0.65, 0.42, 0.34, 0.20]
labels = [1, 0, 1, 1, 0, 0]
for threshold in (0.5, 0.4):
    pred = [s >= threshold for s in scores]
    tp = sum(p and y == 1 for p, y in zip(pred, labels))
    fp = sum(p and y == 0 for p, y in zip(pred, labels))
    fn = sum(not p and y == 1 for p, y in zip(pred, labels))
    P, R = tp / (tp + fp), tp / (tp + fn)
    print(threshold, tp, fp, fn, round(2 * P * R / (P + R), 3))

核对输出　阈值 0.5 时 F1=0.667。阈值 0.4 时多找回一个正例且未增加误报，F1=0.857。

评估模型

Evaluating a model · 10 分钟

先训练再评估。回归可以报告模型在未见样本上的平均平方误差，分类可以报告错误比例或更符合需求的指标。课程诊断等式常用去掉正则惩罚的误差来比较不同模型。

算例与应用

测试标签 [1,0,1,0]，预测 [1,1,1,0]，错误率 1/4。若真实连续值 [2,4]、预测 [1,6]，则普通 MSE 是 (1+4)/2=2.5。

理解检查与容易混淆之处

训练的优化目标和报告的业务指标可以不同。说明是否带 1/2 因子以及是否评价概率。

深入阅读 · 补充算例与解释

训练时模型已经看过正确答案。直接用这些题评价它，就像让学生反复练同一套题，再把这套题当作能力测试：分数很高，也可能只是熟悉了题目。

因此在训练前，先留出一些样本。模型没有参与这些样本的拟合，之后预测它们，才更接近真正遇到新数据时的情形。

Model selection and training/cross validation/test sets

为什么还要分三份，而不只是训练与测试两份？因为你训练后还会做选择：三层还是五层？λ 多大？阈值 0.3 还是 0.7？如果反复根据测试表现选择，测试数据也会间接影响模型。

数据角色 具体做什么 类比
训练集 train 通过损失和梯度学参数 平时练习
验证集 validation / cross-validation set 比较结构、λ、阈值等方案 模拟考，用来调整复习策略
测试集 test 方案确定后估计表现 最终考试

比例没有唯一标准。对较大数据，验证和测试可能只需较小比例；对小数据，可考虑 K 折交叉验证。课程说 cross-validation set 时，常指一份验证集，不自动表示 K 折。

一个完整比较例子

训练三个多项式模型，次数分别是 1、3、10。用验证集比较，发现三次模型最好，于是选它。最后再看测试表现，报告模型对未参与这些选择的数据的效果。

若你看完测试发现十次模型更好，于是改选十次，再报告同一测试分数，这份测试已经用于选择。它还提供信息，但不再是原来那种独立最终检查。

数据怎么划分，也会影响结论

预测未来销量，应按时间分；同一病人的多次检查，通常要避免跨训练与测试混放；重复图片也不能一张进训练、一张进测试。划分应模拟实际使用，而不是一律随机抽。

标准化、缺失值填补、PCA、特征选择都属于训练流程。只用训练部分拟合，再应用到验证和测试；做 K 折时，也要在每个训练折里重新拟合这些步骤。

用验证集选 λ，算不算错误？用测试集反复选 λ 呢？

前者是验证集的正常用途；后者会污染最终评价。关键不是「有没有用标签」，而是各份数据是否承担了预定角色。

诊断偏差与方差

Diagnosing bias and variance · 11 分钟

比较训练误差与可达基线，估计高偏差。比较验证误差与训练误差，估计泛化差距。课程常以相近分布为前提使用这套判断，分布变化时要另外核对。

算例与应用

基线 2%、训练 15%、验证 16%，训练比基线高 13 个百分点。另一模型训练 3%、验证 18%，训练接近基线，但验证比训练高 15 个百分点。

理解检查与容易混淆之处

这两个差值是实用诊断信号。仅凭它们不能严格分解统计学意义上的 bias、variance 与噪声。

深入阅读 · 补充算例与解释

模型结果不好时，最有价值的问题是：它连训练规律都没学好，还是只在训练数据上表现好？这决定下一步该加容量还是改善泛化。

先用两个成绩判断

假设一个任务的合理参考错误率是 2%。模型 A 的训练错误率 20%、验证 21%，说明它连训练数据也没处理好。优化正常的前提下，可能需要更好的特征、更强模型或更弱正则，这叫高偏差倾向。

模型 B 的训练错误率 1%、验证 15%，说明对训练很熟，对新题差很多，表现为高方差倾向。可以尝试更多有效数据、增强、正则化或控制容量。

训练情况 验证情况 优先考虑
两边都明显比基准差，差距小 20% / 21% 模型表示、优化、高偏差
训练好，验证明显差 1% / 15% 泛化差距、高方差或分布问题
训练也差，差距还很大 20% / 35% 两种问题可能同时存在

这里不能只看「高于零」就判偏差高。图像里可能有模糊、歧义和标签噪声，合理基准本来就不为零。人类表现、简单基线和已有系统都可以提供参照，但人类错误率也不自动等于理论极限。

Regularization and bias/variance

正则强度大，模型受限制较多，通常更难把训练数据拟合到很低错误，但可能减少训练与验证差距；限制过头则欠拟合。调 λ 是在验证表现中找合适折中，不是只追求某一个方向。

Learning curves（学习曲线）

学习曲线把训练样本数放横轴，把训练和验证误差放纵轴。你想看：如果继续增加数据，验证表现还可能改善多少？

高方差模型在很小训练集上容易接近零误差，验证却差；加入更多有效数据后，训练题更难全部记住，训练误差可能略升，验证误差下降，差距缩小。

高偏差时，两条曲线可能在较高错误水平靠拢。继续加同类数据，未必解决模型表达不足。这里是经验诊断，要结合实际曲线，不是数学保证。

Deciding what to try next revisited

训练损失高，先排除学习率错误、训练不足和代码问题；验证差距大，也要检查训练与验证是否来自不同分布。不能把所有训练失败都叫偏差，把所有跨域失败都叫方差。

训练和验证错误率都高，直接把 λ 增大很多，通常是第一优先吗？

通常不是。更强限制可能让模型更难拟合。应先判断优化、特征与容量；如果存在其他证据再考虑 λ，而不是机械使用一种药方。

误差分析

Error analysis · 8 分钟

人工查看一些验证集上模型出错的案例，将可重复的失败分组并计数。之后估计每个方向能覆盖多少错误，再权衡修复成本。多个错误标签可以重叠。

算例与应用

100 条错例中有 30 条是故意变形词，18 条是转发模板，两类重叠 5 条。如果只修字符变形，粗略可覆盖其中 30 条，但真正能修复多少须用实验验证。

理解检查与容易混淆之处

按错例统计的比例是失败分布。它不等于这种情况在所有线上样本中的发生率。

深入阅读 · 补充算例与解释

模型训练后，面对「再加数据、换网络、改特征」这些选择，最实用的起点往往是打开错误样本，看看它究竟错在哪里。

假设验证集有 100 个误判。你检查后发现 45 个标签本身有歧义，30 个来自某种特殊相机，15 个是低分辨率，其余 10 个其他原因。这个结果会让你更有理由优先改标注规则和相机覆盖，而不急着盲换模型。

Iterative loop of ML development（迭代开发）

先有一个能运行的基线，再检查错误，选择一个有根据的修改，验证结果，再继续。这条循环的价值是减少凭感觉同时改十个东西，最后不知道究竟什么起作用。

Adding data（增加数据）也应该有针对性。如果模型主要错在夜景，继续加入大量白天照片未必最有效。增强数据要保留答案含义：普通物体水平翻转可能仍是同类，文字或左右方向标签则可能被改变。

Transfer learning: using data from a different task

迁移学习是借用相关任务已经学出的表示。例如一个网络见过大量普通图片，你保留它前面的表示层，为新任务换一个输出头。

数据少时，先冻结前面的权重，只训练新头；有更多数据时，再用较小学习率调整部分或全部网络。冻结表示在当前训练中不更新，不表示那些权重一直没有被训练过。

来源任务与目标是否相关很重要。借来一个表示并不会自动解决你的标签错误、分布差异或隐私问题。

Full cycle of a machine learning project

把一个模型变成可用系统，还要明确数据怎么来、预测在什么时候发生、结果由谁使用、失效后如何处理，以及上线后如何监控。用户行为和输入分布会变，离线一次高分不能保证长期稳定。

Fairness, bias, and ethics

平均成绩可能掩盖某些群体表现很差。因此应查看相关子群的样本量和误差，检查标注和数据覆盖；同时考虑输入与输出是否泄漏隐私，模型决策是否会给人造成实际伤害。

这里的「公平」不能简单理解成所有群体每个统计量都必须相等。应结合任务、影响与可行约束具体讨论，不能只靠一个总准确率作结论。

大多数错误来自同一种拍摄条件，下一步最有根据的动作是什么？

先核实这类错误及其样本覆盖，再尝试补数据、改善预处理或针对性建模，并用验证实验确认。误差分析给的是优先级依据，不是保证收益。

线上可监控到输入和预测变化，但真实标签常延迟出现。预测分数分布漂移与性能下降应分别验证。

不平衡数据的误差指标

Error metrics for skewed datasets · 12 分钟

当正例很少时，准确率可能掩盖漏检。先画混淆矩阵，再计算 precision=TP/(TP+FP) 和 recall=TP/(TP+FN)。Precision 问「我报出的正例有几个对」，recall 问「真实正例找到几个」。

算例与应用

有 1000 条记录，真实正例 10。模型报出 20 个，其中有 8 个真阳性。precision=8/20=0.40，recall=8/10=0.80。总是预测负类虽有 99% 准确率，却漏掉全部正例。

理解检查与容易混淆之处

没有预测正例时 precision 分母为 0。没有真实正例时 recall 分母为 0。报告时注明指标实现对零分母的处理。

深入阅读 · 补充算例与解释

假设 1000 封邮件只有 10 封垃圾邮件。一个模型永远输出「普通邮件」，准确率也有 99%。但它一封垃圾邮件都没找出来。

因此在正类很少时，accuracy 容易让你误判系统有用。我们把结果拆成四类：

实际情况 模型说垃圾邮件 模型说普通邮件
确实是垃圾邮件 TP：找对了 FN：漏掉了
实际是普通邮件 FP：误拦了 TN：放对了

Precision（查准率）

模型说「这是垃圾邮件」的那些邮件里，有多少真的属于垃圾邮件？如果共拦了 24 封，其中 18 封真是垃圾，precision=18/24=75%。剩下六封是误报。

Recall（召回率）

全部真正垃圾邮件中，找到了多少？假设真实共有 30 封，找到了 18 封，recall=18/30=60%。剩下十二封漏掉了。

两种问题的分母不同，所以不能因为模型查准率高，就说它找全了所有问题。

Trading off precision and recall（两者的权衡）

提高拦截阈值，模型更谨慎，拦得更少，召回不会增加；查准率可能改善，但不保证每个阈值位置都单调变好。降低阈值则通常能找更多正类，同时可能误拦更多普通邮件。

F1 尝试把两者合成一个分数，对其中一项很低比较敏感：

代入 18、6、12，得到 36/(36+6+12)=2/3。它不是 precision 与 recall 的普通平均，也没有把 TN 放进去，因此不是所有任务都适合只优化 F1。

实际可以在验证集上挑阈值，比如先要求 recall 至少达到某值，再尽量减少误报。阈值确定后，才在测试集检查最终表现。

精确率 100%、召回率 1%，是否意味着系统已经非常好了？

不一定。它可能只找出极少数最明显的正类。是否有用，取决于漏报与误报的实际代价，而不是单独看某一个百分比。

Python 实操 · 计算一次信息增益

从父节点和两个子节点的计数出发，自己算出加权后的熵。

from math import log2

def entropy(positive, total):
    p = positive / total
    return -sum(q * log2(q) for q in (p, 1 - p) if q > 0)

left = (4, 5)
right = (1, 5)
n = left[1] + right[1]
child_entropy = sum(node[1] * entropy(*node)
                    for node in (left, right)) / n
gain = entropy(left[0] + right[0], n) - child_entropy
print(round(child_entropy, 3), round(gain, 3))

核对输出　子节点加权熵约 0.722，父节点熵为 1，信息增益约 0.278。

决策树模型

Decision tree model · 7 分钟

树从根节点沿特征条件向下走，直到叶子输出类别或数值。课程用猫与非猫的图片特征解释规则路径。一个叶子可以对应多个样本，类别输出通常取多数。

算例与应用

根节点问耳朵是否尖，下一层问是否有胡须。若一张图片依次走向「是」和「是」，它收到该叶子的类别预测。

理解检查与容易混淆之处

树状条件是从训练数据选择的。规则看起来直观，并不能把相关性解释成因果。

深入阅读 · 补充算例与解释

决策树像一套逐步问问题的规则。比如分类动物：先问耳朵是否尖，再问脸是否圆，最后在叶节点输出类别。

「根节点」是第一个问题；「分支」是不同回答走的方向；「叶节点」是不再继续问问题、给出结果的位置。训练时要决定问哪个特征，以及在哪里停止。

Measuring purity（衡量纯度）

一个节点中如果 10 个样本全是猫，很纯；如果 5 猫 5 狗，就很混杂。我们希望问完一个问题后，分出来的节点比原来更纯，这样分类更容易。

熵 H 用一个数表示这种混杂程度。对二分类，正类比例为 p 时：

第一遍先记三个数：p=0 或 1，H=0，说明标签全一样；p=0.5，H=1，说明最混杂。这里用 log₂，因此单位常叫 bit。0log0 按极限约定为 0。

Choosing a split: Information Gain

假设原节点有 5 猫 5 狗，熵为 1。问「耳朵是否尖」后，左边 4 猫 1 狗，右边 1 猫 4 狗。每边的熵都约为 0.722，分裂后平均不确定性为 0.722。

所以信息增益=1−0.722≈0.278。若另一个问题分出来的两边仍各一半猫狗，增益就是 0；如果能把猫狗完全分开，增益就是 1。

为什么要按样本数加权

如果左边只有一个样本，右边有九个，就不能把左右视为同等重要。分裂后的熵是「左样本占比×左熵 + 右样本占比×右熵」。这让大节点中的混杂程度获得相应权重。

选分裂的核心：比较各个候选问题，看哪一个让当前节点的标签不确定性下降最多。

如果当前节点标签已经全一样，再分裂最多还能降低多少熵？

零。当前熵已为 0，通常可以直接成为叶节点，无须继续把同类样本拆得更细。

用信息增益选择切分

信息增益是父节点熵减去子节点熵的加权平均，权重为子节点的样本占比。候选分裂的增益越高，类别在训练节点内分得越清楚。

Course 2 · Week 4 / 第 05 节

完整走一次树训练

Putting it together · 9 分钟

从根节点找信息增益最大的候选，再对每个子节点用各自局部数据重复。停止时让叶子存多数类别或类概率。预测只沿一条路径。

算例与应用

根节点按耳朵分出两个分支。在尖耳分支中，局部 4 猫 1 非猫，再检查胡须能否把最后一例分开。该子节点的计算只使用其中 5 条数据。

理解检查与容易混淆之处

最大深度限制路径长度。即使训练叶都纯，过细规则也可能只适合极少数样本。

深入阅读 · 补充算例与解释

决策树训练不是只选好第一个问题就结束。选定一个分裂后，对左右子节点分别重复同样的过程：在该节点的数据里，再找一个好的问题。

Continuous valued features（连续特征）

如果特征是体重，不是简单的「是/否」，可以问「体重是否≤某个阈值」。例如特征 [1,2,3,4]、标签 [0,0,1,1]，阈值 2.5 能让两边完全纯。

通常先把不同取值排序，再尝试相邻值中点。每个候选都能计算信息增益，按同一标准比较。树学习通常是逐步贪心选择当前最好分裂，不保证最终整棵树全局最优。

Using one-hot encoding of categorical features

颜色有红、绿、蓝三个值，若直接写成 1、2、3，会人为引入顺序。one-hot 把它拆成「是不是红」「是不是绿」「是不是蓝」三列，例如绿色写成 [0,1,0]。

这样树就能问「是不是绿」。不同实现也可能支持原生类别特征，应以所用库为准。训练后编码规则必须沿用到新数据，并为未见类别设置处理方式。

为什么要停止

如果允许不断分裂，树可能把每条训练样本都单独记住。通常通过最大深度、最小叶样本数、最小增益等条件限制；再用验证集选合适设置。

树太浅可能欠拟合，太深可能过拟合。这与前面的模型容量问题是一致的，只是限制方式从权重惩罚变成了树的结构。

Regression Trees (optional)

预测房价也能用树。不同区域、面积范围被分到不同叶子，每个叶子输出该叶训练房价的平均值。之所以用均值，是因为在只能给一个常数时，均值使平方误差最小。

分裂时则比较平方误差下降，不再用分类标签熵。单棵回归树形成分段常数预测，因此输入越过阈值时可能突然跳变。

一棵树的训练成绩近乎完美，是否应该继续增大深度？

不能仅凭训练成绩决定。应看验证表现；继续增深可能只是把偶然细节分得更碎，并未提高新数据预测能力。

随机森林

Random forest algorithm · 6 分钟

对每棵树做有放回抽样，并在每个节点从随机选中的特征子集里找切分。最终汇总多棵树的预测。随机的特征子集降低各树重复使用同一强特征的倾向。

算例与应用

数据有 16 列，若每个节点考虑 4 列，该节点先抽 4 个候选再选其中最佳切分。到下一节点，再抽另一组。

理解检查与容易混淆之处

随机森林的树通常可独立训练。它与按前一轮误差顺序训练的 boosting 使用不同机制。

深入阅读 · 补充算例与解释

一棵树可能因为训练数据略有变化，就选择了不同的第一个问题，后面结构也全部改变。随机森林让许多不同的树共同决策，减少这种不稳定性。

Sampling with replacement（有放回抽样）

假设原数据是 A、B、C、D。每抽一次后把样本放回，可以得到 A、A、C、D 这样的训练集合；另一次可能是 B、C、C、D。样本可能重复，也可能没被抽中。

用多个这样抽出的数据集分别训练树，然后分类时投票、回归时平均，叫 bagging。树的数量多有帮助的前提之一，是它们不全犯一模一样的错误。

随机森林还在每个节点找分裂时，只考虑随机抽出的一部分特征，进一步让树不同。它通常不是「随机挑一列后整棵树一直只用这一列」。

XGBoost

提升树的组织方式不同：先有一个模型，再加新树帮助修正当前整体的问题，逐步累加。对平方损失，新树可以拟合剩余误差；对一般损失，梯度提升利用损失的负梯度方向。

XGBoost 是高效的梯度提升树实现，结合正则化、采样和工程优化。它与随机森林都使用多棵树，但训练逻辑不同。

When to use decision trees（什么时候用树模型）

对于表格型结构化数据，树集成通常值得作为强基线；对图片、音频和文本，神经网络更容易利用相应结构与表示学习。最后仍应在一致划分和合理调参预算下比较。

K-means 的步骤

K-means algorithm · 10 分钟

先选 K 个初始中心。对每条样本计算距离并记录中心编号 cᵢ。对每组求均值更新 μₖ。重复直到分配稳定、改进很小或达到迭代上限。

算例与应用

对点 (1,1)、(1,3) 同属的一组，中心更新为 (1,2)。若某个中心没有被分配任何点，则需要重置该中心等处理。

理解检查与容易混淆之处

计算 argmin 时平方距离已足够，平方根不会改变哪个最小。先明确空簇与距离相同的处理规则。

深入阅读 · 补充算例与解释

假设你只有顾客消费记录，没有人事先告诉你每个人属于哪类。你想把消费模式相近的人放在一起，这就是聚类。

K-means 先规定要分成 K 组，每组有一个中心。然后交替执行两件事：每个点找最近中心；每个中心移动到自己组里所有点的平均位置。

K-means intuition：用四个数手算

数据是 [1,2,8,9]，要分 K=2 组，先放中心在 1 和 8。

1、2 离中心 1 更近，8、9 离中心 8 更近。于是两组为 {1,2} 与 {8,9}。第一组平均为 1.5，第二组平均为 8.5，中心就移到这里。再分配，结果不变，算法稳定。

Optimization objective（优化目标）

为什么中心用平均值？因为平均位置能使组内平方距离总和最小。K-means 的目标就是让每个点离自己中心的平方距离尽量小。

在刚才例子中，所有点离对应中心都是 0.5，平方为 0.25，所以平均平方距离是 0.25。若一个点被分去很远中心，目标会明显变差。

Initializing K-means（初始化）

不同起始中心可能得到不同结果。通常多次启动，选目标最小的一次；K-means++ 用更分散的策略挑初始中心。若某组没有点，中心更新需要明确回退，例如保留原中心或重选。

Choosing the number of clusters（选择 K）

K 大通常使组内损失更小，因此不能只按这个损失选择，否则每个点各一组就可能最小。可以结合肘部、其他评价和实际用途。数据不一定存在一个特别明显、唯一正确的 K。

还要注意特征尺度：若一列数字比另一列大很多，距离就可能主要由它决定。K-means 也不擅长所有形状，例如环形簇或密度差异很大的簇。

两次聚类得到同样的两组点，但分别标成 0、1 与 1、0，这是不同结果吗？

仅编号交换，不是实质不同。簇编号没有天然类别含义，解释时应看每组包含哪些点以及它们的特征。

高斯分布

Gaussian (normal) distribution · 11 分钟

单变量高斯由均值 μ、方差 σ² 确定，标准差 σ 描述尺度。课程用 μ=Σxᵢ/m、σ²=Σ(xᵢ−μ)²/m 拟合参数。密度的峰值在 μ 附近。

算例与应用

用测量值 [8,10,12] 估计，μ=10，方差为 (4+0+4)/3=8/3，σ≈1.633。x=10 的密度高于 x=14。

理解检查与容易混淆之处

某个连续点处的密度不等于恰好取到该点的概率。区间概率对应密度曲线下的面积。

深入阅读 · 补充算例与解释

接下来要识别机器运行是否异常。假设正常机器的温度大多围绕 70°C，少数偏高或偏低。我们想用一个分布描述「正常时哪些数值常见」。

高斯分布的曲线像一个钟形：中心附近密度高，远离中心密度低。它主要由两个数决定：均值 μ 表示中心；标准差 σ 表示分散程度。

先解释均值与方差

正常温度 [68,70,72] 的平均数是 70。各自偏离平均数 −2、0、2；平方是 4、0、4。按课程高斯最大似然估计，方差 σ²=(4+0+4)/3=8/3，标准差是其平方根，约 1.633。

方差用了平方，因此不会让正负偏差抵消；标准差开方后回到温度原本单位。统计学中还有除以 m−1 的无偏样本方差，这里用 m 是因为估计目标不同。

密度不是「恰好这个数的概率」

对连续温度，曲线高度叫概率密度。真正说「温度在 69–71°C 之间的概率」，需要看那一段曲线下面的面积。

密度可以大于 1，所以看到密度 1.5 不能直接读作 150%。你也不能把某个精确温度点的曲线高度，当作恰好发生这个无限精确数值的概率。

再往深一点：把钟形曲线写成公式

(x−μ)² 表示离中心多远；除以 σ²，表示相对于正常波动幅度有多远；前面的负号让远处的指数变小。最前面的系数把总面积调整为 1。

你可以先用这个逐项解释理解，而不急着把整条公式背下来。

正常标准差很小的机器，温度突然偏离均值 10°C，与标准差很大的机器相比，通常哪一种更值得警惕？

前者偏离了更多个正常标准差，按相应高斯模型通常密度更低。但是否需要报警，还要结合任务、特征和验证阈值。

异常检测算法

Anomaly detection algorithm · 12 分钟

每一列先拟合一个单变量高斯。课程的乘积模型用 p(x)=∏ⱼ p(xⱼ;μⱼ,σⱼ²)。新样本 p(x)<ε 时标记异常。大量特征时可将乘积改为对数密度之和。

算例与应用

若两维密度为 0.2 与 0.01，总密度 0.002。ε=0.005 时标记异常。若用对数尺度，等价于比较 ln(0.002) 与 ln(0.005)。

理解检查与容易混淆之处

阈值 ε 越大，按该规则标异常的样本越多。乘积模型也可能遗漏只体现在特征相关性上的异常。

深入阅读 · 补充算例与解释

现在把「正常分布」用于报警。先用大量正常运行数据估计均值和方差，再计算新机器状态在这个正常模型下有多常见。密度太低，就标为疑似异常。

多个特征怎样一起用

一台机器可以同时有温度、功率、振动等数值。课程基础模型分别估计每个特征的高斯分布，再把各维密度相乘。

这是一个简化模型，忽略了特征间相关性。实际可能出现「温度单看正常、功率单看正常，但低功率配高温度很反常」。可以构造反映关系的特征，或使用更合适的联合模型。

Developing and evaluating an anomaly detection system

「密度太低」到底多低？设置阈值 ε，p(x)<ε 就报警。ε 大，报警范围更广；ε 小，只抓更罕见的状态。

正常训练集用来拟合分布；另外准备带一些异常标注的验证集，用 F1 或具体误报漏报成本挑阈值；最后用测试集检查。异常标签虽然少，仍对评价和选阈值很有价值。

密度在多维连乘后可能非常小，代码通常计算 log 密度，把乘积变成求和。若用 log p<t 报警，提高 t 同样会扩大报警集合。

Anomaly detection vs. supervised learning

如果异常很少、类型可能不断变化，描述「正常是什么样」比较有吸引力；如果有大量、相对全面的异常标签，且未来类型与训练相似，监督分类可能更直接。不是所有罕见事件都应该归为业务异常。

Choosing what features to use

好的特征应让正常与异常容易区分。只记录房间温度，可能看不出机器故障；加入运行负载、功率与温升关系可能更有效。

若某特征严重长尾，可考虑 log1p 等合理变换，但要检查取值范围，并在变换后重新拟合与选阈值。变换只是帮助建模，不会自动证明数据适合高斯假设。

正常训练数据拟合很好，但所有验证异常也都得到高密度，最值得检查什么？

检查特征是否真的反映异常、模型是否忽略关键关联、标注是否可靠。只微调阈值可能无法弥补输入信息不足。

-0.4
Python 实操 · 验证协同过滤的观测掩码

构造几个实际评分与未知评分，核对只有观测位置参与损失。

import numpy as np
X = np.array([[1., 2.], [1., 0.]])  # 两部电影
W = np.array([[2., 0.], [0., 1.]])  # 两位用户
b = np.array([[0.5, 0.]])
Y = np.array([[4., 0.], [0., 1.]])
R = np.array([[True, False], [False, True]])
P = X @ W.T + b
e = (P - Y)[R]
print(P)
print("平方损失 =", 0.5 * (e @ e))

核对输出　预测矩阵为 [[2.5, 2], [2.5, 0]]。只有两个掩码为 True 的单元被计入，损失 1.625。

用 (4+5)/2=4.5，第三位不参与均值，也不因缺失而产生评分误差。

推荐系统要预测什么？

Making recommendations · 6 分钟

评分矩阵的行可放电影，列放用户。y⁽ⁱʲ⁾ 是电影 i 被用户 j 给的分数，r⁽ⁱʲ⁾ 标记该评分是否观察到。训练只对已知项计算评分误差，再用预测结果寻找用户可能喜欢的未评分物品。

算例与应用

电影三部、用户两位，共 6 个格子。若只观察到 4 个评分，其余 2 格是未知。模型可以给未知格打分并排序。

理解检查与容易混淆之处

空白表示没有观察到评分。0 分是否为真实观测要由数据与掩码判断。

深入阅读 · 补充算例与解释

推荐系统要解决的问题是：一个用户没有评价过某件物品，我们能否估计他可能喜不喜欢？

先把数据放进表里。下面每行是一部电影，每列是一位用户；数字是 1–5 分，问号表示没有观察到评分。

电影 / 用户 A B C D
星际远航 5 4 1 ?
周末厨房 1 ? 5 4
数学日记 4 5 ? 1

这张表有 3 部电影、4 位用户。课程常记物品数量为 n_m、用户数量为 n_u，因此这里 n_m=3、n_u=4。用户数看用户这一维，不是看到矩阵行数就一律填行数。

两种下标分别在指谁

y⁽ⁱ,ʲ⁾ 表示第 i 个物品、用户 j 给的评分。在上表，y⁽¹,²⁾=4，意思是第二位用户 B 对第一部电影评 4 分。

课程题目经常从 1 编号；Python 从 0 编号，所以同一个位置在 NumPy 中写 Y[0,1]。先确定「行是什么、列是什么」，再换算下标。

问号为什么不能当零分

没打分可能是没看过，而不是看完讨厌。因此还要一张同样大小的表 R：有评分记 1，没有记 0。模型训练时，只对 R=1 的位置计算评分误差。

文件里可能把缺失评分暂存成数值 0，但那只是占位。真正决定是否参与训练的是 R 掩码。若丢掉掩码，模型就会误以为所有未看电影都应预测为零分。

三部电影、四位用户、每部用八维向量表示，评分表与物品向量表各是什么形状？

评分表 Y 是 3×4；物品向量表 X 是 3×8。前者列表示用户，后者列表示特征维度，不能把两个表的列含义混用。

协同过滤算法

Collaborative filtering algorithm · 14 分钟

电影特征也可从评分里学习。令电影向量 xᵢ、用户向量 wⱼ、用户偏置 bⱼ 都为可训练参数，最小化已观察格子的平方误差和及 L2 惩罚。梯度下降可同时更新两组向量。

算例与应用

若某个已评分格子的目标为 5、当前预测为 3，则误差 −2。其梯度推动这个用户向量与该电影向量的组合提高分数。未知格按掩码剔除。

理解检查与容易混淆之处

学出的潜在维度通常没有固定命名。若两个向量空间做同样的正交旋转，点积不变。

深入阅读 · 补充算例与解释

先设想电影特征已经由你提供：每部电影有「动作程度、浪漫程度」两个数。不同用户对两项的偏好不同，于是能像多特征回归那样预测评分。

例如某电影特征 x=[1,0]，用户偏好 w=[5,1]，偏置 b=0，预测为 5×1+1×0=5。另一电影 x=[0,1]，同一用户预测 1 分。

Using per-item features：先理解一位用户的回归

同一位用户看过多部电影，就提供了多个「电影特征→用户评分」样本。固定这些电影特征，就能训练这个用户的偏好参数 w、b。其他用户也各有自己的参数。

难点是现实中，你通常并不知道每部电影应该用什么特征数值。这正是协同过滤进一步处理的事：同时从评分里学习物品向量与用户向量。

先读下标：x⁽ⁱ⁾ 属于电影 i；w⁽ʲ⁾、b⁽ʲ⁾ 属于用户 j。T 表示这里要做对应相乘再相加的点积。它没有凭空换一种预测规则，只是不同电影与用户各有自己的数字。

损失怎样算

对于有真实评分的位置，用预测减真实，再平方。把所有已观察评分的平方误差加起来，乘 1/2；再给电影和用户向量加 L2 正则，避免依赖过大的参数。

例如只有两条已观察评分：第一条真实 5、预测 4；第二条真实 1、预测 2。数据损失是 ((4−5)²+(2−1)²)/2=1。其他缺失位置预测多少，都不进入这部分训练损失。

这些向量怎样互相帮助

一个用户喜欢的一批电影，会共同影响其偏好向量；某电影又收到多位用户的评分，因而其向量也同时受多位用户影响。用户和电影通过共享评分关系把信息联系起来。

再往深一点：只算一个向量的一步更新

设某用户 w=[1,2]、电影 x=[2,1]、b=0，预测 4，真实评分 5，误差 e=−1。

暂时固定用户参数，只改电影向量，不加正则。x 的梯度为 e×w=[−1,−2]；α=0.1 后，x 变为 [2.1,1.2]。

新的预测是 1×2.1+2×1.2=4.5，比原来 4 更接近真实 5。完整训练还会按旧参数同时计算所有用户与物品的梯度，再更新。

学到的向量通常叫潜在表示。它们不保证真的分别是「动作、浪漫」等可解释轴；前面的命名只是为了帮助你理解点积，实际学习坐标可能混合多种因素。

把物品向量全部固定，只训练某位用户的偏好，最像前面学过什么？

最像用物品特征预测该用户评分的正则化线性回归。协同过滤再把「物品特征也未知」纳入训练，因此联合问题更复杂。

均值归一化

Mean normalization · 9 分钟

对每部电影计算已观察评分的平均值 μᵢ。训练在 Y−μ 上学习相对基础分的偏差，预测后再加回 μᵢ。对没有评分历史的用户，电影平均分可作为起点。

算例与应用

某电影已有得分 4、5，均值 4.5。某用户的残差预测为 −0.4，则原尺度预测为 4.1。新用户没有足够偏好证据时先给约 4.5。

理解检查与容易混淆之处

平均值使用观测掩码。全新电影连自身平均值都缺失，需要全局或内容先验等办法。

深入阅读 · 补充算例与解释

某电影的训练评分为 4、5、3，均值是 4。我们可以先把这些评分改写成 [0,1,−1]，也就是「比这部电影平均分高或低多少」。模型预测完相对分数，再把 4 加回去。

这样做的好处是提供一个自然起点：对于几乎没有历史数据的新用户，若用户向量接近零，预测可以回到电影平均分，而不是不合理地回到零分。

均值从哪里算

只用训练中已经观察到的评分，不把验证、测试的答案提前算进去。若这部电影完全没有训练评分，不能除以零，应设明确回退，例如训练全局均值或内容模型。

Binary labels: favs, likes and clicks

实际反馈可能是点没点击、喜不喜欢，不再是 1–5 分。这时可把点积分数送进 sigmoid，用二元交叉熵训练。

但「没有点击」不一定是不喜欢，用户可能根本没有被展示过该内容。因此真实系统还需要关注曝光、负样本怎样产生、不同交互可信度等问题。缺失与负类不能随意等同。

Finding related items（寻找相关物品）

已经有了电影向量，可以找向量接近的其他电影。距离小或余弦相似度高，可能表示它们在当前表示下相似。

但相似电影不意味着每位用户都同样喜欢，也不意味着这种相似度代表因果关系。采用欧氏距离还是余弦、是否归一化，应与训练目标和评价保持一致。

TensorFlow implementation of collaborative filtering

实现的核心仍是：矩阵相乘得到全体评分预测；减去真实评分；用 R 只保留已观察项；计算损失和正则；自动求导并更新用户与物品向量。

若 Y 缺失处存的是 NaN，NaN*0 仍是 NaN。应先用索引或安全占位构造残差，不能以为乘掩码就能自动消除所有非法数。

一部电影平均分 3.8，模型预测相对平均分高 0.4，最终评分应是多少？

4.2。只报告 0.4 会忘记还原归一化时减掉的基准。

协同过滤与内容推荐的区别

Collaborative filtering vs Content-based filtering · 10 分钟

协同过滤主要利用群体交互形成表示。内容推荐从用户特征和物品特征预测匹配程度。内容特征可帮助有元数据的新物品获得初始分数，两种信号也能结合。

算例与应用

新电影没有任何评分，但已知类型、年份和语言。内容模型可以将它与用户偏好匹配。只依赖交互的向量需要额外先验或积累反馈。

理解检查与容易混淆之处

冷启动包含新用户与新物品两个问题。用户特征也可能缺乏或涉及需要谨慎处理的信息。

深入阅读 · 补充算例与解释

协同过滤主要从「谁给谁什么反馈」学习表示。如果一部新电影刚上线，一个评分也没有，单靠 ID 和评分关系很难知道它怎样。这叫物品冷启动。

内容推荐则利用物品自身信息，例如类别、剧情文字、演员等；用户也可以用可用属性与历史偏好表示。这些信息让系统有机会在交互很少时也作出估计。

Deep learning for content-based filtering

可以让一个网络处理用户信息，输出用户向量；另一个网络处理物品信息，输出物品向量。两者长度相同，做点积得到匹配分数。这种结构常被称作双塔。

这与协同过滤都使用向量，并不矛盾。区别主要在这些向量怎样得到，以及能否利用新实体已有的内容属性。实际系统可以结合两者。

Recommending from a large catalogue

若有上百万物品，每次把全部物品送进很复杂的模型代价很大。常见做法分两步：先快速召回一批候选，再更仔细排序。

例如提前算好物品向量，线上由用户向量找到几百个近邻；之后用更丰富的用户—物品交互特征排出最终列表。已经看过、无库存或不适合当前地区的物品，还需按明确规则处理。

Ethical use of recommender systems

点击率是容易记录的反馈，但不自动代表长期满意。只追逐点击，可能鼓励夸张标题、形成内容循环，或者让小众内容一直得不到展示。

因此除预测误差外，还应考虑排序质量、覆盖、多样性与长期影响。新用户、新物品也应单独检查，不能只在已有大量交互的老用户上证明系统好用。

新电影没有评分，但有剧情与类别。哪种方法更容易直接利用这些信息？

内容推荐可以直接把这些信息输入物品网络；单纯依赖评分矩阵与 ID 的协同过滤，需要其他机制处理冷启动。内容有帮助的前提是信息与偏好有实际关联。

PCA 的算法（可选）

PCA algorithm (optional) · 18 分钟

先用训练数据中心化，特征单位差异大且希望等权时可先标准化。第一主成分最大化投影方差，后续方向彼此正交并继续抓取剩余方差。投影得低维代码，可用均值加回得到近似重建。

算例与应用

中心化数据 [−2,−2]、[0,0]、[2,2] 沿 (1,1)/√2 投影，坐标为 −2√2、0、2√2。垂直方向无方差，保留一维可无损重建该例。

理解检查与容易混淆之处

主成分方向的正负可同时翻转，投影坐标也随之翻转，重建不变。

深入阅读 · 补充算例与解释

PCA 要解决的是：输入维度很多，其中一些信息重复，能否用更少的数保留主要变化？

先看点 [1,1]、[2,2]、[3,3]。它们都在同一条对角线上：只要知道沿这条线的位置，几乎不需要两个独立坐标来描述。

Reducing the number of features

把两个原坐标换成「沿对角线的位置」这一个数，就是从二维压到一维。PCA 选择的方向，是让投影后保留下来的变化尽可能大。多个方向则要求彼此正交。

先减均值：这里均值 [2,2]，中心化后变为 [−1,−1]、[0,0]、[1,1]。沿单位对角方向 [1/√2,1/√2] 做点积，得到 [−√2,0,√2]。每个点现在只用一个数表示。

压缩后能还原吗

把这个一维坐标乘回方向，再加均值，就能在这组完美共线数据中还原原坐标。真实数据往往并不完全在线上，还原时会有误差，这就是丢掉的信息。

解释方差比例可以告诉你保留了输入变化的多少。例如保留 99% 方差，不等于保留了 99% 的分类能力，因为 PCA 根本没看标签。小变化方向也可能正好决定类别。

PCA in code (optional)

实现中通常先中心化，再用 SVD 等分解找到主方向。新数据投影必须使用训练得到的均值与方向，不是对每一批新数据重新找一套轴。

不同特征的单位会影响哪种变化最大，因此是否先标准化，需要结合任务判断。PCA 也不是为了预测某一列而拟合一条回归线：它看的是所有输入点到子空间的重建误差。

第一次主方向画向右上，第二次画向左下，是否说明算法矛盾？

不一定，同一条轴的正负方向可以互换。如果投影坐标一起反号，重建和解释方差不会改变。

什么是强化学习？

What is Reinforcement Learning? · 9 分钟

智能体观察状态，选择动作，环境转移并返回奖励。学习目标是通过交互提高累积回报。奖励说明结果好坏，但通常不直接提供每个状态的正确动作。

算例与应用

月球着陆器可选择开主发动机或不动作。开发动机有代价，却可能降低撞击风险。最终需比较整段着陆过程。

理解检查与容易混淆之处

奖励定义决定优化目标。只奖励短期位置接近着陆点，可能遗漏速度或姿态造成的失败。

深入阅读 · 补充算例与解释

现在任务变了：程序要选择动作，动作还会改变后面看到的世界。比如一个机器人当前位置在中间，向左还是向右，会影响以后能到哪里、得到多少奖励。

状态 state 描述当前局面；动作 action 是它能选择的行为；奖励 reward 是环境对结果给的数；策略 policy 决定在每个状态怎样选动作。

Mars rover example（火星车例子）怎样理解

可以先想象一条路上有几个位置，不同终点的科研价值不同。车可以向左或右移动，有些路程短但奖励低，有些远却奖励高。它需要比较整个后续过程，而不只看下一步。

The Return in reinforcement learning（回报）

本讲义统一采用：在 S_t 做动作 A_t，环境返回下一状态 S_{t+1} 和奖励 R_{t+1}。回报把从现在开始的后续奖励加起来，并用 γ 逐步折扣。

γ 读作 gamma。若后续奖励为 0、0、10，γ=0.9，回报就是 0+0.9×0+0.9²×10=8.1。延后两步得到的 10，在当前价值里被折扣了两次。

γ 越小，越偏向近期；接近 1，远期奖励权重越大。不能把学习率 α 与折扣 γ 混成同一个调节数：一个控制参数怎么更新，一个控制如何重视未来。

Making decisions: Policies in reinforcement learning

策略可以是「在位置 2 向右，在位置 3 也向右」，也可以给不同动作分配概率。一个状态好不好，要结合之后遵循什么策略判断；同样起点，乱走与合理行动的期望回报不同。

马尔可夫状态需要包含足够信息，让未来主要由当前状态和动作决定。若观测太少，比如只给车的位置却不给决定后续的速度，可能需要补充状态或历史表示。

立即奖励和累计回报有什么区别？

立即奖励是刚执行一次动作后得到的反馈；回报包含之后一连串奖励，并可能折扣。为了以后更大收益，最优动作有时愿意暂时接受较低奖励。

状态—动作价值函数

State-action value function definition · 11 分钟

Q*(s,a) 表示在状态 s 先采取指定动作 a，随后采取最优动作时，期望得到的折扣回报。最优策略选使 Q* 最大的动作。给定固定策略时，也可定义对应的 Q^π。

算例与应用

若 Q*(s,左)=13、Q*(s,右)=19，那么在 s 贪心选择右。这里数值估计了未来总收益，动作本身仍可能只得到即时奖励 0。

理解检查与容易混淆之处

最大化的是动作价值。V*(s) 才是该状态下对所有动作取最大后的状态价值。

深入阅读 · 补充算例与解释

Q(s,a) 问的是一个明确问题：现在在状态 s，先执行动作 a，然后按某个策略继续，预计能得到多少累计回报？

它不是「这一步立刻能拿多少分」，因为后面发生的事也算；也不是只给状态一个数，因为它明确指定了第一步动作。

如果后续按最优策略行动，记为 Q(s,a)。只评价状态的最优价值则是 V(s)，等于这个状态各动作 Q* 中的最大值。

State-action value function example

假设当前向右可以得到即时奖励 2，然后进入下一状态。下一状态两个动作的最优后续回报分别是 3 和 5。接下来当然选 5，所以当前向右价值为 2+γ×5。

γ=0.9 时就是 6.5。这个计算把漫长未来压缩成下一状态的一个价值估计，因此不必在每次决策时重新展开整棵未来树。

Bellman Equation（Bellman 方程）

这是确定性下一状态下的简化写法。r 是当前转移得到的奖励，s′ 是下一状态，a′ 是下一步可能动作，max 表示挑未来最有价值的动作。

你可以读成一句话：当前动作价值 = 现在拿到的奖励 + 折扣后的最佳后续价值。

Random (stochastic) environment (Optional)

若同一个动作不一定到相同位置，就不能只算某一个结果，而要对可能结果按概率加权，也就是取期望。Bellman 思想没变，只是把确定的下一步换成下一步结果的平均。

真正终止时怎么处理

如果这一步之后任务已经结束，就没有后续回报。因此目标只有 r，而不是继续加 γ×某个随意估计的终止状态 Q。奖励时序必须前后一致：不要一会儿记进入状态的奖励，一会儿又额外多记一次。

r=2、γ=0.9、下一最大 Q=5，目标是多少？若下一状态已真正终止呢？

未终止时是 6.5；真正终止时是 2。是否终止会改变是否保留后续价值，不能漏掉这个判断。

Bellman 方程

Bellman Equation · 13 分钟

最优动作价值可分成一次即时奖励和一个折扣后的未来最优价值。确定性非终止转移写作 Q*(s,a)=r+γ maxₐ′Q*(s′,a′)。若转移终止，后一项取 0。

算例与应用

即时奖励 r=2，γ=0.9，下一状态两个动作价值为 10、4，则目标 11。若同一个 r=2 的转移终止，则目标为 2。

理解检查与容易混淆之处

max 作用在下一状态的可选动作。当前动作 a 已固定，不能再对它求一次最大值。

随机环境（可选）

Random (stochastic) environment (Optional) · 8 分钟

同一 (s,a) 可能产生不同的奖励与下一状态。Bellman 方程取这些结果的期望 E[r+γ maxₐ′Q*(s′,a′)｜s,a]，终止结果的未来项为 0。

算例与应用

一个动作以 0.8 概率到达价值 10 的状态、以 0.2 概率到达价值 0 的状态，两个结果即时奖励都为 1。γ=0.9 时目标为 1+0.9×8=8.2。

理解检查与容易混淆之处

先为每个可能的下一状态求最优动作值，再按转移概率加权。不要把最可能出现的结果当成期望。

位置、速度、角度等可取连续值，无法为每个可能坐标储存一张完整 Q 表。可以训练函数近似器，将观测向量映射到各动作的价值。

算例与应用

一架模拟飞行器的 x 位置为 2.10 或 2.11，两条状态接近但不相同。神经网络能通过共享参数为附近状态提供有连续结构的预测。

理解检查与容易混淆之处

连续状态与连续动作可以独立出现。课程着陆器的状态多为连续数值，动作是一组离散选项。

Course 3 · Week 3 / 第 12 节

如何学习 Q 函数

Learning the state-value function · 17 分钟

把交互经验 (s,a,r,s′,done) 存入回放缓冲区。从中抽取样本，用目标网络估计下一状态最大 Q，构造 y=r+γ(1−done) maxₐ′Q_target(s′,a′)，训练在线网络的 Q(s,a) 接近 y。

算例与应用

若 r=−1、γ=0.99，下一状态最大 Q 为 5，非终止目标为 3.95。若 done=1，则同一经验的目标为 −1。

理解检查与容易混淆之处

标题沿用课程的 state-value 写法。这里网络学习的是动作价值 Q(s,a)。构造目标时不对目标网络反向更新。

深入阅读 · 补充算例与解释

课程这一节接续价值函数与连续状态。下面把用于比较动作的网络明确写为 Q(s,a)，以便与只给状态打分的 V(s) 区分。

Example of continuous state space applications

小型网格只有几个位置，可以用表记录每个状态、动作的 Q。月球着陆器却有位置、速度、角度等连续数值，可能状态太多，无法逐一建表。

因此用神经网络：输入当前状态，输出各个离散动作的 Q 值。例如四个动作，对应四个价值输出。它们是累计回报估计，可以为负、也可以大于 1，通常不用 softmax。

先看表格 Q-learning 怎样更新

当前 Q 估计为 4，观察到一次转移后，得到一步目标 6.5。我们不直接把旧值全抹掉，而是往目标移动一部分。学习率 α=0.2 时，新值=4+0.2×(6.5−4)=4.5。

这与监督学习里「预测错了就改参数」相通，但这里的目标也包含当前对未来的估计，不是现成固定标签。

深度 Q 学习怎样接上神经网络

记录交互 (状态、动作、奖励、下一状态、是否终止)，构造目标 r+γ×下一最大 Q；用网络对实际执行动作的预测去逼近这个目标。若已真正终止，目标只有 r。

例如目标 6.5，网络预测 6.0，平方误差为 0.25。反向传播更新网络，让这个动作的价值估计更接近目标；不是把同一目标强行用来训练所有动作输出。

Algorithm refinement: Improved neural network architecture

让同一个网络一次输出所有离散动作的价值，可以共享状态表示，也避免为每个动作重复运行一套完全独立的前向过程。这不代表任何连续动作也能直接列成有限输出。

Algorithm refinement: ϵ-greedy policy

如果始终选择当前 Q 最大的动作，可能永远试不到另一条更好的路线。ε-greedy 以概率 ε 随机探索，其余时刻利用当前最好动作。训练通常逐步减少探索；评价时要说明是否还在随机探索。

Algorithm refinement: Mini-batch and soft updates (optional)

经验回放保存过去转移，再随机取小批量训练，减少相邻交互过于相似的影响。目标网络使用一套较慢变化的参数来算下一步价值；软更新是让目标参数每次只向在线参数靠近一点。这些标准做法有助稳定，但不是收敛保证。

计算本次损失时，目标通常停止梯度，不让网络同时沿目标那条路径反传。完整实现还需处理缓冲区、探索调度与评价，因此附带 notebook 先给更透明的表格 Q-learning，而不把几行伪代码当完整 DQN。

实现提醒：任务终止与时间截断

达到成功或失败终点通常是真正终止，后续价值置零。因为外部步数上限被迫停止，若底层任务还能继续，通常仍应保留下一状态价值。

Gymnasium 用 terminated 与 truncated 区分两者。若时间上限本身就是任务定义的一部分，则应按相应有限时域任务处理，并考虑在状态中包含剩余时间。不能无条件把所有回合结束都当成同一信号。

The state of reinforcement learning

强化学习可能样本消耗大、训练波动大，还可能利用奖励设计漏洞。多个种子的平均回报与独立评价，比一段成功录像更可信。学会 Bellman 和 Q 更新，是继续学更复杂控制方法的基础，不等于所有真实控制问题都已经解决。

反向训练 DQN 时，当前样本只执行了动作 2，应主要更新哪个输出的目标？

对这条转移，损失应比较实际执行动作 2 的 Q 预测与其一步目标。共享网络参数会间接影响其他输出，但不能把同一个目标直接当成所有动作的真实标签。

改进网络结构

Algorithm refinement: Improved neural network architecture · 3 分钟

一种直观的 Q 网络可输入状态与候选动作，对各动作分别前向。课程随后用状态作为唯一输入，一次输出所有离散动作的 Q 值，推理可直接选择最大输出。

算例与应用

输入形状 (64,8)，输出形状 (64,4)。训练时，第 7 条经验执行了动作 2，就取第 7 行第 2 号动作对应的分数来计算其误差。

Course 3 · Week 3 / 第 14 节

ϵ-greedy 策略

Algorithm refinement: ϵ-greedy policy · 9 分钟

以概率 ϵ 随机从可行动作中抽一个，以概率 1−ϵ 选当前 Q 最大动作。训练初期通常多探索，随后降低 ϵ 并可保留一个下限。

算例与应用

4 个等概率随机候选、ϵ=0.20，且贪心动作唯一。贪心动作的总概率为 0.80+0.20/4=0.85，其他各是 0.05。

理解检查与容易混淆之处

随机分支也能抽到贪心动作。贪心动作的总概率不总等于 1−ϵ。

Course 3 · Week 3 / 第 15 节

小批量与软更新（可选）

Algorithm refinement: Mini-batch and soft updates (optional) · 12 分钟

训练时从回放缓冲区抽样，减轻相邻转移高度相关的问题。目标网络更新得更慢，以稳定自举目标。软更新为 θ_target ← τ θ_online+(1−τ)θ_target。

算例与应用

某个参数在线网络值为 4，目标网络旧值为 2。τ=0.01 时目标参数变为 2.02。选择下一轮的 mini-batch 时仍复用缓冲区中的过去经验。

理解检查与容易混淆之处

τ 是目标网络的插值比例，与优化器学习率 α 不同。目标网络通常不直接接收损失梯度。
